# 261004-at1: Airlines tiles cleaned up (stacked on claude/flights-filter-chips)

## Objective

Owner feedback on the Airlines page: the tiles carry too much text, a big
button and a native select. Make a default tile its name and artwork only.

## Tasks

1. Remove the "N manual resolutions, N superseded" summary control, its
   constants, French strings, hover rule and the `[data-filter-set]` hook it
   alone used. The per-card "Resolved by hand" chip stays.
2. Remove the four text lines per tile (From SkyPane / Built-in artwork / Your
   changes / No changes). One small badge only when notable: a hand-made name
   (existing chip), no artwork, or replaced/own artwork.
3. Replace the large Replace/Add artwork button with a round pencil button on
   the artwork corner: 32px disc, 44px hit area, the same
   `data-view-panel-*` vocabulary (panel-lookup.js untouched), the add/replace
   wording kept as its accessible name. `icon-pencil` already exists, so the
   sprite and its count are unchanged.
4. Replace the "Aircraft type" select with a scroll-snap strip, one slide per
   type, the type name under the image, pagination dots (script-gated). It
   swipes and scrolls natively without script; a single-type airline has no
   dots and nothing to scroll; reduced motion jumps instead of smooth-scrolling.
5. Tests retargeted (served HTML, Playwright), render baseline, screenshots
   (390 / 1280, light / dark), full suite and gates.
