# Quick 261124-pl6: Plan 56, five mobile visual fixes

Findings by the owner on an iPhone (dark theme, French, 390 px wide). One atomic commit per fix.

## Task 1: sticky phone anchor bar (`.fleet-anchors`)
- The strip above the stuck bar is shown only while the bar is stuck (`data-stuck`, set by `fleet-anchors.js`), so it never covers the status line while the bar rests.
- The bar and the strip paint their slice of the page gradient (page height and own document offset passed as custom properties), so no band shows at any scroll position.
- Tests (Playwright, 390 wide, both themes, FR): `elementFromPoint` on the status line at scroll 0; bar and strip pixels equal the same pixels with the bar hidden, at scroll 0, 300, 700 and bottom.

## Task 2: bottom sheets over the on-screen keyboard
- `dialog.modal::after`: a fixed strip with the sheet's own background, `--keyboard-inset` tall, from the sheet's bottom edge to the viewport bottom.
- Test: every dialog of the account, airline editor and frame pages, with the visual viewport shrunk the way `modal.js` listens to it; points under the sheet hit the dialog; colours match; document size unchanged.

## Task 3: airline card corners
- The first and last airline groups and the first row take `--radius-card` less the 1px border, so no square fill shows outside the arc.
- Test: for the first, a middle and the last airline, opened and closed, both themes, a pixel just outside each corner equals the same pixel with the card hidden.

## Task 4: Add a frame page
- The outer `page-section` card is removed; the form is the one card and carries the entrance (`reveal`).
- Test: at 390 and 1280 px only the pair card paints a surface between the form and `main`.

## Task 5: page background to the bottom of the window
- A second background layer on `<html>`: a 200 px strip of the gradient's last colour that starts at the bottom of the box and hangs below it, so a window taller than the document shows no band of the flat top colour.
- Test: bottom row equals the pixel 200 px above (within the gradient's own few levels), 390x844 and 360x640, both themes, also with the document forced shorter than the window.
