<objective>
Fix `Cache-Control` on session-gated byte-serving responses in `companion/app.py`.

The shared `Handler.send_bytes()` helper (companion/app.py:205) hardcodes a shared-cacheable scope token whenever `cache_seconds > 0`. It has two call sites with opposite auth postures:

| Call site | Route | Session-gated? | Correct scope |
|-----------|-------|----------------|---------------|
| `_serve_stylesheet` (line 333) | `/static/style.css` | NO — an explicit D-02 gate exemption | shared-cacheable, max-age 300 |
| `_serve_gallery_image` (line 360) | `/gallery/*` | YES — `require_session()` in `do_GET()` | private, max-age 3600 |

Telling a shared/intermediary cache it may store and replay the gallery response means that response can be handed to a different client without that client's session cookie ever being re-checked. That is an information-disclosure bug on authenticated content.

Purpose: close finding WR-02 from Phase 06.4's code review (`.planning/phases/06.4-runway-picker-show-runway-number-and-airport-map/06.4-REVIEW.md`), which was deliberately left out of scope at the time and is now being fixed on its own.

Output: a per-call-site caching-scope distinction (NOT a blanket change to both), plus a regression test on each of the two routes.

**Approach note — fail-closed default (D-02 discipline).** The obvious shape is a `private=False` flag, but that makes the leaky header the default a forgetful future caller gets. Invert it instead: the parameter is named `public` and defaults to `False`, so the default cached response is private and a caller must consciously opt in to shared cacheability. This mirrors the fail-closed discipline this codebase already applies to auth (`companion/auth.py`'s `AuthNotConfigured` startup refusal).

**Non-goals.** Do not touch `_serve_preview_image()` (line 354) — it passes no cache lifetime, already emits `no-store`, and is correct. Do not add `Vary` headers, ETags, or conditional-request handling. Do not touch `deploy/Caddyfile` (verified: it sets no caching headers of its own).
</objective>
