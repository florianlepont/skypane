# Quick task 261112-8ck: Home "Detection" card (variant A)

Goal: Home shows which detection mode the frame is in (position mode around a
place and radius, or airport and runway) in one link row to the Location page.

Decisions (owner chose variant A after reviewing three mockups):
- One `group-block` "Detection" with a single `row--action` link under the hero,
  above the Frame group; chevron only, hidden "Edit detection" text for screen readers.
- Cases: position + usable place; airport and runway (Orly 07/25 when nothing
  was saved: "never chosen" cannot be told apart from legacy runway 3, and the
  frame follows the same runway); position without a usable place (warning icon,
  names the runway the frame falls back to).
- Wording comes from `companion/detection_summary.py`, shared with the Location page.
- Same visibility as Home itself (administrator, owner, co-manager); the place
  name goes through the existing `frame_place()` privacy gate.

Out of scope: `server/plane/*`, `server/poll_cycle.py`, phase 47/47.1, `hardware/`,
the frame protocol.
