# Quick task 261112-am5: Flights thumbnails that belong to the flight

Problem: `_attach_pictures` gave each Flights row "the latest archived render before the flight", else the earliest one. No flight-to-render link is stored, and the gallery keeps only 25 renders, so many rows showed another flight's picture (and the "Image du ..." link opened it).

Decision (owner chose variant 1 after a before/after page):
- A render counts as the flight's picture only when it was archived within a short window of the detection (90 s before, 10 s after): the poll cycle that records a flight archives the render showing it.
- No match: no picture link, and the phone row leads with the airline's own illustration when it has one, else a neutral plane icon (dashed outline). Neither is a link.
- The "View picture" link of the desktop table appears only for a real match.

Out of scope: `server/plane/*`, `server/poll_cycle.py`, phase 47/47.1, `hardware/`, frame protocol, the gallery cap.
