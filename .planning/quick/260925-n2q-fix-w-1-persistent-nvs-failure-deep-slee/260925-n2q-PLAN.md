# Quick task 260925-n2q: fix Phase 34 warning W-1

A persistent NVS failure at boot must deep-sleep with a fixed backoff
instead of panic-looping (`ESP_ERROR_CHECK` on `nvs_flash_init()` /
`nvs_open()` in `app_main.c`, before the abnormal-reset check).

## Tasks

1. Pure helper `nvs_boot.c/.h`: `fp_nvs_init_action(err, after_erase)`
   (READY / ERASE_AND_RETRY only on NO_FREE_PAGES / NEW_VERSION_FOUND and
   only once / UNUSABLE otherwise) and `fp_nvs_fail_sleep_s()` = first
   backoff step (300 s, never 0). Host tests in `tests/test_nvs_boot.c`
   (auto-discovered by `run_host_tests.sh`, run by `firmware.yml`).
2. `app_main.c`: replace the three `ESP_ERROR_CHECK`s with
   `nvs_fail_and_sleep("nvs", err)` — logs `fp_boot nvs unusable err=…`,
   the contract line `poll fail step=nvs backoff_n=0 sleep_s=300`, the
   timing line, then `enter_deep_sleep()`. No NVS, no radio, no fault
   screen. `fp_panel_on_boot()` moved above NVS init (RTC only) so the
   panel guard's accounting holds on that path. `_Static_assert`s pin the
   mirrored error codes.
3. Fault screen: document `nvs` in `fault_screen.h`'s exclusion list
   (sentinel lives in NVS) and assert it in `test_fault_screen.c`.
4. Log Line Contract: add `nvs` to VENDOR.md's step list; extend
   `check_log_contract.sh` extraction to `nvs_fail_and_sleep("nvs", …)`
   and make its VENDOR.md match exact (it used to pass on substrings).
5. Optional bench hook `SKYPANE_FAULT=nvs` (Kconfig choice, build.sh,
   `fp_fault_inject_nvs()`), rejected in production by
   `check_production_config.sh`.
6. Record `resolved:` on W-1 in 34-VERIFICATION.md.
