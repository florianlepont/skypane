| workflow to production deploy | Dispatch triggers an import on the VPS |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-64-40 | Tampering | live-frame release path altered | mitigate | Baseline recorded; additions-only diff against the Phase 57 tag is an acceptance criterion |
| T-64-41 | Elevation | publishing before Phase 57 release | mitigate | Blocking decision checkpoint first; plan stays blocked on "wait" |
| T-64-42 | Denial of service | deploy racing typed assets | mitigate | Dispatch remains the last step |
