Safari check list for the owner

R10: the owner saw the More sheet blur in the web app but not in Safari. The code gives no reason for a difference (the sheet is opaque, only the scrim blurs, 8 px, with the -webkit- prefix and :has() both supported in Safari 15.4 and later), so this is a measurement on the real phone. Nothing is changed unless the result shows a difference.R10 : le propriétaire a vu le flou de la feuille Plus dans l’app web mais pas dans Safari. Le code n’explique pas d’écart (la feuille est opaque, seul le fond assombri se floute, 8 px, avec le préfixe -webkit- et :has() pris en charge par Safari 15.4 et plus) : c’est une mesure sur le vrai téléphone. Rien ne change sans écart constaté.

  1. Note the iPhone model and the iOS version (Settings, General, About).Noter le modèle d’iPhone et la version d’iOS (Réglages, Général, Informations).
  2. In Safari (not the installed app), open the companion on Home. Tap More. Note: is the page behind dimmed? Is it blurred? Is the area under the status bar and the bottom toolbar dimmed too?Dans Safari (pas l’app installée), ouvrir le compagnon sur Accueil. Toucher Plus. Noter : la page derrière est-elle assombrie ? Floutée ? La zone sous la barre d’état et sous la barre d’outils est-elle aussi assombrie ?
  3. Repeat on Flights, Style and Place (the map page has its own layers).Recommencer sur Vols, Style et Lieu (la page carte a ses propres couches).
  4. Open the installed web app (Home Screen icon) and repeat steps 2 and 3 with the same pages.Ouvrir l’app web installée (icône de l’écran d’accueil) et refaire les étapes 2 et 3 sur les mêmes pages.
  5. Take one screenshot per case (Safari and app, Home and Place) with the sheet open, in Light and in Dark, and compare the blur of the text behind the sheet.Faire une capture par cas (Safari et app, Accueil et Lieu) avec la feuille ouverte, en Clair et en Sombre, et comparer le flou du texte derrière la feuille.
  6. Check Settings, Accessibility, Motion: is Reduce Transparency on? (it turns blur off in iOS itself.)Vérifier Réglages, Accessibilité, Animations : la réduction de la transparence est-elle active ? (iOS coupe alors le flou lui-même.)
Write the result as: iOS version, Safari blur yes/no, app blur yes/no, Reduce Transparency yes/no. If nothing differs, the item is closed. If not checked yet, it is verified in plan 32.Écrire le résultat : version d’iOS, flou dans Safari oui/non, flou dans l’app oui/non, réduction de la transparence oui/non. Sans écart, le point est clos. Si non vérifié, il l’est dans le plan 32.
