Filter bar (F1)

One shared search and filter module for Flights and Airlines.

What changes

  • Same module, same order and placement on Flights and Airlines: search field, sort, filter, info (always the last control).
  • Every control is 44px; the search field takes the remaining width; the info button no longer floats on its own line.
  • Active state is explicit: a count badge on Filters (A) or selected chips (B), a result count line, one-tap clear.
  • Only the filter options differ per page (direction/period on Flights; artwork/seen on Airlines).
