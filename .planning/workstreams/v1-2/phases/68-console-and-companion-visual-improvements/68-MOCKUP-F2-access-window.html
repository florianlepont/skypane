Access window (F2)

The “Gérer l’accès” dialog for frame co-managers.

What changes

  • Three clear zones: the owner (read-only, pill), the co-managers (avatars, one remove icon each), the add form.
  • Empty state is a dashed card with an icon, the existing heading “Aucun cogestionnaire pour l’instant” and one line of help.
  • A pending (not yet signed in) person has a dashed mail avatar, a “Pending” pill and an explanatory line; still removable.
  • Select and Add share one 44px row; on a phone the dialog is a bottom sheet with a grabber.
  • “Remove this frame” is kept apart from the add flow (link in A, bordered row in B); “Terminé” stays the single primary.
