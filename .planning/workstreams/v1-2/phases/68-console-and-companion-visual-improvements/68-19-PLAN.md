| Boundary | Description |
|----------|-------------|
| companion to Auth0 Management API | outbound calls with a machine-to-machine credential |
| environment file to process | second Auth0 secret |
| administrator to invited person | the ticket link is a one-time credential for setting a password |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-68-19-01 | Information disclosure | secret, token and ticket link in logs or repository | mitigate | read only from the environment file; no logging of these values (log-capture test); placeholders only in `skypane.env.example` and README |
| T-68-19-02 | Elevation | Management API scope | mitigate | documented scopes limited to `create:users` and `create:user_tickets`; no read, update or delete scope; the payload carries no role or metadata |
| T-68-19-03 | Elevation | Auth0 account without local invite | mitigate | sign-in still requires the local invite row (`fleet_sessions.sign_in_user` unchanged and tested); sign-ups stay disabled |
| T-68-19-04 | Spoofing | result URL redirect | mitigate | result URL is supplied by the caller from the validated application URL, never from request text in this module |
| T-68-19-05 | Denial of service | Auth0 outage or slow response | mitigate | timeouts and size cap; failure returns a result, never raises into the invite handler |
</threat_model>
