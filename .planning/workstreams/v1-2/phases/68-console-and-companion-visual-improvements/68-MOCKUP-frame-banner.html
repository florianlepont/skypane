Foreign-frame banner (version française)

R35 and R12: when an administrator opens the personal view (Home, Flights, Place, Style, Airlines) of a frame that is not theirs, a strong banner says so and one button returns to Fleet, on the same frame. Sample e-mails are invented. The two proposals differ only in colour and icon; sticky or scrolling is a switch below.

1. Today (shipped)

A 14 px strip on the same tint as a chip, rounded like a card, with an underlined link. It scrolls away and is easy to read as part of the page. Scroll the phone to compare.

Phone 360 px (data-viewport="phone")
Desktop 1280 px (data-viewport="desktop")

2. Variant A: accent slab (recommended)

Graphite slab in light, ivory in dark, on-accent text, eye icon, a thin amber bottom edge, text at 16 px, 44 px inverse button. It is the strongest element on the page and uses only existing accent pairs.

Desktop 1280 px, page switch in the top bar

3. Variant B: warn tone

Same content in the warn tone used by the anomaly banner: amber tint, dark amber text, person icon, accent button. Less heavy, but it reads as "something is wrong" rather than "this is not your frame".

Desktop 1280 px, page switch in the top bar

4. Long e-mail

The e-mail is never cut off or hidden: it wraps (anywhere) inside the text area and the button keeps its 44 px size and its own line when the text needs the width.

A, phone, long address
B, phone, long address
Today, phone, long address

5. Where Back to Fleet leads (R12)

Today the link is the plain /fleet route, which opens the first frame. Proposed: /fleet?frame=<id> with the id of the frame being viewed, so the administrator lands on that same frame. The id comes from the request scope, never from typed text.
