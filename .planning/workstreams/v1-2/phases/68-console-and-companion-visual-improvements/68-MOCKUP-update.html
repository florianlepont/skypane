Mockup for the owner. Existing components only (groups, segmented control, chips, buttons). Phone 360 px and desktop 1280 px; use the switches for language and theme.

Questions for the owner

  1. Retirer aussi l’ancien balisage de la page /update autonome dans le même changement, ou le laisser tel quel ?
    Recommandation : le retirer. Les deux pages partagent déjà les constructeurs ; garder deux balisages coûte plus cher que de régénérer le fichier de référence une seule fois.
  2. Une seule carte « Appareil et version » (résumé + état) à la place des deux blocs actuels : d’accord ?
    Recommandation : oui, c’est ce qui allège le plus le téléphone (un bloc en moins, un seul bouton principal).
  3. Notes de version repliées derrière « Notes (n) », ouvertes seulement sur la version proposée : d’accord ?
    Recommandation : oui ; les anciennes versions restent compactes.
  4. « Revenir » reste un bouton discret (fantôme) sur les versions plus anciennes, avec la page de confirmation ambre : d’accord ?
    Recommandation : oui, c’est une action réversible mais plus rare qu’Installer.
  5. Page de confirmation : afficher « Actuellement → Après » et l’heure estimée du réveil : suffisant, ou trop d’informations ?
    Recommandation : suffisant tel quel ; ne rien ajouter.
  6. Libellés : « Planifiée » / « Échec » en pastille, « Réessayer » en action : d’accord, ou autre mot ?
    Recommandation : garder ces mots, ils reprennent le vocabulaire existant.
