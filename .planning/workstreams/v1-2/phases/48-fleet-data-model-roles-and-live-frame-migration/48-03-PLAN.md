<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator args -> fleet_cli / fleet_migrate | email, MAC, hashes, names, timezone arrive as untrusted text |
| legacy JSON files -> migration | files may be corrupt, truncated, or hand-edited |
| migration/CLI -> legacy files | the live frame's identity files must never be damaged |
| stdout/stderr -> logs | deploy logs and CI output are broadly readable |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-48-11 | Tampering | corrupt legacy file migrated as "empty" | mitigate | strict reader aborts (exit 2) on any malformed non-empty file; tests for invalid JSON, wrong shape, bad MAC/hash |
| T-48-12 | Denial of service | migration damaging the live frame's identity | mitigate | migration only reads legacy files; directory snapshot test proves sha256 and mtime unchanged; fleet.db written in one transaction; marker set last |
| T-48-13 | Spoofing | bootstrap owner invented when email absent | mitigate | email required for the first run, abort before any write, same preconditions in dry-run; normalised and shape-checked |
| T-48-14 | Information disclosure | tokens/hashes printed in reports or CLI listings | mitigate | reports and `list` verbs print MACs, counts and hash prefixes only; tests scan captured output for the seeded token and hash |
| T-48-15 | Tampering | SQL injection through CLI args | mitigate | all queries go through fleet_db parameterised helpers |
| T-48-16 | Elevation of privilege | role set from outside the local row | mitigate | role only from `--role` on a local admin-run CLI, validated against ROLES; no claim input exists in this phase |
| T-48-17 | Tampering | reconcile resurrecting or overwriting intentionally changed data | mitigate | reconcile never deletes; legacy wins only on secret/token for MACs in both; CLI removal and revocation mirror to legacy so the two stay equal; test removes via CLI and re-runs |
| T-48-18 | Tampering | stranded device when token exists without registry entry | accept | aborting is chosen over importing a device with no secret; cannot occur on the live frame (one registered device), message names the MAC for manual repair |
</threat_model>
