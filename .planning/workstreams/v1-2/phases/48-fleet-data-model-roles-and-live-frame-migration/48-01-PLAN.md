<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process environment -> registry | the simulation gate is read from an environment variable that production must never set |
| caller -> get_profile | a hardware key arrives from a database row or CLI argument and is untrusted text |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-48-01 | Tampering | simulation gate in hardware.available_types | mitigate | gate equals the exact string "1", read per call; production guard test asserts env example and every unit file omit SKYPANE_SIM_HARDWARE |
| T-48-02 | Tampering | get_profile with unknown/hostile key | mitigate | lookup only by exact registry key, raises UnknownHardwareType; key is never used to build a path or SQL |
| T-48-03 | Elevation | profile mutation at runtime | mitigate | frozen dataclasses and MappingProxyType registry; tests assert immutability |
| T-48-04 | Information disclosure | profile data | accept | profiles hold public hardware facts only, no secrets |
</threat_model>
