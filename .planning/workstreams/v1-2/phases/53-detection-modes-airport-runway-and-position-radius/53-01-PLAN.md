## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-53-01 | Tampering | build_airports.py reading a hostile CSV row | mitigate | Default build reads only the committed, sha256-pinned subset; strict float parsing, 20 MB cap, regex on ident and designator, fail-closed validations; refresh run with `python3 -I` on a copy outside the repo |
| T-53-02 | Tampering | catalogue path/ID injection via find_airport / find_runway | mitigate | Exact-match regex then dict lookup only; no filesystem path, SQL or format string is ever built from the id; tests with "../x", newline and lowercase |
| T-53-03 | Denial of service | search_airports with a huge or pathological query | mitigate | Query capped at 60 characters, result capped at 20 rows, linear scan of about 272 airports |
| T-53-04 | Elevation of gate | half_width_m 0 silently widening the corridor to 500 in detect.corridor_params | mitigate | Floor of 50 m and a build-time failure on any value <= 0; test over every stored runway |
| T-53-05 | Information disclosure | catalogue contents | accept | Public airport data, public domain; no user data is stored in it |
| T-53-SC | Tampering | package installs | accept | No package is added; stdlib only (nothing to run slopcheck on) |
</threat_model>
