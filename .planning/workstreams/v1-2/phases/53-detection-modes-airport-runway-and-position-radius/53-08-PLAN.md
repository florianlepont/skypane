## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-53-34 | Elevation of privilege | assigning or editing another user's location (IDOR on location_id) | mitigate | Ownership checked server-side against the subject's list before any write, plus fleet_db.set_device_location_checked PermissionError mapped to the "not available" message; tests with two users |
| T-53-35 | Tampering | forged POST with location outside France or radius out of range despite client hints | mitigate | detection.validate_position runs on the rounded values server-side; strict regex before int(); all-or-nothing |
| T-53-36 | Tampering | CSRF on detection or location POST | mitigate | Existing Origin/Sec-Fetch-Site gate before routing; foreign-Origin test for both actions |
| T-53-37 | Tampering | stored XSS via location name | mitigate | Name length-capped to 60, escaped on every output (list, select option, summary, aria-label); test with markup and quotes |
| T-53-38 | Information disclosure | showing unrounded home coordinates beside the "rounded" claim | mitigate | The select and summary print only rounded values; the stored precision appears only in the owner's own location list (UI contract) |
| T-53-39 | Denial of service | unbounded location creation | accept | No cap per the owner decision; request bodies are size-capped and each row is small; zone count is bounded by 2-decimal centres and whole-km radii |
