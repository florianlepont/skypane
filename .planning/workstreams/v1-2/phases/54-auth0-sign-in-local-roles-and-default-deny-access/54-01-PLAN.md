## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process -> fleet.db | companion, byos and CLI all open the same SQLite file |
| Auth0 claims -> local users | identity claims decide which local row (if any) is signed in |
| backup archive | will now contain the sessions table |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-54-01-01 | Elevation | resolve_login | mitigate | No INSERT path; link only when email_verified is True, user enabled, iss/sub NULL, UPDATE guarded by `sub IS NULL` plus rowcount == 1; UNIQUE(iss, sub) backstop; thread-race test |
| T-54-01-02 | Spoofing | account takeover by email after first link | mitigate | After the first link, resolve_login matches on (iss, sub) only; same email with another sub is refused ("email_linked_other") |
| T-54-01-03 | Information disclosure | sessions table / backups | mitigate | Only sha256(token) stored; raw token never reaches the DB; README (plan 09) notes backups carry unexpired session hashes |
| T-54-01-04 | Spoofing | session fixation | mitigate | create_session(replace_hash=...) rotates atomically in one transaction |
| T-54-01-05 | Elevation | stale role / disabled user keeps access | mitigate | lookup_session joins users on every call; role and disabled are never cached in the row |
| T-54-01-06 | Denial of service | concurrent schema upgrade | mitigate | user_version re-read inside BEGIN IMMEDIATE; two-connection test |
| T-54-01-07 | Tampering | schema v2 vs previous release | accept | Old byos refuses a too-new file and serves from legacy files (covered by test_fleet_auth); documented in plan 09 rollback note |
| T-54-01-SC | Tampering | package installs | accept | No new dependency in this plan |
</threat_model>
