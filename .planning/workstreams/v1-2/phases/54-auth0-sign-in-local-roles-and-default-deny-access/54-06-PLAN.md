<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user principal -> global pages | role boundary between user and admin |
| shell navigation -> routes | links must not advertise unreachable or admin routes |
| browser cross-site redirect | cookie delivery after the Auth0 hop |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-54-06-01 | Elevation | user reaching admin pages or fleet data | mitigate | ADMIN_ONLY routes return NOT_FOUND for user; Account page renders identity only; test enumerates every admin GET/POST for a user |
| T-54-06-02 | Information disclosure | existence oracle (403 vs 404) and Health dot on error pages | mitigate | single 404 outcome byte-identical to unknown path; dot only for admin principals |
| T-54-06-03 | Tampering | post-preference redirect to an attacker path | mitigate | return target restricted to NAV_TABS plus /account via exact membership; user always /account |
| T-54-06-04 | Spoofing | Strict cookie lost or fixated across cross-site hop | mitigate | interstitial landing proven in Chromium on two different sites; documented fallback to Lax for the session cookie only |
| T-54-06-SC | Tampering | package installs | accept | none |
</threat_model>
