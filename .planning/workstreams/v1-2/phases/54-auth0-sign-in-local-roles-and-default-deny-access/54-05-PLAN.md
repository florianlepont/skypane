<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> /callback | code, state, error arrive as untrusted query parameters |
| companion -> Auth0 | token exchange with client secret |
| Auth0 identity -> local users | claims select which invited user is signed in |
| session cookie across cross-site redirect | SameSite behaviour of the landing |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-54-05-01 | Spoofing | login CSRF / code injection | mitigate | state bound to an HttpOnly Lax cookie and a server-side attempt, compared in constant time, popped on first use; PKCE S256; tested replay and mismatch |
| T-54-05-02 | Spoofing | token substitution | mitigate | iss/aud/azp/nonce/exp checked in validate_id_token before any lookup (tests for each) |
| T-54-05-03 | Elevation | open sign-up / account takeover | mitigate | no INSERT path; link only on verified email to an unlinked enabled invited row; same 403 page for every refusal; tested |
| T-54-05-04 | Tampering | open redirect through next / returnTo | mitigate | next only by exact NAV_TABS membership; redirect_uri and returnTo from configuration, never the Host header; open-redirect table test |
| T-54-05-05 | Information disclosure | codes, tokens and secret in logs, Referer | mitigate | print reason codes and numeric ids only; interstitial carries no-referrer; log-capture test |
| T-54-05-06 | Spoofing | session cookie withheld or fixated on landing | mitigate | 200 interstitial + meta refresh for Strict cookie survival; session rotated on login; browser test in plan 06 proves it |
| T-54-05-07 | Tampering | form-action CSP broken by 303 to Auth0 after POST | mitigate | logout uses a 200 interstitial; start is a GET |
| T-54-05-08 | Denial of service | unauthenticated attempt flood | mitigate | AttemptTable bounded (4096) with TTL; token call has timeouts and cap |
| T-54-05-SC | Tampering | package installs | accept | none |
</threat_model>
