The old stateless token functions stay in auth.py until plan 07 removes them with their tests.
Output: access.py, converted route table, principal-aware `_dispatch`, session-backed login/logout, deliberately regenerated render baseline.
Do not put plan, phase or decision IDs in code comments.
</objective>

| request path/captured segment -> device lookup | hostile ids can reach the DB layer |
| companion -> fleet.db | third writer to the shared SQLite file |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-54-04-01 | Elevation | route registered without a policy | mitigate | Route.__new__ raises TypeError without a valid Access; hand-written public/signed-in expectation sets in test_route_table |
| T-54-04-02 | Elevation | IDOR on device-scoped routes | mitigate | decide + authorized_device_id: owner match or admin; regex-validated ids before any lookup; unknown and foreign both NOT_FOUND with the same body as an unknown path |
| T-54-04-03 | Spoofing | session fixation / theft | mitigate | rotation on login (replace_hash), hash-only storage, HttpOnly + Secure + SameSite=Strict, logout deletes the row first |
| T-54-04-04 | Elevation | stale authority after disable or flag-off | mitigate | role/disabled read from users every request; legacy sessions re-checked against the flag every request |
| T-54-04-05 | Elevation | fail-open on DB error | mitigate | sqlite3/FleetDb errors answer 503 on gated routes, never ALLOW, never /login redirect; tested |

| T-54-04-07 | Denial of service | write-per-request on last_seen_at | mitigate | throttled to once per 5 minutes in fleet_sessions (plan 01) |
