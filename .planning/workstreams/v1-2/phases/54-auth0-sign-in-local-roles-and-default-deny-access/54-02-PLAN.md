<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| companion -> Auth0 token endpoint | outbound TLS call carrying client secret, code, verifier |
| Auth0 -> companion (redirect) | untrusted query params (code, state, error) arrive via the browser |
| environment -> config | operator-provided domain and secret |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-54-02-01 | Spoofing | token substitution (other client or tenant) | mitigate | validate_id_token checks iss exact (trailing slash), aud, azp, nonce (compare_digest), exp/iat with 60 s leeway; token read only from the token-endpoint response |
| T-54-02-02 | Tampering | TLS downgrade / SSRF | mitigate | verify=True always, https enforced except an explicit loopback-only test flag, domain only from operator env, no redirects followed, trust_env=False so no proxy/netrc |
| T-54-02-03 | Denial of service | slow-drip or huge token response | mitigate | connect/read timeouts, 64 KiB cap, overall deadline; tests with delay and oversized body |
| T-54-02-04 | Information disclosure | logging secrets | mitigate | SignInError carries reason code only; no body/code/token/secret in messages; test asserts message content |
| T-54-02-05 | Denial of service | AttemptTable growth by unauthenticated GETs | mitigate | 4096 cap, 600 s TTL, oldest evicted |
| T-54-02-06 | Tampering | partial config silently enabling weak mode | mitigate | all-or-nothing variables; Auth0ConfigError names variables only |
| T-54-02-SC | Tampering | package installs | accept | requests is already hash-locked; no new package |
</threat_model>
