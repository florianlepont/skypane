<interfaces>
Decode order shared with Python (server/image_container.py): panel dim 0 -> ARG; len>=4 and "SPIM" -> container path else legacy if len == ceil(w*h/2), else len<4 TRUNCATED, else MAGIC. Container path: len<24 TRUNCATED; header_len<24 or >len HEADER_LEN; version!=1 VERSION; flags!=0 FLAGS; reserved!=0 RESERVED; pixel_format!=1 FORMAT; palette_id!=1 PALETTE; dims != panel DIMENSIONS; payload_len != ceil(w*h/2) LENGTH; len != header_len+payload_len LENGTH; crc mismatch CRC.
Manifest lines: `panel <w> <h>`, `<file> <expected> <palette_id> <payload_len> [panel_override w h]`, `check_crc32 <hex>`, `full_size_crc32 <hex>`.
Full-size pattern: byte i = (LEGAL[(i*5)%6]<<4) | LEGAL[(i*3+1)%6], LEGAL = {0,1,2,3,5,6}.
</interfaces>
</context>
