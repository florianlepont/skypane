## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| device -> byos | token and MAC are authenticated; everything else the device sends is untrusted |
| byos -> fleet.db | the server-assigned type is the only authority |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-49-19 | Spoofing | device claims another type (hw_rev, headers) | mitigate | type resolved from fleet.db only; test with claiming header/body |
| T-49-20 | Tampering | fallback mode offers legacy binary to a fleet-only device | mitigate | legacy fallback only for MACs in devices.json; test |
| T-49-21 | Elevation of privilege | unknown/disabled sim type reaches an offer | mitigate | is_known and available_types checks; fail closed |
| T-49-22 | Information disclosure | /fw serves any registered hash to anyone | accept | unchanged by design (content-addressed public binaries); isolation relies on the offer and on device-side chip/project/signature checks |
| T-49-23 | Denial of service | SQLite read inside registry lock | mitigate | resolve once, before locks; tested |
| T-49-SC | Tampering | package installs | accept | none |
