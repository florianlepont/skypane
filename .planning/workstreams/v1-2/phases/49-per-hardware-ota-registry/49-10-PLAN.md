## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| signed image -> device | the device trusts the key of the image it currently runs |
| VPS -> device | a compromised VPS must not be able to install unsigned or foreign-signed code |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-49-29 | Spoofing | image signed by a wrong key published for a type | mitigate | embedded modulus compared with the type's expected key at publish time; espsecure verify in CI; device check is the real boundary |
| T-49-30 | Tampering | unsigned image published for a signed type | mitigate | signature sector required unless the type is explicitly declared unsigned (owner decision) |
| T-49-31 | Elevation of privilege | claim of device-side rejection never observed | mitigate | blocking human-verify checkpoint with recorded results; honest "not proven" statement otherwise |
| T-49-32 | Information disclosure | key material committed | mitigate | only public keys referenced; no key generation in this plan |
| T-49-SC | Tampering | package installs | accept | none; DER parsing is stdlib |
</threat_model>
