# Phase 68.1 Plan 12: Components page fit and catalogue entries (P12) Summary

The admin Components page no longer cuts off its Wake interval card or its unsaved-changes bar, and now shows the four families it lacked.

## What changed

- Tests first (`2a4ac376`): `companion/test_browser_components_fit.py`, 33 cases (EN and FR, Light and Dark, 360 and 1280 px, plus reduced motion). Red first for the missing samples and the clipping.
- Build (`c0f1163b`):
  - The measured "280 in 276px" of DEV-41 was not text: it was the 52px switch track of the third row, placed straight in the row, sticking 3px past the card. In `style-admin.css` a switch directly in a catalogue row now keeps its width (`flex: none`, margin like the page's form), so the text column shrinks.
  - The docked save-bar sample's message wraps (no ellipsis) in the catalogue only. At 1280px the sample was also degenerate (bar 34px wide, message 0px, because the page's `width: min(... 100% - 448px)` went negative); the sample bar now takes its sample's width.
  - New samples, built through the product helpers (`ui_components.card_status_class`, `fleet_tiles._tile` and `system_tiles_html`, `status_dot`): page section (plain, ok, warn, error), frame tiles by status, a linking tile and a wide tile, compact System tiles, and a "dots without a live signal" state with `.dot--off` (Resting) and `.dot--hollow` (Waiting for pairing), each beside its word. Seven new strings, French in `i18n_fr/components.py`.
- Skill (`02fabc94`): `components.md` no longer says the families are absent; SKILL.md "as of" line updated.
- Baseline (`regenerate`): only with `companion_render_snapshot.py --write`; 60 pages changed, all differences are the stylesheet `?v=` hash (verified by normalising the hash).

## Manifest and drift test

No token or documented value was added or changed: `design_system_tokens.json` and the drift test are untouched (drift test run, green).

## Deviations from Plan

- [Plan assumption] The long-label row ("A deliberately long label...") still ends in the row label's designed two-line clamp at 360px. That is the component's documented behaviour for long labels, not a cut sample, so the test does not assert it unclipped.
- [Rule 1] The 1280px docked-bar width defect above was found by the new test and fixed in the same task.
- `fleet_tiles._tile` is a private helper used from the catalogue page (no public helper draws a single non-link tile); the family's `helpers` list is unchanged because the catalogue spy test resolves only `companion.<module>` names.
- Compact tile anchors point at `#system-topic-components-*` ids that do not exist on this page.
