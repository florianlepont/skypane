# Phase 68.1 build-plan template (one approved proposal per plan)

Used by Plan 09 to generate `68.1-11-PLAN.md` onward. Copy the skeleton below, replace every `<...>`, delete this header. Generated plans are instantiated with the proposal's real files, mockup, EN and FR strings, selectors and tests; nothing is left as a placeholder.

## Sizing rule

One proposal per plan. At most 3 tasks. One small change each: if a proposal needs more, split it into option steps (as P16 does) but keep one plan and at most 3 tasks, or ask for a second plan before generating it. No page outside the proposal's "Pages affected" is touched.

## Wave rule (render baseline)

Every plan that regenerates `companion/testdata/render_baseline.json` is built in its own wave, strictly after the previous one: two such plans never run in parallel, they would both rewrite the same file and the hashes of every page (all pages link all nine stylesheets with a `?v=<hash>`, so any `style*.css` edit changes every baseline page). Generated plans start at wave 8; Plan 10 sits in a wave strictly greater than every generated plan's.
