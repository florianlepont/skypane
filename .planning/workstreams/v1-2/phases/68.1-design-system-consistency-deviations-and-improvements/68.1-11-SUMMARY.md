## Deviations from Plan

**1. [Plan assumption stale] The "23 TOKEN-EXISTS literals" no longer exist on main.** The scan on current main reports 4 spacing TOKEN-EXISTS findings and 0 font-size ones (Plans 03 to 05 already migrated the rest, including DEV-14 and DEV-16). Option A therefore changed 6 declarations, not 23. Two of them are not scan findings: the second literal of `padding: 0 12px 0 16px` and `max(16px, ...)` in `dialog.modal.modal--compact`, rewritten because they equal `--space-md`.

**2. [Plan acceptance not fully met] The scan still lists 4 spacing TOKEN-EXISTS findings and 1 radius one.** Each is deliberately left literal:
- `.update-item__notes` `calc(var(--space-md) + 8px + var(--space-sm))`: 8px is the width of a dot.
- `.health-row__body` `calc(var(--space-lg) + 32px + var(--space-md))`: 32px is the width of an icon.
- `li.entity-row` `calc(var(--space-md) + 12px + var(--space-sm))`: 12px is the width of a dot.
- `.home-state__dot` `calc((1.15em - 14px) / 2) ...`: 14px is the dot size.
- `.home-stats__bar` `8px 8px 4px 4px`: the plan keeps it literal; the scan reads only its first literal.
The plan's own truths keep "calc() geometry" literal, and writing a dot width as a spacing token would make the indent follow `--space-*` instead of the dot. The decision is recorded in the skill's Known exceptions.

**3. [DEV-07 not done] `.upload-type-chip` `999px` kept.** `--radius-pill` is 32px; the computed radius would change from 999px to 32px, which the no-computed-change rule forbids (the plan allowed leaving it with the reason recorded). The skill lists it.

**4. [Instrument limit] Python Playwright is not installed here.** The browser test file was collected and passes ruff and `test_suite_guards.py`; its browser tests error on the missing fixture, as every browser test does locally. Its JavaScript probes and control flow were mirrored one to one in Node Playwright (`304` checks, `0` failures after option B; before option B the only failures were the missing tokens). The existing drift test was mirrored the same way: 0 mismatches, including the 7 new tokens (57 scale checks per page). CI runs the real tests.

**5. [Branch] Work was committed on the worktree branch** (`worktree-agent-a0fccc940a1071c75`, required by the commit guard, based on `origin/main` `ef229d21`) and is pushed to `phase-68-1-p16-tokens`.
