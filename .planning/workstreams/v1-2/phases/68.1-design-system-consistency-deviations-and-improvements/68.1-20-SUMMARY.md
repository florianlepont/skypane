# Phase 68.1 Plan 20: Editor ask rows say it once (P09) Summary

The Editor's Missing illustrations list no longer repeats "No sighting yet: you pick the type in the dialog" on every airline with no sighting: the sentence is one caption above the list, and each such row shows one short action label ("Choose type" / "Choisir le type").

## What changed

- `airline_missing.py`: `ASK_TITLE` becomes the action label "Choose type"; `ASK_HINT` is rendered once as the section caption (existing `.section-caption` class, no CSS change) when at least one row asks for the type; the row drops its second line. Row buttons keep `airlines.missing_add_ask_aria` ("Add an illustration for <airline>, type to choose"), so the accessible name carries the airline.
- EN and FR strings in `companion/i18n_fr/airlines.py` (same two keys, new texts): caption "No sighting yet for the airlines marked "Choose type": pick the type in the dialog." / "Aucun passage observé pour les compagnies marquées « Choisir le type » : choisissez le type dans la fenêtre."
- No new CSS, token, route, table or cookie. No motion.

## Tests

- `companion/test_browser_airline_rows_once.py` (red first, 8 failures): EN/FR, Light/Dark, 360px, reduced motion emulated: the sentence occurs once and before the list; seven seeded ask rows show only the action label; each button's aria-label contains its airline; no overflow; rows at least 44px; caption and row text at least 4.5:1; no running animation.
- Existing tests updated because they asserted the old repeated sentence or the old label: `test_airline_missing.py` (row text, sentence counted once, FR), `test_browser_airline_missing.py` (row locator text), `test_browser_airline_missing_label.py` (the section now has exactly one caption between its label and the list).

## Manifest, drift test and baseline

No token or documented value added or changed: `design_system_tokens.json` and the drift test are untouched (drift test run, green). `companion_render_snapshot.py --write` produced no diff: the baseline pages do not render the section's rows or stylesheet changes.

## Verification

Access matrix, render baseline, golden render (both), Phase 47 freeze, drift test, the Phases 54/55/60 access tests: green (see the full-suite run in the P11 summary). ruff, mypy, function-size, comment-history: clean.

## Deviations from Plan

- The caption names the "Choose type" rows ("for the airlines marked ...") instead of the mockup's "for these airlines", because the list also holds family rows of airlines that do have sightings.
- The visible airline name of an ask row stays in the airline header above it (the row sits under that header); the row itself shows the action label and the button's accessible name carries the airline.
- STATE.md and ROADMAP.md not touched (shared PR branch). Draft PR is the existing PR #596.
