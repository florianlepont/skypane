# Phase 68.1 Plan 15: Account version line (P08) Summary

Account ends with one quiet caption, "SkyPane build 3f9c1ab", and under it "Tap to copy for support" / "Touchez pour copier (support)". A tap copies the line with the existing copy script; the copied word replaces the hint line in place.

## Build id source (stop-and-ask condition did not trigger)

`companion/build_info.py` `build_id()`: realpath of the module, then the name of the directory that holds the `companion` package; a 40-hex name gives its first 7 characters (lower case); else `SKYPANE_BUILD` (7 to 40 hex, strict `fullmatch`); else `dev`. Checked against `deploy/activate.sh` (`RELEASE_DIR=${SKYPANE_ROOT}/releases/${SHA}`, `CURRENT_LINK=${SKYPANE_ROOT}/current`) and `deploy/skypane-companion.service` (`ExecStart=/opt/skypane/venv/bin/python3 /opt/skypane/current/companion/app.py`): the description holds, so no deploy file is touched and `SKYPANE_BUILD` is set by none.

## Tests (red first, commit test(68.1-15))

- `companion/test_build_info.py` (14 cases): a symlinked release (`releases/<40-hex>/companion/` plus a `current` symlink, path given through `current`) gives the target's first 7 characters; plain release path; release wins over the environment; env 7 to 40 hex used outside a release; empty, short, non-hex, markup, quote, 41-char, leading space and trailing newline give `dev`; a non-hex release name is not a release.
- `companion/test_browser_account_version.py` (8 cases): at 360px, EN and FR, Light and Dark: 13px, no uppercase, no mid-dot, at least 44px high, contrast at least 4.5:1 of both lines (ink composited on its fill), no horizontal scroll. The id is the server's own and holds no `@` or token. A tap writes the version text to the clipboard, the label swaps to Copied/Copié and back, the line and the label stay inside the main column (`scrollWidth <= clientWidth`). Reduced motion: instant swap, no running animation.
