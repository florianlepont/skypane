## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser to companion | session-cookie holder chooses a device id in the path and posts forms |
| return_to / Referer | client-supplied redirect target |
| poll request to upstream providers | each poll issues provider requests |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-51-23 | Elevation of privilege | cross-device write (A's POST writing B) | mitigate | handlers take an explicit Device; byte-identical snapshot tests for dev_b and live after every POST type |
| T-51-24 | Information disclosure | unknown id as live frame; id existence oracle | mitigate | 404 after the session gate; unauthenticated callers get the unchanged login behaviour (test) |
| T-51-25 | Tampering | open redirect through return_to / Referer | mitigate | membership test against a fixed whitelist after prefix stripping; foreign prefixes rejected (test) |
| T-51-26 | Tampering | CSRF on device POSTs | mitigate | Origin/Sec-Fetch-Site gate stays the first statement of POST dispatch, before route matching and prefix handling (existing test_post_origin.py stays green) |
| T-51-27 | Information disclosure | live battery log leaking into a device | mitigate | caddy_log never passed for a device directory (spy test) |
| T-51-28 | Denial of service | one device's poll blocking others / provider spacing | accept | per-device lock and cooldown; global request budget is a later phase (documented gap: provider spacing state is per directory) |
| T-51-SC | Tampering | package installs | accept | none installed |
</threat_model>
