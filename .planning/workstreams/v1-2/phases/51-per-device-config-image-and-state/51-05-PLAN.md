<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL to route table | `/devices/<id>/...` path from an authenticated browser |
| URL id to filesystem | id is only a lookup key into fleet.db; the directory comes from the stored state_path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-51-18 | Tampering | `/devices/<id>` path traversal | mitigate | anchored regex on the raw path with `\Z`, no unquote before matching, tested with encoded slash, newline, uppercase and short ids |
| T-51-19 | Elevation of privilege | global route reachable under a device prefix | mitigate | only `device_scoped` routes match under the prefix; login, logout, theme, lang, static and update return no match (test) |
| T-51-20 | Information disclosure | unknown id served as the live frame | mitigate | find_device returns None; later dispatch returns 404; tested here at lookup level |
| T-51-21 | Information disclosure | Device exposing MAC or token | mitigate | Device namedtuple has no such fields; fleet list query already excludes tokens |
| T-51-22 | Denial of service | lock registry | mitigate | registry lock is a leaf held only for dict access; per-device lock never shared |
| T-51-SC | Tampering | package installs | accept | none installed |
</threat_model>
