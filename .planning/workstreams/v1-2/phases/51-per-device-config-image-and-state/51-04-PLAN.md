<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| frame to BYOS | bearer token and headers from an untrusted network client |
| unauthenticated /img route | URL path chooses which device directory is read |
| fleet.db row to filesystem | stored state_path is turned into a path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-51-12 | Spoofing | _authenticate_device | mitigate | constant-time compare against every candidate, no early exit; unresolved token or MAC without a row is 401; test with spy |
| T-51-13 | Information disclosure | fallback to the live image | mitigate | explicit 401/503 on every resolution failure; test that a non-live device with a missing panel never receives --image bytes |
| T-51-14 | Information disclosure | /img/<id>/<sha>.bin | mitigate | id regex on the raw path, id looked up in fleet.db, directory from validated state_path, only that directory's img/ is read, no search across directories; 256-bit hash; route stays unauthenticated only because content is non-secret (unchanged rule) |
| T-51-15 | Tampering | state_path traversal | mitigate | `device_dirs.resolve_state_dir` on every read; tampered row yields 503 (test edits the row) |
| T-51-16 | Denial of service | health write failure | mitigate | best-effort, exceptions swallowed, response unchanged |
| T-51-17 | Information disclosure | token or secret in logs | mitigate | log the device id only; no token, secret or MAC secret printed (test greps captured output) |
| T-51-SC | Tampering | package installs | accept | none installed |
</threat_model>
