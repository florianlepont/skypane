| Boundary | Description |
|----------|-------------|
| `?device=` query parameter | client text drives a redirect |
| device names to HTML | names come from fleet.db and are rendered into option text and the page title |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-51-36 | Tampering | open redirect through `?device=` | mitigate | value matched against `live` or the id regex and looked up in fleet.db; location built from the fixed page path plus the validated id; anything else is a 404 (tests with `//evil`, absolute URLs, encoded slashes) |
| T-51-37 | Tampering | stored XSS via device name in option text or title | mitigate | `escape_html` on name, id and title; test with a name containing markup |
| T-51-38 | Information disclosure | MAC/token/secret in selector | mitigate | Device has no such fields; test greps the page for the fixture's MAC, token and secret prefix |
| T-51-39 | Information disclosure | existence oracle for unauthenticated callers | mitigate | switch hook runs after the session gate |
| T-51-SC | Tampering | package installs | accept | none installed |
</threat_model>
