<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fleet.db row to filesystem | `state_path` becomes a directory the BYOS and companion read and write |
| CLI argument to row | `--state-path` is operator input stored in the database |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-51-01 | Tampering | device_dirs.resolve_state_dir | mitigate | shape regex with `\Z`, realpath containment under root/devices, symlinked directory rejected; tested with "..", absolute, newline, symlink cases |
| T-51-02 | Tampering | fleet_db.add_device state_path | mitigate | only "." or "auto" accepted; unsafe value raises before INSERT; read side re-validates through resolve_state_dir |
| T-51-03 | Information disclosure | provision_device_dir | mitigate | writes only config and panel inside the validated directory through atomic_write; never copies the live frame's files |
| T-51-04 | Tampering | partial provisioning | mitigate | provisioning inside the CLI transaction so a failure rolls the row back |
| T-51-SC | Tampering | package installs | accept | no package is installed in this phase (stdlib, Pillow, requests already pinned) |
</threat_model>
