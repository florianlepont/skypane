## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-55-01-01 | Elevation of privilege | `_handle_settings_post` mass assignment (wake interval, LED, runway, scope=all) | mitigate | `sanitise_settings_form` strips the fields and forces scope server-side; Test 2 posts the crafted body |
| T-55-01-02 | Information disclosure | Health page, nav dot, Home attention row, freshness token leaking platform state | mitigate | all four gated by `platform_visible`/frame-only severity; Tests 3 to 5 |
| T-55-01-03 | Information disclosure | admin-only controls present in served bytes | mitigate | sections omitted at render, tests assert absence in markup |
| T-55-01-04 | Tampering | role read from a request value | accept | role comes only from the resolved principal (`prefs`), set by the dispatcher from the local users row |
| T-55-01-SC | Tampering | package installs | accept | no package is added in this plan |
</threat_model>
