<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| frame -> byos `/device/v1/setup` and `/display` | MAC + secret + bearer token authenticate; everything else is untrusted |
| unauthenticated `GET /img/p_<id>/<sha>.bin` | content-addressed, hash unguessable |
| CLI operator -> fleet.db | trusted but must never receive a raw secret |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-55-07-01 | Spoofing | pending enrolment by a MAC that is not registered | mitigate | unchanged 403/401 model; registry merge only includes registered pending rows |
| T-55-07-02 | Information disclosure | pairing code visible in the served image URL space | accept | the code is meant to be shown on the panel; the image hash is sha256 of 960 kB pixels, files not listable; 30 min TTL; documented in hand-off |
| T-55-07-03 | Tampering | pending frame polluting live state (img/, battery_state.json, legacy files) | mitigate | separate `pairing/<pid>/` tree; Tests 7 and Task 3 Test 5 |
| T-55-07-04 | Tampering | path traversal through `/img/p_.../` | mitigate | strict anchored regex with `\Z`, content-addressed names, Test 8 |
| T-55-07-05 | Denial of service (battery) | redraw churn from a varying image | mitigate | deterministic image; hash stable until rotation (Test 3) |
| T-55-07-06 | Elevation of privilege | CLI assign bypassing the wipe | mitigate | assign routed through `fleet_ops.reassign_frame` |
| T-55-07-07 | Information disclosure | secrets/tokens/codes in backups of pairing images | mitigate | `pairing` excluded; fleet.db rows hold hash/salt only |
| T-55-07-SC | Tampering | package installs | accept | none added |
</threat_model>
