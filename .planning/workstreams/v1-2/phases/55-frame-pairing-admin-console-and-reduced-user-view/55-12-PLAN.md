## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin POST -> user table | role and enablement control all other access |
| invited email -> Auth0 first sign-in | the invite pre-authorises an identity |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-55-12-01 | Elevation of privilege | role change by non-admin or forged request | mitigate | admin-only routes, `csrf=True`, role read only from the local row |
| T-55-12-02 | Denial of service | last-admin lockout, self-disable, concurrent demotion | mitigate | guards in one BEGIN IMMEDIATE transaction (plan 02) and two-thread HTTP tests |
| T-55-12-03 | Elevation of privilege | disabled user keeps a live session | mitigate | session rows deleted in the same transaction; next request refused (Test 3) |
| T-55-12-04 | Spoofing | invite for an attacker-chosen email | accept | admin-only, audited; Auth0 sign-ups are disabled (owner checklist) so the invite is the only way in |
| T-55-12-05 | Repudiation | untraced user changes | mitigate | audit row per action in the same transaction, denied rows standalone |
| T-55-12-06 | Information disclosure | iss/sub or session data on the page | mitigate | never rendered; Task 1 Test 5 |
| T-55-12-SC | Tampering | package installs | accept | none added |
</threat_model>
