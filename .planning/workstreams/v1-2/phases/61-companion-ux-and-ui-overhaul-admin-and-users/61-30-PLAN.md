## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| query string (chip, sort, q) to rendered page | untrusted text |
| stored event text (airline, callsign, aircraft type) to HTML | data from external ADS-B sources |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-61-30-01 | Tampering (XSS) | airline names, callsigns and types from stored events | mitigate | every value escaped with escape_html; dialog ids are slugs derived from the normalised key, never raw text; tests with hostile strings |
| T-61-30-02 | Elevation of privilege | a user reaching airline editing from the collection | mitigate | the page renders no form, file input or /airlines/... link; the five POST routes are administrator-only (plan 61-17); tests post as a user and expect 404 |
| T-61-30-03 | Information disclosure | another frame's history | mitigate | the read model uses the request-scoped connection of the authorised frame only |
| T-61-30-04 | Denial of service | grouped query over a large history | accept | indexed ts column, one grouped read per request, read-only; measured on the seeded fixture |
| T-61-30-SC | Tampering | package installs | accept | none installed |
</threat_model>
