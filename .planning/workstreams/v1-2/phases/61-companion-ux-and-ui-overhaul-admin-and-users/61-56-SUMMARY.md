## What changed

- **Font stacks (CI fix from 61-55).** "Inter" and "Inter Display" are gone from `--font-ui`/`--font-display`; the tails are `"Segoe UI", Roboto, "Helvetica Neue", Helvetica, Arial, system-ui, sans-serif`, so Linux resolves to Liberation Sans on this machine and on the GitHub runner alike (this sandbox has Inter installed, which is why the six French tests passed locally and failed in CI). Reproduced the six tests by forcing "DejaVu Sans"; with the new stack all pass. Wide-font hardening of the six layouts was not done (they only break with DejaVu, which the stack no longer selects).
- **One glass tier.** `--glass-bg` white 0.72 (Light) / 0.09 (Dark), `--glass-border`, `--glass-highlight` (inset top edge), `--shadow-glass`, `--glass-blur` 22px with `--glass-saturate` 165%, `--glass-solid` fallback, `--glass-hairline`. `--glass-bar-bg` is removed: sidebar, tab bar, phone header, save bar, sheets, dialogs, popovers, tables, groups, cards and segmented tracks all use `--glass-bg` inside the one `@supports (backdrop-filter...)` block, each keeping a solid base fill outside it. Blur is on groups, dialogs, sheets, popovers, bars and the sidebar only.
- **Legacy beige removed.** `--color-secondary` is `#E9EEF5` and `--color-border` `#DAE1EB` in Light; frame fold (inset gradient dropped), space switch, filter chips, Personalisation nav, look picker, Location modes, More panel, Place card, users table, info tooltip and row menu take the glass tier. Segmented controls get a glass track and a graphite (ivory in Dark) selected pill with the on-accent label (the Personalisation thumb stays under a link filled with the same colour).
- **Components.** `companion/ui_groups.py`: `section_label`, `group`, `group_panel`, `row`, `hero`, `chip_html`; CSS `.group-block`, `.section-label`, `.group`, `.row`/`.row__main|chip|text|label|detail|value|chevron`, `.hero`. Rows are 54px, link/button/plain, 32px chip with `--radius-chip` 9px, hairline separators, focus ring, trailing controls beside (never inside) the link, label clamped to two lines, value one line with an ellipsis (max half the row). Documented in `61-UI-SPEC.md` ("Surfaces and components").
- **Home.** Hero (current picture beside the state word and dot, detail, next update, battery dial for administrators), then the Frame group (Screen and Quiet hours switch rows, the quiet window still opens the existing dialog), then the Recent flights group (one row per flight linking to Flights, a "See all flights" row; empty state inside the group). With no picture the "Current frame" empty state is one panel group. Notification position under the title, greeting, plane and trail untouched; every `home-state*`, `home-switch*`, `home-flights`, `home-frame-state`, `home-facts` id/class hook and the switch ARIA wiring is kept. The Frame group sits before Recent flights (not after as in g1.png) so the schedule and switches stay above the fold on a phone: the step-count test U4a (3 actions) fails otherwise. The freshness swap registry (`freshness.js` and `ui_nav.REFRESH_SWAP_SELECTORS_BY_PAGE`) gained the Frame group.
- **Fleet State.** The health rows keep their native `<details>`; from a 420px container the name and verdict stack in one column beside the value, which wraps and takes at most half the row (the old five-column layout with a 208px name column squeezed the verdict at ~600px containers). The audit's overlap did not reproduce in the seeded 1440px page (it only showed in a narrower single-column window); the new test covers 360/1000/1280/1440 in EN/FR.
- **Notification banner.** `.toast--docked` (Home notice and attention row, plus the other docked toasts) is a glass banner with page ink in both themes, a 32px amber/red icon chip and the 44px underlined contact link; the floating flash toast keeps its inverse surface.
