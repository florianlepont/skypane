<objective>
Put the CI on a free self-hosted runner on the owner's Mac with a one-line fallback to GitHub-hosted runners (D-05, D-06), and record the reduced-CI decision (D-07).

DEVIATION FROM D-07 FOR THE OWNER TO SEE: D-07 asks for path-based job splitting. Research measured that it saves almost nothing safely: 22 of the last 52 commits are docs-only (already skipped), of the other 30 only about 2 touch no test-relevant path, 28 test files read `firmware/`, and `scripts/ci_gates.py` has an executed-test floor of 12,821, a skipped ceiling of 0 and a whole-suite coverage floor that any skipped shard group would trip. This plan therefore keeps the docs-only skip, adds NO test-skipping `changes` job and weakens no gate; the savings come from the runner. The measured before and after minutes and this finding are recorded in plan 70-07. If the owner still wants path splitting, it is a separate plan that must default to run-everything and adjust the gates.

Output: workflow `runs-on` change, sudo/apt steps guarded for hosted-only, a stdlib-free shell launcher with tests, a Lima VM definition, and an install and isolation runbook. Installing the runner on the Mac is the owner's step in 70-07.

Delivery: draft PR based on `main`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| branch code -> Mac VM | sessions' branches and Dependabot PRs execute on the owner's Mac |
| VM -> macOS host | must stay closed (no mounts, no socket) |
| admin token -> GitHub API | token with Administration scope exists on the host only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-70-20 | Elevation | malicious branch escapes to the Mac or reads host files | mitigate | Linux VM with `mounts: []`, no forwarded socket or agent, unprivileged runner user, single-use JIT runners, work folder wiped |
| T-70-21 | Information disclosure | admin token reachable from the VM | mitigate | token only in macOS Keychain, sent via curl stdin config, test asserts it is absent from VM command and environment |
| T-70-22 | Elevation | fork pull request runs on the runner | mitigate | job condition requires head repo equals this repo; no `pull_request_target`; test asserts; repository has no collaborators |
| T-70-23 | Denial of service | Mac off or asleep, jobs queue | accept | documented fallback `gh variable delete CI_RUNS_ON`; hosted cost explained |
| T-70-24 | Tampering | runner tarball substituted | mitigate | README requires verifying the published SHA-256 |
| T-70-25 | Repudiation | a self-hosted charge appears later | accept | cost watch recorded with the date, re-checked before the flip |
| T-70-SC | Tampering | package installs on the VM | mitigate | only distro packages and the official actions/runner tarball with checksum; no new Python or npm package |
</threat_model>
