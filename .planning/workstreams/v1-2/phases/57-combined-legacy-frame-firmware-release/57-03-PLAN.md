<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server -> device download | Body bytes cross into a PSRAM buffer, then the parser, then the panel |
| device -> server headers | Request headers announce capability and type |
| CI -> signed image | Compile happens in CI; signing only in the gated release job |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-57-09 | Tampering | download buffer | mitigate | Hard read cap FP_IMAGE_BUF_BYTES, plausibility window, SHA-256 over all bytes before parse, imgc_parse before any draw |
| T-57-10 | Denial of service | unreachable frame after bad container | mitigate | Sticky flag stops announcing so raw image returns; unconfirmed trial rolls back; verified only on bench (see plan 05) |
| T-57-11 | Information disclosure | stale headers on shared HTTP handle | mitigate | clear_request_headers deletes both names; download never carries them |
| T-57-12 | Tampering | wrong hardware key compiled in | mitigate | check_hw_type_key.sh compares Kconfig, defaults and server LEGACY_KEY; invalid value sends no header |
| T-57-13 | Elevation of privilege | unsigned image easy to flash | mitigate | No artifact upload added; flash.sh refuses unsigned images |
| T-57-SC | Tampering | package installs | accept | No packages installed |
</threat_model>
