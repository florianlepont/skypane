<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| aggregator response -> select | untrusted aircraft records, now shared by many devices |
| state_dir argument -> filesystem | the cycle reads/writes under a directory chosen by the caller |
| shared ZoneFetch -> every device in zone | one malformed/poisoned result could affect all devices in a zone |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-52-15 | Tampering | ZoneFetch results | mitigate | Selection still runs runway_candidates/filter_in_geofence per device on the shared lists; query_provider already drops non-dict records and validates shape; corroboration across two providers unchanged |
| T-52-16 | Elevation of privilege | state_dir path | mitigate | run_once never derives paths from request text; the fleet loop (52-05) resolves directories only through device_dirs.resolve_state_dir; peek_hold performs no mkdir and takes the directory as given |
| T-52-17 | Denial of service | standalone fetch bypassing budget | mitigate | The only live-fetch branch goes through RequestLedger; test asserts spacing across back-to-back cycles |
| T-52-18 | Tampering | removal of provider_last_call bookkeeping breaks previous release | mitigate | Constant kept, no schema change; previous release treats a missing meta key as "no previous call" (documented tolerant loader) |
| T-52-19 | Information disclosure | peek_hold side effects | mitigate | Read-only by test (listing and mtimes unchanged); no lock taken |
| T-52-SC | Tampering | package installs | accept | No new dependency |
