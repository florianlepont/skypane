Create `server/request_budget.py` (stdlib only, fully type-annotated so it can join the mypy list later) per decisions D-01, D-05, D-06, D-14.

Module constants: `LEDGER_FILENAME = "request_ledger.json"`, `LOCK_FILENAME = "request_ledger.lock"`, `MIN_SPACING_S = 1.1` (a test asserts it equals `detect.MIN_SECONDS_BETWEEN_CALLS`), `PROVIDER_PAUSE_S = 60.0`, `LOCK_WAIT_S = 5.0`, `MAX_ZONE_ENTRIES = 256`, `MAX_ZONE_KEY_LEN = 128`. Exception `BudgetUnavailable(RuntimeError)`.

Class `RequestLedger(root, clock=None, sleep=None, spacing_s=MIN_SPACING_S)`: `clock`/`sleep` resolve to `time.time`/`time.sleep` inside `__init__` at call time (not default-argument values) so patched time is honoured; `spacing_s` exists so a multi-process test can use a short spacing. Both files live directly in `root` (fixed names, no caller text in any path).

Methods:
- `acquire(provider) -> bool`: take `atomic_io.exclusive_lock(<root>/request_ledger.lock, LOCK_WAIT_S)` (translate `LockBusy` into `BudgetUnavailable`); read the document tolerantly; if the provider's pause_until is in the future return False without stamping; otherwise compute wait = clamp(last_request_at + spacing_s - now, 0, spacing_s) treating a non-finite or missing last_request_at as "none", sleep the wait WHILE HOLDING the lock (the wait is at most 1.1 s, and holding the lock is what makes spacing exact across processes), then store last_request_at = clock() and persist atomically before releasing, and return True. The caller makes the HTTP request after acquire returns, outside the lock.
- `report_failure(provider)`: under the lock set pause_until = clock() + PROVIDER_PAUSE_S for that provider (only providers present in `detect.PROVIDERS` are accepted; others ignored) and persist.
- `paused_until(provider) -> float | None`: clamped, tolerant read for diagnostics.
- `zone_last_served() -> dict[str, float]` and `mark_zone_served(zone_key, when)`: the per-zone aging map used later for oldest-served-first ordering; bounded as in the behaviour list.

Document format is JSON `{"version": 1, "last_request_at": float, "providers": {name: {"pause_until": float}}, "zones": {key: float}}`. Parsing is a pure helper that sanitises every field (finite floats only, bool excluded, clamps against the current clock: last_request_at capped at now, pause_until capped at now + PROVIDER_PAUSE_S) and drops unknown providers; writes use `atomic_io.atomic_write(..., mode=0o600)`. A write failure (OSError) propagates as BudgetUnavailable from acquire so no request is made when the budget cannot be recorded.

Lock-order invariant (state it in the module docstring): the ledger lock is a leaf lock, never held while taking poll.lock or any other lock, and never held across a network call. Keep every function at or under 80 code lines. Comments describe what and why only; no plan, phase or decision identifiers (scripts/check_comment_history.py check must pass). Expand-only: this file is new, fleet.db and history.db are not touched, and the previous release ignores it.

Tests (`server/test_request_budget.py`) use a fake clock whose `sleep` advances it, `tmp_path` roots, and cover every behaviour bullet above, including two RequestLedger instances on one root and a pair of threads sharing one fake clock whose recorded request times are pairwise at least 1.1 s apart. Assert behaviour (return values, recorded clock readings, file mode via os.stat), never source text.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-52-01 | Tampering | request_ledger.json content | mitigate | Pure sanitiser: finite floats only, bool/str/NaN/inf rejected, last_request_at capped at now, pause_until capped at now + 60 s, unknown providers dropped, zone map bounded to 256 entries and 128-char keys; malformed JSON equals empty ledger |
| T-52-02 | Denial of service | stale/hostile pause or last_request in the future | mitigate | Wait clamped to 1.1 s, pause clamped to 60 s, so a hand-edited or clock-skewed file cannot stall the unit past its 90 s timeout |
| T-52-03 | Denial of service | retry storm after a provider outage | mitigate | Failure or 4xx/429 persists a 60 s pause shared by every process; failed request still stamps the spacing; no in-process retry |
| T-52-04 | Elevation of privilege | path built from input | mitigate | Ledger and lock filenames are module constants joined to the caller-supplied root only; no device or request text reaches any path |
| T-52-05 | Information disclosure | ledger permissions | mitigate | Files created 0600 via atomic_write/exclusive_lock; ledger holds no secrets, only times and provider names |
| T-52-06 | Repudiation/abuse | exceeding adsb.fi 1 req/s personal-use limit | mitigate | Global 1.1 s spacing under flock held across the wait; airplanes.live rejected in fetch_zone |
| T-52-SC | Tampering | package installs | accept | No new dependency: stdlib plus existing requests only |
