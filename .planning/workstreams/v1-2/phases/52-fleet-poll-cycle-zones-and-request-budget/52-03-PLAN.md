Deduplicate adsbdb lookups across devices through a shared, root-level callsign cache (decision D-13), without touching the per-device enrichment cache or the TTLs.

Output: `server/plane/shared_route_cache.py` and tests.

  <behavior>
    - First call for callsign "AFR123" invokes the inner transport once and returns its (status, body); a second call (same instance, a new instance, or a different root-sharing instance) returns the stored (status, body) without invoking the inner transport.
    - A 404 is shared with the negative TTL (expires after CACHE_MISS_TTL_S, tested with an injected clock); a 2xx with the positive TTL.
    - 429, 500, 403 results and a raised exception from the inner transport are returned/propagated unchanged and nothing is written.
    - Invalid callsigns (not matching ^[A-Z0-9]+$ after normalisation) bypass the cache and go to the inner transport unchanged (enrich still rejects them).
    - Body larger than ADSBDB_MAX_BYTES is not stored; more than CACHE_MAX_ENTRIES entries evicts least-recently-stored first; corrupt/non-dict JSON file loads as empty; a lock timeout or OSError falls back to calling the inner transport directly (a cache fault must never fail a cycle).
    - The stored body is a UTF-8/bytes-safe representation round-tripped losslessly (store text via base64 or JSON string, as the inner body type requires).
    - File mode 0600; filename is the module constant under the root.
  </behavior>
  <action>
Create `server/plane/shared_route_cache.py` (stdlib only; annotate fully) implementing D-13. `SharedRouteTransport(root, inner=None, clock=None)` is callable as `(callsign, timeout) -> (status_code, body)` so it plugs into `enrich.resolve_route(transport=...)`. `inner` defaults to `enrich.default_transport` looked up at call time. Cache file `SHARED_CACHE_FILENAME = "adsbdb_shared_cache.json"` in `root`, guarded by `atomic_io.exclusive_lock` on a sibling lock file with a short wait (2 s); the inner HTTP call is made OUTSIDE the lock (take lock, check, release; call; take lock, store, release) so one slow lookup never blocks other devices. The lock is a leaf lock (never held while taking poll.lock or the request ledger lock, never across network I/O).

Per-entry shape `{"status": int, "body": <text or base64>, "stored_at": float}`; reuse the enrich TTL constants (do not copy numbers) and `enrich.normalise_callsign`. Only status 404 and 200-299 are stored. Tolerant loader (non-dict -> empty, bad entries dropped, non-finite stored_at dropped, stored_at in the future treated as stale). Writes atomic, mode 0600, bounded to `enrich.CACHE_MAX_ENTRIES`. Any OSError/LockBusy falls back to the inner transport result.

Tests (`server/test_shared_route_cache.py`) use a counting fake inner transport, tmp_path roots and an injected clock; two `SharedRouteTransport` instances on one root stand in for two processes. No real network (pytest-socket guard). Comments contain no plan/phase/decision identifiers; functions under 80 lines.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-52-11 | Tampering | callsign into key or path | mitigate | Callsign normalised and restricted to ^[A-Z0-9]+$ before it is a cache key; invalid values bypass the cache; file path is a module constant |
| T-52-12 | Tampering | cache poisoning by editing the file | mitigate | Loader validates shapes, drops bad entries; enrich._parse_route still validates every body on use; the file is 0600 and only the skypane user writes it |
| T-52-13 | Denial of service | unbounded growth / lock stall | mitigate | Entry count capped at 300, body capped at 256 KiB, lock wait 2 s then fall back to a direct lookup, network call outside the lock |
| T-52-14 | Information disclosure | negative-cache of transient failures | mitigate | Only 404 and 2xx stored; 429/5xx/other 4xx never stored |
| T-52-SC | Tampering | package installs | accept | No new dependency |
