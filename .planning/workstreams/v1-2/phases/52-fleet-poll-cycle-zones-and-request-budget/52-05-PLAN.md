<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fleet.db row -> filesystem path | `state_path` comes from the database (editable by the admin tooling and, later, by other phases) and selects a directory the service writes |
| device directory contents -> loop | config/state files per device are user-influenced (companion saves) |
| fleet size -> process time | a large fleet could run the unit past its 90 s timeout |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-52-20 | Elevation of privilege | state_path traversal | mitigate | Directories only via device_dirs.resolve_state_dir (shape check, realpath containment, symlink refusal); invalid row skipped and logged; tests with `devices/../x` and a symlinked directory |
| T-52-21 | Denial of service | retry storm / budget exhaustion by many zones | mitigate | Single ledger spacing; failure pause 60 s shared; no in-cycle retry; unserved zones age and are served oldest-first next cycle |
| T-52-22 | Denial of service | unit killed at 90 s with torn state | mitigate | 25 s start deadline, bounded per-provider deadlines, all state writes already atomic; deferred devices untouched |
| T-52-23 | Denial of service | one device's failure blocking others | mitigate | Per-device and per-zone try/except, PollBusy isolation, tests asserting later devices still run |
| T-52-24 | Information disclosure | logs | mitigate | Summary lines carry device ids and counts only, never MACs, secrets, tokens or coordinates |
| T-52-25 | Tampering | live frame image/state regression | mitigate | Live frame still uses the root directory with the same cycle steps; integration test compares panel bytes with a direct run_once; Phase 47 freeze test run |
| T-52-26 | Spoofing/abuse | provider terms | mitigate | Only adsbfi and adsblol, sequential, 1.1 s global spacing, both unchanged by fleet size |
| T-52-SC | Tampering | package installs | accept | No new dependency |
