## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-65-01 | Information disclosure | device_photos metadata in fleet.db | mitigate | store only random id, sizes, dimensions, uploader id, time; no names; docs record that counts and timestamps are visible to anyone reading fleet.db |
| T-65-02 | Tampering | photo id / device id in SQL | mitigate | parameterised queries only; id CHECK constraint at the schema level |
| T-65-03 | Denial of service | FK blocking remove_device / park_retired | mitigate | rows cleared before the devices DELETE; tests remove a frame that has photos through both paths |
| T-65-04 | Information disclosure | audit detail leaking photo ids | mitigate | audit_photo_purge takes a count and a cause only; test asserts no photo id in detail |
| T-65-05 | Tampering | migration on live database at deploy | mitigate | expand-only CREATE TABLE/INDEX; upgrade test proves existing rows unchanged; rollback caveat (older release refuses v5) goes into the docs in plan 07 |
</threat_model>
