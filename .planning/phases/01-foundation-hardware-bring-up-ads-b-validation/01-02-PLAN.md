<objective>
Prove the device poll protocol end to end on the developer's laptop, before any hardware exists, by standing up the local stub server (per D-09) and a host-side harness that walks the entire wake-cycle contract: setup, authenticated poll, download, SHA-256 verify, exact 960,000-byte size check, hash-skip, and rejection of a corrupted payload.

This is the software half of the Walking Skeleton. The harness plays the part the firmware will later play, so the protocol contract is nailed down and green while hardware is still in transit (per D-08). When plan 01-05 flashes the real device it points at exactly this server, so any mismatch is a firmware bug rather than an unknown.

Purpose: DEVICE-03's "polls the server, downloads and displays a new image if available" is a contract between two sides. Getting one side provably correct with zero hardware collapses the search space when the real device first misbehaves.
Output: A runnable stub server, a deterministic panel-image generator, and a one-command end-to-end contract harness.
</objective>
