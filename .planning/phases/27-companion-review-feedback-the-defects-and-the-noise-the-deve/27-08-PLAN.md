<objective>
Two small corrections, both of which are traps if done the obvious way.

**Correction 6 — the link.** The Quiet hours card already tells the reader where the
switch is. The reverse does not exist: standing at the Frame strip's Quiet hours
switch, there is no way to the schedule fields. The fix is an anchor.

The trap is that `layout.frame_strip_html()` is a **shared component rendered on more
than one page**, and the obvious way to add "a link on Display" is to add it where
Display is built. That forks the strip, and a forked shared component is two
components that will disagree later. There is one write site and the link goes there
— and the cell's `caption_row_html` slot **already exists and is already used** by the
delay caption, so this is an append, not a new slot.

**The carried-in hit area.** `.copy-btn` measures **34×26** in a Flights detail row
against the project's 44 px floor. The trap is recorded in the stylesheet's own
comment: **`.row-toggle` reuses `.copy-btn`'s values verbatim.** Enlarging `.copy-btn`
moves `.row-toggle` with it, in a different container, where nobody measured
anything. So both get measured, each in its own container, or the fix is scoped so it
cannot reach the other.
</objective>
