<objective>
CMP-04: replace page_context()'s god dict (_LazyContext, a dict subclass read with ctx["key"] /
ctx.get("key")) with a typed PageContext, preserving every Phase 38 laziness/sharing invariant
byte-for-byte in behaviour; and finish app.py's CMP-03 item by moving the context builder out.

Typed-context shape (Claude's discretion per CONTEXT): one PageContext class per request, built
for the page being rendered, with explicitly declared eager and lazy fields and attribute
access; each page's render()/handle_post() is annotated `ctx: PageContext`. Plain mappings (used
by several hundred existing unit-test call sites) are converted at each public ctx-taking entry
point by page_context.coerce(), which rejects unknown keys — so a typo in a test ctx fails
loudly instead of reading None.

before starting, run `git fetch origin && git log --oneline HEAD..origin/main`; if it lists

companion imports to shared state_store / battery / quiet-hours modules). If the merge changes
any rendered page (test_render_baseline.py fails right after the merge), stop and report rather
than regenerating the baseline.
