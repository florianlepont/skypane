## Accomplishments

- Added `server/plane/illustrations.py::target_variants_by_airline()`, a third public read-only accessor grouping `_ILLUSTRATION_TARGETS` by airline (first-appearance order, non-`None` shapes only) — 27 pairs, matching `target_airline_names()`'s order/length exactly, with Air Caraïbes' three-shape list (`a330`, `a350-1000`, `atr72`) and Air France's empty (not `[None]`) list both verified. `server/test_illustrations.py` grew 47→52 checks.
- Added `GET /illustration/{key}.png`: `companion/app.py` gains `ILLUSTRATION_IMAGE_ROUTE_PREFIX`, a module-level `_ILLUSTRATION_FILENAMES` frozenset (computed once from `illustrations.target_filenames()` at import), and `Handler._serve_illustration_image()`, mirroring `_serve_runway_image()`'s validate-then-join shape statement-for-statement — membership test first, `illustration_path_for_key()` only after, identical 404 on both failure modes. Dispatched inside the `require_session()`-gated region of `do_GET`, never the pre-auth static-asset list. `companion/test_companion_app.py` grew 88→92 checks (real key, unknown key, three adversarial traversal paths, unauthenticated redirect).
- Added `companion/static/panel-lookup.js` (D-20): an ES5-safe IIFE resolving `#panel-lookup-dialog` (early-return if absent or `showModal` unsupported), a delegated `document` click listener performing a manual ancestor walk (no `Element.closest`) to find the nearest `data-view-panel-src` element and populate the dialog's image/caption before calling `showModal()`, and a `data-view-panel-close` click handler calling `close()`. No Escape handler or focus-management code — the native `<dialog>` already provides both, per UI-SPEC §8.3's own reasoning, stated in a comment. `companion/app.py` gained `PANEL_LOOKUP_SCRIPT_ROUTE`/`_PANEL_LOOKUP_JS_PATH`/`Handler._serve_panel_lookup_script()`; `companion/layout.py` gained `PANEL_LOOKUP_SCRIPT_SRC` and a sixth deferred `<script>` tag in `page_shell()`. `companion/test_companion_app.py` grew 92→96 checks.

## Decisions Made

- Materialised `_ILLUSTRATION_FILENAMES` as a module-level constant computed once at import (`_illustration_filenames()` calling `illustrations.target_filenames()` wrapped in `frozenset`) rather than recomputing per request, per the plan's explicit "one closed, server-controlled list" instruction.
- Added a defensive `None` guard on `illustration_path_for_key()`'s return value in `_serve_illustration_image()` before `open()` — a key that has already passed the membership test can never actually produce `None` from that function, but the guard costs nothing and keeps the byte-serving path from ever raising `TypeError` on an unexpected future change to either function (Rule 2, out of the plan's literal text but consistent with its "never a substitute for the membership test" framing).
