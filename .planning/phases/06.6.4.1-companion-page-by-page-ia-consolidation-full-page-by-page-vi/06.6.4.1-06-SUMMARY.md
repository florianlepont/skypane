## Accomplishments

- Rewrote `airlines_page.py`'s module docstring and imports for the gallery; added `ILLUSTRATION_ROUTE_PREFIX` (duplicated-not-imported against `app.py`'s own constant, pinned by a cross-module equality check), `GALLERY_PURPOSE_TEXT`, `CARD_IMAGE_ALT_TEMPLATE`, `variant_chip_label()`, `_airline_card_html()`, and `_gallery_grid_html()` — `render()` now emits `page_header("Airlines", ...)` followed by one `.airline-card` per `illustrations.target_variants_by_airline()` pair (27 against today's data).
- `variant_chip_label()` classifies a shape string by its own form (a `^[a-z]+\d[\d-]*$` letter-prefix-plus-digits pattern for type codes, everything else as a word-form manufacturer shape with its trailing model number split into its own word) rather than testing `SHAPE_SLUGS` membership — the trap the plan named, since `"a350-1000"` is not itself a `SHAPE_SLUGS` member and such a test would silently drop it. Verified: Air Caraïbes' card renders exactly `[A330, A350-1000, ATR72]`; Embraer/Beechcraft-1900D shapes word-case.
- Added a gallery-variant filter bar (D-16): reused `companion/static/list-filter.js`'s shared attribute contract verbatim (zero script changes), with History's real `<button type="button" data-filter-clear>` Clear control rather than the old read-only page's anchor-link variant — D-16's read-only constraint no longer applies to this page. Every card carries `data-filter-text`/`data-filter-group` so the shared script's per-group counting stays accurate.
- Deleted every migrated diagnostics symbol from `airlines_page.py` after confirming each one's live counterpart already exists in `health_page.py` (plan 04): the coverage/stats copy constants, `_safe_query()`, `unresolved_rows()`, `coverage_status()`, `resolution_stats()`, the old registry row/table/section builders, the resolved-rate headline builder, and the statistics table builder — along with the now-unused `history_db`/`poll_loop`/`sqlite3`/`datetime` imports.
- Pinned both plan-level non-goals with test guards rather than leaving them as intent: D-17 (no `history_db`/`poll_loop`/sqlite import anywhere in the module's source) and D-13 (the rendered Airlines page contains none of the migrated registry/stats table headers, while Health still renders both header sets — the content moved, it was not lost).
