# Phase 06.6.4.1.1 Plan 02: Type Ladder and Unified Label Voice Summary

**Reordered the serif font stack, built a real 32/22/16px three-tier heading ladder with alternating weight, and converged every label-shaped element in the companion on one 12px uppercase sans-semibold voice.**

## Performance

- **Duration:** 8 min
- **Started:** 2026-09-03T20:58:00Z
- **Completed:** 2026-09-03T21:06:15Z
- **Tasks:** 3
- **Files modified:** 2

## Accomplishments
- Serif stack now leads with "Iowan Old Style", Charter (D-12) instead of Georgia-first, matching what Apple devices actually bundle, while staying a zero-external-reference system stack.
- Built the full three-tier heading ladder: 32px semibold `.page-title`, 22px regular `.text-heading` section headings, 16px semibold sans nested card titles — the weight alternation (semibold/regular/semibold) is what makes the three tiers read apart, not size alone (D-10, D-09).
- The wordmark (`.site-title`) grows to a literal 24px serif semibold with tighter tracking (D-11), explicitly documented as a brand-role literal rather than a fifth content-scale token.
- Retired the serif Label-role exception entirely: `.stat-tile__caption`, `.data-table th`, `.data-card__label`, `.filter-bar__count`, `.banner__pill` and `.airline-card__chip` all now state one 12px uppercase sans-semibold voice with 0.06em tracking (D-13). `.section-caption` was deliberately left out — it's a muted description, not a label.
- Corrected two stale comments the plan's own CSS boundary discipline cares about: the serif-set allow-list that used to name `.stat-tile__caption` as an exception, and a sub-scale-tier comment that still cited `.data-table th`'s old 11px value.
