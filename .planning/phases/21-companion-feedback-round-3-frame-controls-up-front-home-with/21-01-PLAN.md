| nav rendering → route reachability | the Advanced group's visibility was presentation-only, never access control |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-01 | Tampering | the deleted `/ui-mode` POST handler | mitigate | the route constant, the handler and its `do_POST()` dispatch line are deleted together, so the path falls through to the existing unknown-route behaviour; pinned by the replacement check in Task 1 |
