<objective>
Make each upstream input safe to receive: bounded provider and adsbdb calls (INT-07), a
type-checked provider body (INT-10), an adsbdb cache that never stores a transient failure and
expires entries (INT-08), and a Caddy log tailer that never skips or chokes on a line (INT-09).

Purpose: ROADMAP criterion 5 ("a transient adsbdb error is never cached as a miss") and "no
single bad input or slow upstream can hang or fail a cycle". `poll_loop` passes its clock to
`resolve_route` in 36-07; until then `now=None` falls back to `time.time()`.
Output: `detect.py`, `enrich.py`, `history_db.py` and their tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ADS-B aggregators, adsbdb -> poll | public, unauthenticated upstreams; body shape, size and pace are untrusted |
| Caddy access log -> poll | lines contain client-controlled header values (X-Battery-Mv etc.) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-36-30 | Denial of service | `query_provider` body shape | mitigate | dict/list type checks raise ValueError, caught per provider; non-dict records dropped |
| T-36-31 | Denial of service | slow/huge provider or adsbdb body | mitigate | `bounded_get` deadline 8 s and caps 4 MiB / 256 KiB |
| T-36-32 | Tampering (cache poisoning) | adsbdb cache | mitigate | only 404 or an empty 2xx is cached as a miss, for 1 day; transient failures never cached |
| T-36-33 | Denial of service | Caddy log line content | mitigate | binary read, replacement decoding, guarded `fromtimestamp`, guarded stored offset |
| T-36-34 | Information disclosure | provider error text | mitigate | HTTPError message names the provider and status only, no URL |
</threat_model>
