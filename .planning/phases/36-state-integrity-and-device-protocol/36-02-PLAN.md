<objective>
Land the outbound-HTTP primitives (INT-07 total deadline, INT-14 pinned connection) and give the
poll oneshot a start timeout (INT-07, systemd side).

Purpose: today `requests`' `timeout=` bounds connect and each socket read, not the transfer, and
the oneshot has no start timeout (systemd's oneshot default is infinity), so one trickling
upstream can hang a cycle forever. And `_host_is_safe` checks DNS answers that the later
connection does not reuse. This plan builds the primitives; callers migrate in 36-05 (calendar,
notify) and 36-06 (detect, adsbdb). Phase 39 (ARC-03) will later absorb this module into
`net/safe_fetch.py`; it is deliberately one small module now.
Output: `server/http_fetch.py` + tests, the FakeResponse streaming surface, the unit timeout.
</objective>

<interfaces>
Contract created here (36-05 and 36-06 code against it exactly):

- Exceptions, all `OSError` subclasses through `requests.exceptions.RequestException`, so every
  existing `except requests.RequestException` / `except Exception` handler keeps working:
  `class DeadlineExceeded(requests.exceptions.Timeout)`,
  `class ResponseTooLarge(requests.exceptions.RequestException)`,
  `class UnsafeDestination(requests.exceptions.ConnectionError)`.
- `FetchResult = collections.namedtuple("FetchResult", "status_code content headers")`.
- `bounded_get(url, *, headers=None, timeout, deadline_s, max_bytes, clock=None) -> FetchResult`:
  `clock` defaults to `time.monotonic`; deadline = clock() at entry + `deadline_s`. Calls
  `requests.get(url, headers=headers, timeout=timeout, stream=True)` through the module
  attribute at call time (FakeProviders patches `requests.get`). Raises `DeadlineExceeded` if
  the deadline has passed when the response arrives or after any chunk; iterates
  `response.iter_content(chunk_size=8192)`, raises `ResponseTooLarge` once the running total
  exceeds `max_bytes` (never trusting Content-Length); always `response.close()` in `finally`.
  Does not raise on a non-2xx status: callers decide. The docstring states the bound:
  deadline + one read timeout.
- `address_is_public(ip_text) -> bool`: same classification as today's
  `calendar_rules._address_is_public` (ipaddress; private, loopback, link-local, reserved,
  multicast, unspecified are not public; parse failure is False). 36-05 makes the calendar
  function delegate here.
- `resolve_public_addresses(hostname, port, resolver=None) -> list[str]`: one call to
  `resolver or socket.getaddrinfo` (looked up at call time) with `type=socket.SOCK_STREAM`;
  raises `UnsafeDestination` on resolution failure, an empty answer, or if any address is not
  public; returns the de-duplicated addresses in answer order.
- `class PinnedResponse`: attributes `status_code`, `status` (same int), `reason`, `headers`
  (the `http.client.HTTPMessage`, so `.get("Location")` works), `is_redirect` (status in
  301/302/303/307/308 and a Location header present); methods `iter_content(chunk_size=8192)`
  (before each read sets the socket timeout to `min(read timeout, time left)` and raises
  `DeadlineExceeded` when no time is left), `getcode()`, `close()`. It never follows redirects.
- `pinned_request(method, url, *, headers=None, body=None, timeout, deadline_s, resolver=None,
  create_connection=None, ssl_context=None, clock=None) -> PinnedResponse`: `https` only (else
  `UnsafeDestination`); hostname and port (default 443) from `urllib.parse.urlsplit`; addresses
  from `resolve_public_addresses` (the only resolution); for each checked address in order,
  try `(create_connection or socket.create_connection)((address, port),
  min(timeout, time left))` until one connects; wrap with `(ssl_context or
  _default_ssl_context()).wrap_socket(sock, server_hostname=hostname)`; send
  `method` + path-and-query with `Host` = hostname (plus `:port` when not 443) and the given
  headers and body through an `http.client.HTTPSConnection` subclass whose `connect()` performs
  the steps above; read the status line and headers under `min(timeout, time left)`.
  `_default_ssl_context()` returns `ssl.create_default_context()` unchanged (hostname check on,
  CERT_REQUIRED). Proxies from the environment are not used; say so in the docstring.
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server -> user-supplied URL (calendar feed, ntfy topic) | owner-entered URLs are fetched from the VPS, which can reach loopback and the provider's metadata address |
| server -> public upstreams (adsb.fi, adsb.lol, adsbdb) | responses are untrusted in size and pace |
| DNS | answers can change between two lookups (rebinding) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-36-05 | Spoofing / Elevation (SSRF via DNS rebinding) | `pinned_request` | mitigate | one `getaddrinfo`, every address must be public, the socket connects only to a checked address; test with a resolver whose second answer is private |
| T-36-06 | Spoofing (TLS) | `_default_ssl_context`, `wrap_socket` | mitigate | `ssl.create_default_context()` unchanged, `server_hostname=hostname`; test asserts check_hostname and CERT_REQUIRED |
| T-36-07 | Denial of service (slow trickle) | `bounded_get`, `PinnedResponse.iter_content` | mitigate | monotonic total deadline checked between chunks, socket timeout clamped to time left; bound = deadline + one read timeout |
| T-36-08 | Denial of service (huge body) | `bounded_get` | mitigate | running byte count against `max_bytes`, Content-Length ignored |
| T-36-09 | Denial of service (hung oneshot) | `skypane-poll.service` | mitigate | `TimeoutStartSec=90s` |
| T-36-10 | Information disclosure | exception text | accept | callers already log the exception type only; this module adds no URL to messages it builds |
</threat_model>
