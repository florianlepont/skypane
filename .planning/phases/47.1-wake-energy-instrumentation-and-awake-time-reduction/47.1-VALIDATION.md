# Phase 47.1 — Validation Strategy

> Per-phase validation contract. Style follows `47-VALIDATION.md`. Derives from `47.1-RESEARCH.md` (Validation Architecture) and the sixteen plans. Anything that needs the real frame or the replacement pack is manual-only and owner-run; the host side is fully automated.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest (+ xdist, cov) in `server/.venv` for server, stub-server, companion, hardware; C host tests with system `cc` for firmware |
| **Config file** | `pyproject.toml` (pytest, ruff, mypy module list); `firmware/tests/run_host_tests.sh` |
| **Quick run command** | `./firmware/tests/run_host_tests.sh && server/.venv/bin/python3 -m pytest server/test_wake_stats.py server/test_caddy_tail.py server/test_history_db_scope.py companion/test_export_battery_history.py stub-server/test_phase47_freeze.py hardware -q --no-cov -n0` |
| **Full suite command** | `./scripts/run-all-tests.sh` |
| **Estimated runtime** | about 30 s quick, about 12 min full |

## Sampling Rate

- **After every task commit:** the quick run command plus `python3 scripts/check_comment_history.py check`
- **After every plan wave:** quick run command, `python3 hardware/logtools.py selftest`, `sh firmware/tests/check_log_contract.sh`, `sh firmware/tests/check_production_config.sh`; full suite after wave 2 (shared `history_db`), after wave 3 and at the end
- **Before `/gsd:verify-work`:** full suite green; ruff, mypy, `scripts/check_function_size.py` clean; firmware host tests green; the container build run or CI's containerised build named as the record
- **Max feedback latency:** 60 s for the quick run
