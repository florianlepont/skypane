<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| frame to server (request header) | untrusted bytes from a holder of a device token |
| Caddy access log to tailer | log line parsed by the poll oneshot |
| companion export | existing read-only bearer-token route |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-47.1-03 | Tampering | forged or oversized X-Wake-Stats | mitigate | fixed grammar, per-key integer bounds, 192 byte cap, whole header dropped on any violation, parameterised inserts |
| T-47.1-04 | Information disclosure | credential leak through header logging | mitigate | explicit allowlist, no wholesale header copy, raw header value never logged |
| T-47.1-05 | Denial of service | migration or export on an old database | mitigate | guarded ALTER is idempotent and race tolerant (duplicate column name swallowed); export falls back instead of failing; row cap and age bounds unchanged |
| T-47.1-06 | Repudiation | malformed header silently changing the poll | mitigate | parse failure changes nothing in the response or the battery row; covered by test |
| T-47.1-SC | Tampering | package installs | accept | none; stdlib only, requirements untouched |
</threat_model>
