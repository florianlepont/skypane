<objective>
Close A-20 (D-02): replace Health's unconditional 45-second `location.reload()`
with a fetch-and-swap refresh, make the freshness line tell the truth, and give
the user a visible way to stop it.

Purpose: today Health reloads the whole page every 45 seconds with no opt-out,
destroying keyboard focus and closing every disclosure; the line above it reads
"Live — refreshed HH:MM (0s ago)", which is structurally always zero because the
page was just rendered; and the only thing that stops the polling is opening a
disclosure, silently.
Output: a rewritten `companion/static/freshness.js` that fetches its own page,
parses it without any HTML-writing sink, swaps a documented list of regions
including the nav severity dot, leaves the chart and the filter untouched, and
obeys a real Pause/Resume button.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| network response -> live DOM | the fetched page's markup is parsed and inserted into the authenticated document every 45 s — a brand-new surface this app did not have before |
| session expiry -> fetch response | an expired session makes the fetch return a redirect/login page rather than Health data |
| page DOM -> fetch target URL | a URL read out of the DOM would let injected markup choose what this script fetches |
