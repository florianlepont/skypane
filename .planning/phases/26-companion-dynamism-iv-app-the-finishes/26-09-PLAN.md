<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet → Caddy → companion | compression is applied at the edge; which responses it covers is a security decision, not a performance one |
| browser chrome ← theme-color | a value derived from configured state reaches a document meta tag |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-09-A | Tampering (injection) | the theme-color value interpolated into a meta attribute | mitigate | the value comes from the theme registry's own token, not from request data, and is escaped like every other attribute in the shell |
| T-26-09-B | Information disclosure (BREACH) | compressing responses that contain session-derived content | mitigate | compression is scoped to public static asset types served before `require_session()`; no HTML response is compressed, so the attack has no reflected secret to work against. Asserted by a check that distinguishes the two site blocks |
| T-26-09-C | Information disclosure | compressing the device-protocol block and disturbing the telemetry access log the history tailer parses | mitigate | the device block is not touched; the check asserts the directive's absence there |
| T-26-09-SC | Tampering | dependency installs | accept | no packages; a Caddy directive and one meta tag |
</threat_model>
