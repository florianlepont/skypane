## Bibliothèque de formes SVG (SVG shape library)

This area consumed most of the session and materially changed the phase's architecture.

| Question | Options presented | User's choice |
|---|---|---|
| Type coverage | Just observed types / Broader library / 2 generic categories | **Broader library** |
| Shape source | Free SVG sources / Adapt current silhouette / AI vector generator | User was confused — thought this question was about livery colors, not outline shape. Clarified in plain text. |
| Detail level | Same as current (detailed 3/4-view) / Simplified | **Same as current (Recommended)** |
| Family variants | One shape per family / One per exact variant | **One shape per family (Recommended)** |

**Sketch detour:** User asked to see visual comparisons ("on pourrait avoir des sketches de chaque méthode pour voir ce que ça donne"). First attempt (hand-drawn programmer-art SVG ellipses/rectangles, 3 panels) was rejected outright ("c'est horrible" / "tout ça") — too crude to inform a real decision.

**Real sourcing investigation (in response to user's own find):**
- User found `airlineenterprise.com/forums/printthread.php?tid=633` — flight-sim repaint PSD templates, ~100+ types, correct side-profile angle. WebFetch confirmed explicit terms: "do not redistribute... out of respect to the work and craftsmanship." User initially pushed back ("tu sais ces illustrations sont libres de droit... ça reste un projet perso") — clarified that "free to use" ≠ "free to redistribute," and that a public GitHub repo checking in the file constitutes redistribution regardless of commercial intent. User accepted the correction.
- Fetched a real candidate from Wikimedia Commons (`Boeing_737-800_silhouette.svg`, CC-BY-SA 4.0, author Peter Lowden/"FlyingPete") and rendered it for the user — turned out to be a **top-down plan view** (map-tracker style), wrong angle for this project's side-profile nose-left convention.
- Checked Wikimedia's Airbus "Line drawings" category — PNG only, no SVG, licenses unverified per-file.
- Checked generic CC0 clipart (openclipart, svgsilh) — only generic universal jet shapes, no per-type differentiation, same as the project's existing asset.
- **Conclusion:** no viable ready-made source exists. User's response: "s'il y a besoin de changer le plan pour cette phase, il faut le faire" — explicitly reversed course and asked for the exhaustive company × aircraft-type list instead, to generate images externally (same discipline as Phase 3's D-09), abandoning the render-time procedural compositing architecture ROADMAP.md originally described for this phase.

**Exhaustive list built and verified:**
- First draft from Wikipedia's Paris–Orly Airport "Airlines and destinations" table (25 real airlines) + general aviation knowledge for fleet types.
- User caught a real gap: "il te manque les nouveaux A320 neo de transavia aussi ?" — verified via search that Transavia France is genuinely mid-transition (B737→A320neo/A321neo), confirming both types are real, not one.
- User then asked to verify company-by-company rather than trust a single pass. ~10 additional targeted searches were run (ITA Airways, Air Europa, Air Algérie, Royal Air Maroc, Tunisair, Pegasus, LOT, Volotea, easyJet, Air Corsica, TAP, Iberia, Amelia, ASL Airlines France, Air Caraïbes, Corsair, French Bee, La Compagnie), surfacing several more real corrections (Pegasus is majority-Airbus not majority-Boeing; Amelia's Pau route is specifically Embraer E145, not a mixed fleet guess; Air Corsica's real ex-name is CCM Airlines).
- Final table (24 airlines, 7 real distinct base shapes) locked into CONTEXT.md D-03 on user confirmation ("oui tu peux figer").

**Notes:** This area's outcome directly reverses ROADMAP.md's stated architecture for this phase (see CONTEXT.md D-02/D-10) — a genuine mid-discussion scope pivot, not a refinement.
