## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ADS-B aggregator -> `detect.py` | Untrusted third-party JSON crosses here. The new `t` field is attacker-influenceable in the same sense the existing `flight` field is (anyone can transmit an arbitrary ADS-B payload). |
| `detect.py` -> `poll_state.json` -> `render.py`/`illustrations.py` | The normalized value is persisted and later used to build a lookup key that resolves to a filesystem path. |
