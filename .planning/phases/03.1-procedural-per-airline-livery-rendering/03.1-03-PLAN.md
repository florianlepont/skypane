## Planner decisions this plan implements

- **P-04** — primary (unsuffixed) file is the numerically dominant type and an already
  vendored file is never regenerated to swap roles. `transavia-france.png` stays B737 with a
  new A320-family secondary; `ccm-airlines.png` stays A320 with a new ATR72 secondary;
  `royal-air-maroc.png` is B737 with an Embraer secondary; `air-caraibes.png` is A350 with an
  A330 secondary.
- **P-05** — `required_filenames()` keeps meaning "must exist and validate now";
  `target_filenames()` is the full D-03 plan; `outstanding_filenames()` is the difference.
- **P-06** — ATR42 ICAO codes map to the `atr72` bucket, per D-03's explicit seven-shape table.
