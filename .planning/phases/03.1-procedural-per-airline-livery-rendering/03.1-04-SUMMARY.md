## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `_flight_line2_text()`'s no-label fallback returned a non-string for a truthy non-string `airline_name`**
- **Found during:** Task 1, while running the newly-added never-raises battery check (`_flight_line2_text({"airline_name": 12345}, None)`)
- **Issue:** The function's own docstring and the plan's Task 1 `<behavior>` block both state the function never raises for a non-string airline name and (implicitly, via the "always a string" test the plan itself specifies) always returns a string. The initial implementation's no-label fallback `return display_name` returned `display_airline_name(airline_name)`'s output unchanged - and `display_airline_name()` correctly passes non-string input through unchanged too (by design, for its own never-raises contract), so the composed result was `12345` (an `int`), not a string.
- **Fix:** Changed the final fallback line to `return "%s" % (display_name,)`, forcing string coercion without affecting any real (string) airline name's output.
- **Files modified:** `server/plane/render.py`
- **Verification:** Task 1's own never-raises battery check (`_flight_line2_text_never_raises_for_hostile_inputs`, crossing 6 malformed routes x 8 hostile types = 48 combinations) passes; all prior real-airline-name assertions re-verified unchanged.
- **Committed in:** `f3837d5` (Task 1 - found while implementing Task 1's own specified check, fixed before that commit, not a separate amendment)
