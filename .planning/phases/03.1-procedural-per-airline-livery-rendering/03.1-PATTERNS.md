**Key-normalization pattern to mirror for `classify_aircraft_type()`** (from `normalise_airline_key()`, lines 114-127):
```python
def normalise_airline_key(airline_name):
    """Return a deterministic, filesystem-safe slug for `airline_name`, or
    `None` for anything falsy or non-string - mirrors enrich.py's
    `normalise_callsign()` never-raises discipline. Pure, no I/O.
    """
    if not isinstance(airline_name, str) or not airline_name:
        return None
    ascii_name = unicodedata.normalize("NFKD", airline_name).encode("ascii", "ignore").decode("ascii")
    slug = re.sub(r"[^a-z0-9]+", "-", ascii_name.lower()).strip("-")
    return slug or None
```
`classify_aircraft_type()` should follow the identical shape (isinstance check → normalize → static-table lookup → `None` on miss, never raises), per RESEARCH.md Code-Level Finding #4:
```python
def classify_aircraft_type(icao_type):
    if not isinstance(icao_type, str) or not icao_type:
        return None
    return _TYPE_SHAPE_BUCKETS.get(icao_type.strip().upper())
```
Security note (ASVS V5, Tampering mitigation from RESEARCH.md): this is a lookup against a **fixed static dict**, never a pass-through of the raw value into a filename — mirrors why `illustration_path_for_key()`'s `_UNSAFE_KEY_RE` boundary check (lines 107-111, 130-138) exists as defense-in-depth for `normalise_airline_key()`'s output too.

**Existing single-tier selection pattern** (lines 145-165) — the pattern to extend from 1 tier to 4:
```python
def select_illustration(route):
    try:
        airline_name = route.get("airline_name") if isinstance(route, dict) else None
```

## Shared Patterns

### Never-raise / graceful-degradation discipline
**Source:** `server/plane/illustrations.py` `normalise_airline_key()` (lines 114-127), `select_illustration()`'s `try/except` (lines 151-154), `server/plane/detect.py`'s `.get()`-then-normalize idiom (lines 177-180).
**Apply to:** `classify_aircraft_type()`, the new `aircraft_type` extraction in `detect.py`, and every new tier in `select_illustration()`. Rule: `isinstance()` check first, falsy/wrong-type input always degrades to `None`/next fallback tier, never an exception. This is also the ASVS V5/Denial-of-Service mitigation RESEARCH.md calls out explicitly.

### Path-safety boundary check
**Source:** `server/plane/illustrations.py` `_UNSAFE_KEY_RE` (line 111) + `illustration_path_for_key()` (lines 130-138).
**Apply to:** any new composite key built for the `generic-{shape}.png` / `{airline}-{shape}.png` filenames — always go through the existing `illustration_path_for_key()` helper rather than constructing `os.path.join` calls directly, so the same regex boundary check applies uniformly.

### Static-table-over-live-lookup for classification
**Source:** `server/plane/illustrations.py` module docstring's `_LIVE_RESOLVED_AIRLINES` list (lines 92-100) — a hand-curated, out-of-band-verified static list, not a runtime API call.
**Apply to:** the new `_TYPE_SHAPE_BUCKETS` dict in the same file — same "verified once, hardcoded, documented in the module docstring with the verification methodology" convention.

### Test harness exact-count self-check
**Source:** every `server/test_*.py` file's `EXPECTED_CHECK_COUNT` constant.
**Apply to:** all three touched test files — a forgotten bump makes the harness fail even when new checks themselves pass, so this must be updated in the same commit as any added `check(...)` call.
