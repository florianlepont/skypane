## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| externally generated image files -> `server/assets/` | Binary content produced outside this repository by a third-party tool crosses into the repo and is later decoded by Pillow inside the render path. |
| hand-written `HANDOFF.md` filename -> selection key | A filename that disagrees with the code's derived slug produces permanently unreachable art with no error signal anywhere. |
| neutral shape files -> the panel | Art shown specifically when the carrier could not be identified; any brand cue becomes a false attribution to a real airline. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
