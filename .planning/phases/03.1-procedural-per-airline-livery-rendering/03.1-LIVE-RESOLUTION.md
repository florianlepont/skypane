## Probe method calibration (Step A)

Probed `https://api.adsbdb.com/v0/airline/AFR` (the per-airline endpoint, distinct from the per-callsign endpoint
`enrich.lookup_route()` already uses in production) against the known answer `AFR` -> `Air France`:

```
GET https://api.adsbdb.com/v0/airline/AFR
-> {"response":[{"name":"Air France","icao":"AFR","iata":"AF","country":"France","country_iso":"FR","callsign":"AIRFRANS"}]}
```

Response shape: a JSON object with a single top-level key `response`, whose value is an **array** of airline
objects (even for a single-ICAO-code lookup) — the resolved airline name sits at `response[0].name`.

**Result: matches the known answer exactly.** The airline endpoint is **trusted** for the rest of this task,
with one caveat discovered live during Step C: the airline endpoint can return a **different resolved name than
the equivalent real callsign would**, when an ICAO code has been reused or is otherwise ambiguous in adsbdb's
crowdsourced database (see the ASL Airlines France / Corsair International / La Compagnie findings below). Per
Pitfall 2's discipline, a real callsign is treated as stronger evidence than the airline endpoint alone whenever
both are available, and every row below records which probe(s) were actually used.

### ASL Airlines France
Candidate code `FPO` (guessed) returned an airline-endpoint name of `"Europe Airpost"`, not `"ASL Airlines
France"` — investigated further with a real callsign before drawing any conclusion (Pitfall 2 discipline):
```
Real callsigns harvested live from a 250nm Paris sweep (lat/48.8566/lon/2.3522/dist/250): FPO701, FPO458
GET https://api.adsbdb.com/v0/callsign/FPO701
-> airline.name = "Europe Airpost", icao = "FPO", callsign = "FRENCH POST", origin/destination both real (CDG-CDG)
GET https://api.adsbdb.com/v0/callsign/FPO458
-> airline.name = "Europe Airpost", origin Algiers (DZ) -> destination Lille (FR)
```
**Load-bearing finding, same shape as the CCM Airlines / Air Corsica case (D-04):** ASL Airlines France was
rebranded from **Europe Airpost** in 2016, but `adsbdb` — confirmed via two independent real, currently-flying
callsigns, not a guess — still resolves the ICAO code `FPO` (radio callsign `FRENCH POST`, which matches ASL
Airlines France's real-world radio callsign) to the pre-rebrand name `"Europe Airpost"`. The real flights
observed (Algiers-Lille, CDG-CDG cargo positioning) are consistent with ASL Airlines France's actual operation
(cargo/freight + Algeria routes), confirming this is the same airline under an old name, not a different company.
**Verdict: `[VERIFIED-CALLSIGN]`, but the correct selection-key string for the illustration hand-off is
`"Europe Airpost"`, not D-03's label `"ASL Airlines France"`.** Any future `ccm-airlines.png`-style filename
must be named `europe-airpost.png`, mirroring P-01's exact rationale (the selection key must match the data
source's literal output, not the airline's current public brand).
