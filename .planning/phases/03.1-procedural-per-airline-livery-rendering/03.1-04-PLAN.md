## Planner decisions this plan implements

- **P-01** — the panel shows a presentation-only alias for the one carrier that rebranded in
  2013, while `illustrations.py`'s selection key and the vendored filename stay keyed on the
  literal string the route API resolves. One dict entry, applied in `render.py` only, never
  reaching a filesystem path. Rationale: D-04's real concern is what a human reads on the
  glass, and keeping the selection key literal means a future genuine route-API miss still
  surfaces instead of being masked.
- **P-02** — friendly type labels call out neo and MAX variants by name rather than collapsing
  to the base family, per RESEARCH.md Code-Level Finding #6's table. Claude's Discretion per
  CONTEXT.md; more informative, cosmetic, and reversible.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| persisted flight dict -> `_flight_line2_text()` | An aggregator-sourced, attacker-influenceable type string is used to look up text that is then drawn onto the panel. |
| persisted flight dict -> `select_illustration()` call sites | The same untrusted value is forwarded into the selection chain that resolves to a filesystem path. |
| `poll_loop.py` log line -> `journalctl` on the live VPS | Untrusted field values are written into a system log read by a human. |
