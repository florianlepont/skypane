<objective>
Airlines shows raw machine time to a household member and hides its own editing
mode. The resolve dialog writes `first_seen` and `last_seen` into data attributes
verbatim, so it renders "2026-09-09T15:49:27+00:00" while the no-JS path beside it
formats the same value properly; its Save and Close stack onto two lines. The
"CHANGE PICTURES" button shouts because it inherits an uppercase transform from
the page header; turning edit mode on changes nothing visible on the grid, so the
affordances exist only inside the lightbox; "1 manual resolutions" is a 12 px bare
link; and on a phone the page is 5 800 px because it renders one card per row.

Purpose: this is the page a user reaches when a flight could not be named, which
means they arrive already slightly frustrated. Every defect here is about making
the page say plainly what it can do.
Output: a dialog that reads in Paris local time and fits one action row, a grid
that shows its editing state, two cards per row on a phone, and a filter bar that
holds one line.
</objective>
