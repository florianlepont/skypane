<objective>
Make Health tell the truth about the flight pipeline. Today the "Flight data"
tile stacks two verdicts and borrows the battery module's vocabulary ("A little
stale / A little behind · no reading yet · Last aircraft detected: no reading
yet"), because `staleness_status()` maps an unknown age to warn when the pipeline
has simply never run, and Home re-embeds Health's whole verdict block under its
own. Alongside it, "How well we name flights" renders as an empty heading-only
card while 36 real rows sit in the database, because the stats count only five
`route_source` values and drop everything else.

Purpose: B2 and B3 are the same question as X2 — is the state reported honestly?
— asked on Health rather than on the frame strip. They land in wave 2 alongside
the next-wake computation because they are independent of it in logic and because
this is the last wave in which `health_page.py` is free.
Output: one verdict per tile, a real neutral never-ran state, a verdict-free
detail string Home can consume, and naming statistics that count what is actually
there.
</objective>
