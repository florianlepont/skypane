# Phase 22: Companion audit round 4 — Audit ledger

**Gathered:** 2026-09-12, against `main` at 541d19c (end of phase 21).
**Method:** the companion was run locally on a seeded state directory (36 runway events over 17 h, 40 days of battery readings at 3 h then 5 min cadence, 3 gallery renders, 2 unresolved prefixes, 1 manual resolution, 2 colour rules, wake interval 300 s, quiet hours 23:00–07:00) and every page (login, Home, Display, Flights, Airlines, Health, Device, 404) was screenshotted with Playwright at 1280×900 and 390×844, light and dark, FR and EN, plus the interactive states (login error, quick toggle, theme chip change, expanded row, resolve dialog, lightbox, edit mode, Health disclosures, dirty form, keyboard focus). Element geometry and computed styles were measured in the DOM. Two read-only code reviews covered `style.css` + `static/*.js`, and `layout.py` + `app.py` + `wake.py` + the five page modules + `i18n_fr/`.
**Full report with evidence images:** https://claude.ai/code/artifact/af979b96-c02d-41bc-ad04-9623ff0d143a (developer-validated 2026-09-12: "Je valide l'ensemble des points remontés").

**Audience framing:** unchanged from phase 18 — a second household member with basic computer skills must be able to use the everyday half without an explanation.
