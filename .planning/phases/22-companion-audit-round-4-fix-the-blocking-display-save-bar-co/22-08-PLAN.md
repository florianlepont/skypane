<objective>
Close the French leaks. Flash banners are never translated at all — no FR
catalogue carries a single FLASH string, because `_resolve_flash_text()` returns
English and nothing routes it through `i18n.t`. Page titles are English under a
French tab ("Health - SkyPane" under "État", "Login - SkyPane", "Not Found").
Plurals read "1 manual resolutions". `aria-label="Primary navigation"` and the
Light/Dark segments are untranslated. And the completeness harness cannot see any
of it, because it scans neither `app.py`, nor attribute literals, nor the JS-side
fallbacks.

Purpose: CFG-29 is not "translate these strings" — it is "the harness covers the
places it currently cannot see", so the next leak fails a test instead of an
audit. The scanner widening is therefore the load-bearing half of this plan.
Output: a French interface with no English in it, and a mechanical check that
keeps it that way.
</objective>

| Boundary | Description |
|----------|-------------|
| flash key from a query string or redirect → rendered banner | a client-influenceable key selects which message is shown |
| catalogue lookup → rendered text | translated strings reach the same interpolation sites as English ones |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
