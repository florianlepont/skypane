listens on the form element, which never receives events from the fields that

hidden while `.dirty-ready` has already hidden the fallback Save button. Ship the
delegation fix, the fallback-visibility contract, and the browser harness that

ride along because they live in the same two functions this plan rewrites.

string-comparison harness can see, and B1 is the reason that harness exists
(D-01/D-02). Nothing else in the phase is provable until saving works.

`companion/test_browser_ux.py` wired into the suite and into CI.

| Boundary | Description |
|----------|-------------|
| browser DOM → save path | a document-level listener now sees every `change` in the page, not only the form's own |
| CI runner → PyPI and the Playwright CDN | a new dev dependency and a browser binary are downloaded during CI |
| test browser → network | a headless Chromium is launched inside the test suite |
| scripts-blocked browser → settings save | the fallback Save is the only write path when the script fails |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-01 | Tampering | `dirty-state.js`'s new document-level listeners | mitigate | the handler returns immediately unless `e.target.form === form`; it reads state only and never writes a field value, so a foreign element's event can at most trigger a no-op recount |
| T-22-02 | Denial of Service | the fallback Save button | mitigate | the fallback is hidden only once the bar has actually been shown, so a broken or blocked script can never leave the page with no write path — this is the defect being closed, pinned by a browser check |
| T-22-03 | Elevation of Privilege | the headless Chromium in the harness | mitigate | the harness constructs URLs from `Harness.base_url()` only (127.0.0.1, ephemeral port, temp state dir); no external origin is reachable from any check, asserted by an acceptance grep |

| T-22-05 | Information Disclosure | CSP | accept | unchanged: `script-src 'self'`, no `unsafe-inline`, no nonce; this plan adds no inline script and no new external origin |
| T-22-SC | Tampering | pip install of `playwright` | mitigate | 22-RESEARCH.md's Package Legitimacy Audit records PyPI, Microsoft-maintained, slopcheck `[OK]`, disposition Approved — no `[ASSUMED]`/`[SUS]` package is installed, so no blocking legitimacy checkpoint applies.
