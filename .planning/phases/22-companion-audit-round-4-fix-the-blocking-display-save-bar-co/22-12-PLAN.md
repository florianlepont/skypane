<objective>
Health shows three server cards with three anatomies: one stacks a double bold
verdict, one renders "Only one saw it" in exactly the same green as "Both agree",
and one puts a 22 px serif empty-state heading inside a tile whose own caption is
12 px — an inverted hierarchy the app already fixed once, for nested cards. In
French the unresolved-prefix table overflows a 1280 px desktop, clipping a header
and pushing the Resolve column behind a scroll whose only affordance is a 12 px
shadow. And the filter Clear drops onto its own line at 390 px, the last of the
three pages where it does.

Purpose: Health is where a user goes when they suspect something is wrong, so a
page that contradicts itself is worse here than anywhere else. One anatomy, one
verdict, one neutral state for a state that is not a problem.
Output: three tiles that read the same way, a table that fits in both languages,
and a compact empty state the rest of the app can reuse.
</objective>
