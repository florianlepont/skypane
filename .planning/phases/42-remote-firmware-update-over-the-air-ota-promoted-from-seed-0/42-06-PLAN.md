<objective>
Move the Wi-Fi credentials and the server base URL out of the compiled image (today a gitignored `secrets.h`) into the device's existing `secret` NVS partition, written by `firmware/provision.sh` alongside the enrolment secret.

Purpose: this is an enabling change the phase cannot ship without. OTA-10 has CI build and sign every release, and D-17 stores the image on the VPS and in the nightly backup. With `secrets.h` compiled in, a CI build carries placeholder credentials (the device would join no network and every update would roll back), and a build with real credentials would put the Wi-Fi password into GitHub artifacts, the VPS and backups. The project already keeps the per-device enrolment secret out of the image for the same reason ("the firmware image is identical for every device", secrets.example.h). This decision was not taken in /gsd:discuss-phase; it is flagged to the developer in the planning return and must be confirmed before execution.
Output: credentials loaded from NVS, provisioning extended, `secrets.h` retired, docs updated.
</objective>
