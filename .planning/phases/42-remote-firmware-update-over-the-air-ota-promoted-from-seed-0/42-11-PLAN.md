## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| git tag push -> signing job | who can cause a signature |
| GitHub secret -> runner | the private key on an ephemeral runner |
| GitHub Release -> VPS / USB flash | published artifacts |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-42-47 | Elevation of Privilege | signing arbitrary code via a tag on an unreviewed branch | mitigate | tag must be an ancestor of main; `firmware-signing` environment requires reviewer approval before the key is exposed |
| T-42-48 | Information Disclosure | key leakage in logs or workspace | mitigate | env: only, umask 077 temp file outside the workspace, read-only mount, always-run removal; test_ci_secrets scans all workflows |
| T-42-49 | Tampering | wrong key in the secret | mitigate | verify_signature against the committed public key before publishing |
| T-42-50 | Tampering | release notes forged by hand | mitigate | notes generated from git log only (D-07) |
| T-42-51 | Information Disclosure | public release assets | accept | images contain no credentials after plan 06; firmware is not secret |
| T-42-SC | Tampering | package installs | accept | no new packages; espsecure.py ships in the pinned espressif/idf:v5.3.1 image (RESEARCH Package Legitimacy Audit: not applicable) |
