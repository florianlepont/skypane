<objective>
Build the e-ink "UPDATING" hold screen the device shows during every firmware update: its server-side composition (the source of truth), a generated ink mask, and a device renderer that shares the existing NO CONNECTION dither code instead of duplicating it.

Purpose: OTA-07 / D-14. The screen must appear even in quiet hours and with the display off, and must not cost a server round trip during a wake that is already downloading a firmware image (UI-SPEC Surface 2 resolution).
Output: render.py composition, generator support, committed mask header, shared hold-screen renderer, and tests on both sides.
</objective>
