<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| VPS response -> device | offer fields arrive from the network and may come from a compromised VPS |
| downloaded image header -> device | the app descriptor of the new image is untrusted until signature verification |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-42-08 | Tampering | offer fields | mitigate | fp_fw_version_valid / fp_fw_size_parse / fp_image_hash_valid / fp_url_valid(allow_http=false) bound every field; a failure means no update, never a crash or oversize write |
| T-42-09 | Elevation of Privilege | downgrade below floor by a compromised VPS | mitigate | fp_ota_decide refuses offered versions below the compiled floor, and fp_ota_image_check re-checks the signed image descriptor's version, so the floor holds even if the offer lies |
| T-42-10 | Denial of Service | battery drain from update attempts | mitigate | FP_OTA_MIN_BATTERY_MV refusal, unknown battery refuses too |
| T-42-11 | Spoofing | result token injection into telemetry | mitigate | fp_ota_result_format only emits a fixed token set and a validated version without ';' |
</threat_model>
