<objective>
Teach the shared `panel-lookup.js` script to open the dialog with no image, to show the right
one of the dialog's optional forms per trigger, to intercept an `<a>` trigger's navigation, and
to auto-open itself at page load against a URL-carried prefix — the four mechanical
consequences D-02/D-03/D-12/D-13/D-14 impose on the one script every page on this site shares.

Purpose: RESEARCH.md names `image.src = ""` as "the riskiest single line of code in this
phase" — a documented cross-browser bug that would silently reintroduce a network call into a
script whose own header comment forbids one — and names the load-time auto-open path as
"the second real risk," since it is the first non-click entry point this script has ever
needed. This plan is the phase's only touch of `panel-lookup.js`; getting both right here is
what makes every one of VALIDATION.md's manual-only browser checks (14-08) actually pass
rather than merely look plausible on paper.

Output: `panel-lookup.js` gains an imageless-open branch, three new optional-element lookups,
a mode/manual visibility toggle, `<a>` interception, and a factored populate-and-open function
reachable from both a click and page load. `test_view_pages.py` gains eight source-content
checks and empties `_LIGHTBOX_RENDER_ONLY_TOKENS` by promoting every token it staged.
</objective>
