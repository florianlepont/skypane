## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DOM attribute → `list-filter.js` | `data-filter-set`'s value is read from a server-rendered attribute and written into an `<input>`'s `.value`; it never reaches a markup sink |
| stylesheet → every page | `style.css` is a single cached static asset served to every page, so any rule added here is global by construction |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-12 | Tampering (client-side injection) | the `[data-filter-set]` click handler | medium | mitigate | The handler writes the attribute's value into `input.value` — a property assignment, never a markup sink. `list-filter.js` must gain no `innerHTML`/`outerHTML`/`insertAdjacentHTML`/`document.write` of any kind; the value's only downstream consumer is `applyFilter()`'s `indexOf` substring test. The value is additionally server-rendered and already `escape_html()`'d once at interpolation, so it is not operator-typed input reaching the DOM directly. Pinned by the ES5/no-sink source assertions. |
| T-14-13 | Denial of Service (self-inflicted) | `list-filter.js`'s new lookup | low | mitigate | The lookup runs once at init and attaches one listener per matched element; it starts no timer, makes no network call and holds no persistent state — the file's own three standing constraints, re-asserted by the source check. A `querySelectorAll` over a bounded server-capped card set cannot become unbounded work. |
| T-14-14 | Information Disclosure | `style.css` served to every page | low | accept | The new rules describe presentation only and reference no state; a stylesheet cannot leak data it never receives. Accepted with no mitigation beyond keeping the rule set to UI-SPEC's exhaustive list, which the acceptance criteria pin. |
| T-14-15 | Tampering (visual signalling) | `.airline-card__placeholder` as a colour/shape-only signal | low | mitigate | The placeholder is `aria-hidden="true"` and empty (plan 14-04's markup); the card's own visible, announced callsign text carries the meaning in full. The dashed border and canvas fill are reinforcement, never the sole signal — this codebase's no-colour-only-signal rule, unchanged from Phase 13. |
| T-14-SC | Tampering | package installs | n/a | accept | No dependency added; both files are first-party, build-step-free assets already in the repository. |
</threat_model>
