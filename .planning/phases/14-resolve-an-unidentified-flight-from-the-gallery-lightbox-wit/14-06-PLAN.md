<objective>
Absorb Phase 13's standalone "Manually resolved prefixes" management table into the gallery
cards themselves: a chip marking manual origin (D-08), a superseded card that shows the
frame's real current state (D-10), any prefixed card reachable the same way a raw gap is
(the trigger-tag generalisation D-12's fallback needs), and a clickable summary line in the
table's place (D-11). Delete the table's own rendering functions and their now-orphaned
helpers, and the one CSS selector that existed only for them.

Purpose: this is the last piece of the absorption the developer's own feedback asked for —
"ce tableau ne sert à rien." Every manual-resolution fact the table used to carry
(`_manual_resolution_rows()`'s own tuples) must keep flowing to exactly the same two card
attributes (chip text, dialog manual-note) it already computes correctly, so this plan
consumes that function rather than re-deriving any of its three booleans a second time
(RESEARCH.md Pitfall 6). It depends on 14-04 because both plans edit `render()`'s own
composition and `_gallery_grid_html()`'s own signature — this plan is the second, sequential
edit to both.

Output: `_airline_card_html()` gains a `manual_info` parameter and full attribute coverage for
the needs-artwork/manual-active/manual-superseded states; a new additive grid-injection step
covers a genuinely novel manual airline name; the summary line replaces the table; six
now-dead Python symbols and one CSS rule are deleted; `test_status_pages.py` gains five new
checks and retargets four in place.
</objective>
