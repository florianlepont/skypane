```python
# Source: implements D-22 against server/poll_loop.py:605's actual naming contract
# (now_iso.replace(":", "-") + ".png" — a naive full-string reverse also
# mangles the DATE portion's hyphens).
import re

_GALLERY_TIME_PATTERN = re.compile(
    r"^(\d{2})-(\d{2})-(\d{2})([+-]\d{2})-(\d{2})$")

def _gallery_name_to_iso(name):
    """Reverse server/poll_loop.py::_save_to_gallery()'s ':' -> '-'
    filename sanitization. Returns None (never raises) on anything that
    doesn't match the exact expected shape.
    """
    stem = name[:-4] if name.endswith(".png") else name
    if "T" not in stem:
        return None
    date_part, _, time_part = stem.partition("T")
    match = _GALLERY_TIME_PATTERN.match(time_part)
    if not match:
        return None
    hh, mm, ss, tz_sign_hh, tz_mm = match.groups()
    return "%sT%s:%s:%s%s:%s" % (date_part, hh, mm, ss, tz_sign_hh, tz_mm)
```

```python
def concise_timestamp_html(ts, now_ts, fallback="no reading yet"):
    """Returns '<span class="mono" title="<full ISO>"><HH:MM> UTC (<relative>)</span>'
    — the full ISO demoted to `title`, visible text a concise clock time
    plus relative_age_text()'s suffix, preserving absolute-first ordering.
    RAW-MARKUP-PRODUCING: callers must interpolate verbatim, never
    re-escape, and only place it in data_table()'s new raw_columns.
    Returns an escaped plain fallback string (no markup) when `ts` is
    falsy — that branch IS safe to interpolate verbatim too, since it
    already ran escape_html() itself.
    """
    if not ts:
        return escape_html(fallback)
    parsed = parse_iso(ts)
    age = age_seconds(ts, now_ts)
    if parsed is None or age is None:
        return '<span class="mono" title="%s">%s</span>' % (escape_html(ts), escape_html(ts))
    clock = parsed.strftime("%H:%M")
    return '<span class="mono" title="%s">%s UTC (%s)</span>' % (
        escape_html(ts), escape_html(clock), escape_html(relative_age_text(age)))
```

    if not rows:
        return empty_state("No data yet.", "Nothing to show here yet.")
    header_cells = "".join("<th>%s</th>" % escape_html(h) for h in headers)
    body_rows = []

def _serve_script_file(self, abs_path):
    try:
        with open(abs_path, "rb") as fh:
            payload = fh.read()
    except OSError:
        return self.send_html(404, self._not_found_page())
    return self.send_bytes(200, "text/javascript", payload, cache_seconds=300, public=True)

def _serve_nav_dropdown_script(self):
    return self._serve_script_file(_NAV_DROPDOWN_JS_PATH)

## Shared Patterns

### Escaping discipline
**Source:** `companion/layout.py::escape_html()` (~lines 218-230).
**Apply to:** every new dynamic value in every file above (filter query, dirty-state bar copy, card labels, disclosure summaries, `data-filter-text`/`data-copy-value` attribute values). Single choke point — no page module reaches stdlib `html` directly.

### Python→JS boundary escaping
**Source:** `companion/pages/config_page.py::_js_literal()` (~lines 197-212): `json.dumps(value).replace("</", "<\\/")`.
**Apply to:** the dirty-state bar's embedded script and any other Python-value-into-`<script>` interpolation — never `%`/f-string interpolation directly into a `<script>` body.

### `raw_columns` / verbatim-content contract
**Source:** `layout.py::stat_tile()`'s `content_html` docstring + the new `data_table(raw_columns=...)` diff above.
**Apply to:** any cell/slot receiving pre-built HTML (`concise_timestamp_html()`, `status_dot()`) — never a bare unescaped string.

### `data-filter-text` / `data-copy-value` attribute escaping
**Source:** Pitfall 5 (RESEARCH.md) — same single-escaping-choke-point discipline, applied to `data-*` attributes specifically: `'data-filter-text="%s"' % escape_html(combined_lowercased_text)`.
**Apply to:** History/Airlines row and card markup (D-20), copy-button markup (D-23).

### Breakpoint-toggle (desktop table vs. mobile cards)
**Source:** `.dashboard-sidebar`/`.mobile-nav`'s existing `display: none` + single `@media (min-width: 960px)` override pattern (`style.css`).
**Apply to:** History's `.data-table-wrap` vs. `.history-cards` (D-07) — reuse verbatim, do not invent a second breakpoint or a JS-driven show/hide.

### Native `<details>`/`<summary>` disclosure, un-animated
**Source:** first use in this codebase — no existing rule collides (`grep` confirmed zero existing `details`/`summary` rules in `style.css`).
**Apply to:** Battery readings collapse (D-08), History mobile per-card detail region (D-07). Required CSS (two rules, Safari needs both):
```css
summary { cursor: pointer; min-height: 44px; display: flex; align-items: center; }
summary::marker { color: var(--color-accent); }
summary::-webkit-details-marker { color: var(--color-accent); }
```
Do not attempt to animate open/close — cross-browser `height: auto` animation isn't reliably possible without either a new JS file (contradicts the UI-SPEC's "zero-new-JS disclosures" decision) or Chrome-only `interpolate-size`.

### Process-global / one-shot client timers (no polling)
**Source:** this project's running no-JS-floor + "prefer restrained pattern over background polling" discipline, `health_page.py`'s existing server-computed severity (never recomputed client-side).
**Apply to:** `freshness.js` — a single on-load check plus at most one deferred `setTimeout` scheduled for the threshold boundary; never `setInterval`; never independently recomputes Health's `ok`/`warn`/`error` verdict.
