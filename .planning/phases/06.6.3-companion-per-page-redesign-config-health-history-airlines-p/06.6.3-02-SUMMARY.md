## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Scoped the History card/table breakpoint toggle instead of the plan's literal unscoped `.data-table-wrap` selector**
- **Found during:** Task 2 (History/Airlines/Preview CSS)
- **Issue:** The plan's action text and `06.6.3-UI-SPEC.md` (History section, "Desktop table and mobile card list are two renders...") both specify the toggle as the bare class `.data-table-wrap { display: none; }` below 960px / `display: block;` at `>=960px`. But `.data-table-wrap` is not History-exclusive — `layout.data_table()` (consumed by `airlines_page.py` twice and `health_page.py` once) and `history_page.py`'s own hand-built table all wrap their `<table>` in a `.data-table-wrap` div. Airlines' and Health's tables have no `.history-cards` mobile-card counterpart in this phase's scope. Implementing the bare unscoped selector literally would have hidden Airlines' unresolved-prefix table and resolution-breakdown table, plus Health's battery-readings table, below 960px with nothing rendered in their place — a genuine content-loss regression on two pages this plan does not otherwise touch.
- **Fix:** Scoped both halves of the toggle to the sibling combinator `.history-cards ~ .data-table-wrap` (base rule: `display: none;`; `>=960px` rule: `display: block;`), matching History's own DOM shape where both elements render together as siblings. Since Airlines/Health never render a `.history-cards` element, their `.data-table-wrap` tables are untouched by either rule and remain visible at every width, exactly as they are today. The plan's own acceptance criteria ("an equivalently scoped selector, not the bare `.data-table th`") already anticipates and permits scoped selectors for the analogous sticky-header check; the same reasoning applies here.
- **Files modified:** `companion/static/style.css`
- **Verification:** `awk '/@media \(min-width: 960px\)/,0' companion/static/style.css | grep -c "history-cards"` returns 2 (both the `.history-cards { display: none; }` and `.history-cards ~ .data-table-wrap { display: block; }` rules land inside the breakpoint block); grep confirms `.history-cards` and `.data-table-wrap` co-occur only via this sibling selector, never as a bare unscoped `.data-table-wrap { display: none; }` rule.
- **Committed in:** `4c3205e` (Task 2 commit)
