- `preview_section(ctx)`'s panel-present branch now wraps `<img class="preview-image">` inside `<div class="preview-frame">` (D-18's bounded, centered matte treatment) and adds `width="1200" height="1600" loading="eager" decoding="async"` to the image itself (UXA-16's zero-CLS, above-the-fold hints, matching `server/panel_format.py`'s documented 1200x1600 output size) — the no-panel branch is untouched: no `<img>`, no frame, an honest sentence only.
- Resolved the D-09 caption fork PATTERNS.md flagged: the panel-present branch now builds `caption_html` directly from `layout.concise_timestamp_html()`'s raw, pre-escaped markup (never double-encoded), while the no-panel branch still routes its plain-text caption through `escape_html()` exactly as before. The now-dead `PREVIEW_CAPTION` module constant was retired rather than left pointing at unused code.
- New `_gallery_name_to_iso(name)` reverses `server/poll_loop.py::_save_to_gallery()`'s `now_iso.replace(":", "-") + ".png"` filename sanitisation — matching only the time+offset substring after the first `"T"` against a compiled regex, leaving the date portion's own hyphens untouched, and returning `None` (never raising) on a missing `"T"` separator or a malformed time+offset shape.
- `gallery_tiles()` captions now read `"Captured {concise timestamp}"` when `_gallery_name_to_iso()` recovers a real ISO string, falling back to the existing raw-filename-derived (still-escaped) caption otherwise — closing D-22 with an honest degradation path, never a crash or a blank caption. Every gallery `<img>` gained `width="1200" height="1600" loading="lazy" decoding="async"` (the off-screen-thumbnail opposite of the live preview's eager hints) and is now wrapped in `<a href="{same src}">` reusing the existing `/gallery/{name}.png` route — no new route added.
- The Gallery section's `<h2>` now reads `"Gallery — Latest 12 renders"` via the new `GALLERY_HEADING` template applied to the existing `GALLERY_DISPLAY_LIMIT` constant (D-10) — no logic change, just surfacing the already-real cap.
- `render()` now calls `layout.page_header("Preview", purpose="What the physical frame is currently showing.", freshness_html=...)` with a Refresh link carrying `data-loaded-at`, and emits the same hidden-by-default `[data-stale-banner]` shape Health's Task 3 established — independently gated from Health's own pair since `freshness.js` only ever queries the single such pair present on whichever page is currently loaded, and Health/Preview are never rendered simultaneously in one document.
- `companion/test_view_pages.py` grew 35→41 checks: `_gallery_name_to_iso()`'s well-formed/no-"T"/malformed fixtures; the matte-frame/sizing/caption behaviour re-asserted against the full `render()` output (not just the isolated `preview_section()` call); the no-panel branch's img/frame-less state re-asserted against the full `render()` output; gallery sizing/links/window-label re-asserted against the full `render()` output; a malformed gallery filename's caption fallback re-asserted against the full `render()` output; and Preview's `data-loaded-at`/`data-stale-banner` markers.
