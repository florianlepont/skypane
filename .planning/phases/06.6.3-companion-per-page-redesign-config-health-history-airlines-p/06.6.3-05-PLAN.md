| data-copy-value attribute values | Operates on already-server-escaped, already-rendered DOM text, not raw user input reaching a new HTML sink |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-06.6.3-11 | Tampering | data-copy-value attribute construction | medium | mitigate | Built from the same already-escaped row values format_event_row() already produces for on-page display — no separate unescaped derivation path exists |
