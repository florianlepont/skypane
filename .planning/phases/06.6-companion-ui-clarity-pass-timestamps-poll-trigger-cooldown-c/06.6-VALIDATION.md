# Phase 06.6 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Hand-rolled stdlib test harnesses (no pytest, no unittest) — each file defines a local `check(name, fn)` helper and a pinned `EXPECTED_CHECK_COUNT` module constant |
| **Config file** | none — each `companion/test_*.py` file is directly executable |
| **Quick run command** | `server/.venv/bin/python3 companion/test_status_pages.py` (or `test_view_pages.py` / `test_config_page.py`, matching whichever file a given task touches) |
| **Full suite command** | `scripts/run-all-tests.sh` |
| **Estimated runtime** | ~20-30 seconds |

---

## Sampling Rate

- **After every task commit:** run the single affected file's harness directly — each completes in low single-digit seconds against a fresh tempdir
- **After every plan wave:** `scripts/run-all-tests.sh`
- **Before `/gsd-verify-work`:** Full suite green
- **Max feedback latency:** ~30 seconds
