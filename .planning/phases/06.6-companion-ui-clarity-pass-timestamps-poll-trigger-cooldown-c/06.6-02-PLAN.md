3. Add `_js_literal(value)`: returns `json.dumps(value)` with every `</` occurrence in the result rewritten to `<\/`. Docstring it as the single, mandatory gate for every Python value crossing into the inline script. Two reasons, both stated: `json.dumps()` of an `int` or `str` is by construction a syntactically valid, correctly-escaped JavaScript literal, which hand-rolled quoting is not; and the `</` rewrite means no future copy change containing a closing-tag-like sequence can terminate the script element early. Add the explicit prohibition: never interpolate a Python value into the script with `%` or an f-string. Note that `json.dumps()` defaults to ASCII-only output, so the em dash in `POLL_COOLDOWN_HELPER_TEXT` is emitted as an escape sequence and the script body stays pure ASCII.

4. Add `_poll_cooldown_script(cooldown_remaining)` returning a `<script>` element with no attributes, whose body is a single immediately-invoked function expression opening with a strict-mode directive. Written in an ES5-safe subset (`var`, `function`, no arrow functions, no `let`/`const`, no template literals) so no transpiler is ever needed, matching the convention `06.5-01-PLAN.md` establishes for this codebase. The function must:

On reaching zero it calls `clearInterval`, calls `removeAttribute("disabled")` on the button, sets the paragraph's `textContent` to the empty string, and returns.

It must introduce **no HTML-writing DOM sink, no dynamic code evaluation and no network call** — the exact identifier family this forbids is enumerated verbatim in Task 2's acceptance criteria and is negatively asserted there against the rendered script body.
