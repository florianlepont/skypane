## Accomplishments
- `poll_trigger_section()`'s disabled branch now renders exactly one inline `<script>` that ticks the seeded remaining-seconds value down once per second and re-enables the button (clearing the cooldown text) at zero — the zero-cooldown branch is byte-identical to before, still ships no script.
