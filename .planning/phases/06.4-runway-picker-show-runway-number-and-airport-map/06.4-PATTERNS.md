**Existence-check pattern to mirror** (`gallery_entries`, lines 154-169):
```python
def gallery_entries(state_dir, limit=GALLERY_DEFAULT_LIMIT):
    gallery_dir = os.path.join(state_dir, GALLERY_DIRNAME)
    try:
        entries = sorted(
            (entry.name for entry in os.scandir(gallery_dir)
             if entry.is_file() and entry.name.endswith(".png")),
            reverse=True,
        )
    except OSError:
        return []
    return entries[:limit]
```
New `runway_images_available(image_dir=_RUNWAY_IMAGE_DIR)` should follow this same "defensive, never raises, returns an empty/partial collection on OSError" shape, iterating `device_config.RUNWAY_IDS` and checking `os.path.isfile()` per id (see RESEARCH.md Pattern 1 for the exact function body — already fully specified there, reuse verbatim). Critically it takes a directory parameter with a real default, exactly like `gallery_entries(state_dir, ...)` parameterizes on `state_dir` — this is what makes it unit-testable without touching `companion/static/` (Pitfall 1 in RESEARCH.md).

**Byte-serving pattern to mirror** (`_serve_stylesheet`, lines 326-332):
```python
def _serve_stylesheet(self):
    try:
        with open(_STYLE_CSS_PATH, "rb") as fh:
            payload = fh.read()
    except OSError:
        return self.send_html(404, self._not_found_page())
    return self.send_bytes(200, "text/css", payload, cache_seconds=300)
```
New `_serve_runway_image(self, runway_id)` differs from this precedent in one deliberate way: it must validate `runway_id` against `device_config.RUNWAY_IDS` **before** building any path (unlike `_serve_stylesheet()`, which has a fixed path with no request-derived component). Model the membership-then-open shape on `_serve_gallery_image`/`gallery_bytes` (lines 355-359, 172-187) instead — same file, same "validate against a known set, then open, catching OSError → 404" shape.

**Route wiring pattern to mirror** (`do_GET`, lines 392-393 and 450-453):
```python

...
```

New route block goes in this same `if/elif` chain (insert near the `GALLERY_ROUTE_PREFIX` block, before the final `return self.send_html(404, ...)` at line 458):
```python
if path.startswith(RUNWAY_IMAGE_ROUTE_PREFIX) and path.endswith(".png"):
```

```python
def runway_fieldset(current_runway_id):
    options = []
    for runway_id in device_config.RUNWAY_IDS:
        checked = " checked" if runway_id == current_runway_id else ""
        options.append(
            "<label>"
            '<input type="radio" name="tracked_runway" value="%s"%s> %s'
            "</label>"
            % (
                escape_html(runway_id), checked,
                escape_html(device_config.runway_label(runway_id)),

        "<fieldset>"
        "<legend>Runway</legend>"
```

## Shared Patterns

### Registry-membership validation before path construction
**Source:** `companion/pages/config_page.py` `handle_post()` lines 187-190:
```python
if submitted_theme is not None and submitted_theme not in device_config.THEME_IDS:
    return FLASH_SAVE_FAILED
if submitted_runway is not None and submitted_runway not in device_config.RUNWAY_IDS:
    return FLASH_SAVE_FAILED
```
**Apply to:** `companion/app.py`'s new `_serve_runway_image()` — validate `runway_id not in device_config.RUNWAY_IDS` first, return 404, and only then build any `os.path.join()` path. Never sanitize-then-join.

### Defensive filesystem I/O (never raise, degrade to empty/False)
**Source:** `companion/app.py` `gallery_entries()` lines 154-169 (`try/except OSError: return []`).
**Apply to:** `runway_images_available()` — wrap the existence-check loop so a single bad entry (permissions error, symlink loop) degrades to "no image for that runway" rather than raising and 500-ing the whole `/config` page (RESEARCH.md Pitfall 3).

### Session-gated route handling
**Source:** `companion/app.py` `do_GET()` — every data-bearing route except `STYLE_ROUTE` calls `self.require_session()` first (e.g. lines 445-448, 450-453).
**Apply to:** the new `RUNWAY_IMAGE_ROUTE_PREFIX` route — call `require_session()` as the first statement in its branch, deliberately deviating from `STYLE_ROUTE`'s unauthenticated precedent (images are only ever linked from the already-authenticated `/config` page).

### `send_bytes` helper reuse
**Source:** `companion/app.py` `Handler.send_bytes()` lines 204-213 — already handles Content-Length and Cache-Control uniformly.
**Apply to:** `_serve_runway_image()` should call `self.send_bytes(200, "image/png", payload, cache_seconds=300)`, matching `_serve_stylesheet()`'s `cache_seconds=300` and `_serve_gallery_image()`'s image-serving shape — no new response-writing helper needed.
