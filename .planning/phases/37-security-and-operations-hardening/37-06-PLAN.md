<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI runner / laptop -> VPS (ssh as ubuntu + sudo) | Code crosses into root-executed scripts |
| skypane.env (operator file) -> root script | Values used in root-owned config |
| Release tree -> running services | Services must not be able to rewrite their own code |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-37-26 | Denial of service | half-deployed code / broken release | mitigate | Stage + smoke + validate before swap; atomic mv -T; probes; automatic rollback; non-zero exit |
| T-37-27 | Elevation of privilege | sourcing skypane.env as root | mitigate | Strict sed extraction of four keys; poison-line test proves no execution |
| T-37-28 | Tampering | service rewriting its own code | mitigate | releases root:root, go-w; ProtectSystem=strict; compileall ahead of time |
| T-37-29 | Tampering | Caddyfile render injection / bad config | mitigate | render_caddyfile.sh hostname regex; caddy validate as user caddy before reload; .prev restore on rollback |
| T-37-30 | Tampering | shipping uncommitted or local files (skypane.env, state) | mitigate | git archive of one SHA and an explicit path list |
| T-37-31 | Denial of service | first cutover with no previous release | mitigate | Explicit "no previous release" failure; old in-place dirs kept as manual fallback (Plan 37-09) |
</threat_model>
