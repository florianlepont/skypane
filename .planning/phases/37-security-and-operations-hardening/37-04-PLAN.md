<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mac (pull key holder) -> VPS gate | SSH_ORIGINAL_COMMAND is attacker-controlled if the key leaks |
| Live state (skypane) -> archives (group skypane-backup) | Only archives, never live state, cross to the pull user |
| VPS -> Mac | Downloaded bytes must be verified before they replace anything |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-37-16 | Information disclosure | stolen pull key reads skypane.env / live state | mitigate | Gate verbs only; name regex + S_ISREG + fixed archive dir; env file never archived; restrict,command= (Plan 37-07) |
| T-37-17 | Tampering / injection | SSH_ORIGINAL_COMMAND | mitigate | shlex.split, exact verb/arity, no shell/eval; unbalanced quotes -> exit 2 |
| T-37-18 | Tampering | torn/corrupt snapshot of WAL database | mitigate | sqlite3 backup API + integrity_check; tmp + fsync + os.replace |
| T-37-19 | Tampering | corrupted download on the Mac | mitigate | sha256 compare before mv; partial deleted; no ack on failure |
| T-37-20 | Information disclosure | calendar_url.secret / notification topic in archives | accept | Archives 0640 skypane:skypane-backup on the VPS; Mac copies protected by FileVault (encryption at rest deferred per CONTEXT) |
| T-37-21 | Denial of service | disk fill from archives | mitigate | --keep 14 on the VPS; Mac retention 30 + monthly |
</threat_model>
