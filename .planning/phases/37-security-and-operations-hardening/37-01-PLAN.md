<objective>
Wave A — SEC-01 per-client-IP login throttle, plus the companion `--bind` flag (D-22).

External dependency: Phase 32 only (D-01). This plan must not start until Phase 32's pytest
infrastructure is on `main`; Task 1 opens with that gate. No dependency on Phase 36.

Purpose: today `LoginThrottle` is process-global, so five wrong guesses from anyone lock the owner
out (audit SEC-01). Keying on the client IP (trusted `X-Forwarded-For` from loopback Caddy, D-14)
means failed logins from one IP never lock another (ROADMAP SC-1). The `--bind` flag lets
`skypane-companion.service` (Plan 37-03) bind loopback only, which a systemd IP filter cannot do
because the companion makes outbound calls (D-22 supersedes D-18's companion filter).

Output: keyed throttle + `client_ip()`/`login_throttle_key()` in `companion/auth.py`, login handler
and `--bind` in `companion/app.py`, pytest file `companion/test_login_throttle.py`, legacy throttle
checks ported to the keyed API.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet -> Caddy -> companion | Untrusted clients; Caddy sets X-Forwarded-For from the real peer and drops client-sent values (no trusted_proxies) |
| Direct TCP -> companion port | Should not exist in production (ufw deny 8643, --bind 127.0.0.1 at cutover); dev/LAN only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-37-01 | Denial of service | LoginThrottle | mitigate | Per-IP buckets: a stranger's failures lock only the stranger's key (SC-1 test) |
| T-37-02 | Spoofing | client_ip() XFF parsing | mitigate | XFF honoured only from a loopback peer; right-most entry (the one Caddy appended); ipaddress parsing, fallback to peer |
| T-37-03 | Denial of service | per-IP table memory | mitigate | max_entries cap with stale-first then LRU eviction; IPv6 keyed by /64 |
| T-37-04 | Elevation / bypass | companion reachable without Caddy | mitigate | --bind flag; unit passes --bind 127.0.0.1 (Plan 37-03); ufw deny 8643 unchanged |
| T-37-05 | Spoofing | attacker evicts own locked entry by spraying | accept | Only resets the attacker's own bucket; password is a long random secret, throttle is a courtesy guard |
</threat_model>
