<objective>
Wave A — off-box backup freshness on the companion Health page (SEC-04, D-07, D-23).

External dependency: Phase 32 only (D-01); Task 1 opens with the Phase 32 gate.

Purpose: an off-box backup nobody notices has stopped is not a backup. Each successful Mac pull
leaves a marker on the VPS (written by the forced-command gate, Plan 37-04); the Health page shows
"last off-box backup N ago" and warns when it is older than 3 days or has never happened; the
warning also lights the Health nav dot at warn level (D-23). No new page.

Marker contract (shared with Plan 37-04 backup_gate.py `ack`): the file named by env var
SKYPANE_OFFBOX_MARKER (production: /var/lib/skypane-backup/pulled/last-pull) contains one archive
name matching `^skypane-state-(\d{8}T\d{6}Z)\.tar\.gz$` plus an optional trailing newline. Freshness
is computed from the snapshot time in that name (RESEARCH §SEC-04 "The marker holds the archive name").

Output: health_page.py changes, FR strings, pytest file.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Marker file -> companion | Written by backup_gate.py running as skypane-backup (a key holder can only write names of archives that exist); read by the companion as skypane |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-37-06 | Tampering | marker content rendered into HTML | mitigate | Strict regex on the name; only the parsed timestamp is rendered; escape_html on all other strings; 256-byte read cap |
| T-37-07 | Denial of service | malformed/huge marker breaks every page | mitigate | offbox_backup_status never raises (warn on any error); safe_health_state already fails closed |
| T-37-08 | Repudiation | stale backup goes unnoticed | mitigate | Warn after 3 days or when never pulled; nav dot warn (D-23) |
| T-37-09 | Spoofing | stolen pull key acks a fresh name to hide a stopped pull | accept | Gate only acks archives that exist; freshness comes from the real snapshot time |
</threat_model>
