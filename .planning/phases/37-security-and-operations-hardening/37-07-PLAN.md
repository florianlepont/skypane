<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet -> sshd | Brute force against root and passwords |
| Mac pull key -> VPS account | Key must not grant a shell or read secrets |
| Service user skypane -> skypane.env | The env file holds every secret |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-37-32 | Elevation of privilege | root SSH login | mitigate | PermitRootLogin no in 00-skypane.conf; key-only; MaxAuthTries 3 |
| T-37-33 | Denial of service | SSH lock-out from a bad drop-in | mitigate | sshd -t before reload, restore on failure; CP-3 keeps a session open |
| T-37-34 | Information disclosure | skypane.env readable by the service user | mitigate | root:root 600 in provision; README; verified at CP-3 |
| T-37-35 | Elevation of privilege | pull key with a shell / option injection | mitigate | Key regex (ed25519, no options/quotes); restrict,command=; root-owned 0644 authorized_keys; shell /bin/sh only runs the forced command |
| T-37-36 | Tampering | skypane-backup writing live state via group | mitigate | Dedicated group; explicit removal from group skypane; archives dir setgid skypane-backup |
| T-37-37 | Tampering | service rewriting venv/code | mitigate | venv and releases root-owned; /opt/skypane root:skypane 0750 |
</threat_model>
