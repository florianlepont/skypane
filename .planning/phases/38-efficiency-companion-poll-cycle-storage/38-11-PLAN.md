<objective>
Keep each provider's rate limit across back-to-back cycles now that the fixed sleep is gone
(EFF-06, second part; ROADMAP criterion 4).

Purpose: the old sequential sleep accidentally guaranteed spacing between two calls to the same
provider when `/poll-now` ran right after a timer cycle. The poll loop now reads each provider's
last-call time from history.db meta before detection and writes the updated times in the cycle's
single transaction (meta, not poll_state, so poll_state still changes only when content changes).
Output: poll_loop wiring, one meta key prefix, tests.
</objective>
