<objective>
Remove the fixed 1.1 s sleep between two different providers and query them in parallel, while
keeping each provider's own rate limit (EFF-06, ROADMAP criterion 4).

Purpose: the fixed sleep is ~90 % of a no-network cycle. Within one cycle each provider is called
once, so no limit applies there; the real hazard is two cycles back to back (timer cycle then
`/poll-now`), handled by the `last_call_at` map that the poll loop will persist (later plan).
detect stays a leaf module: it never imports history_db.
Output: parallel `poll_current_aircraft(..., last_call_at=None, clock=None, sleep=None)`, tests,
COMPLIANCE.md wording.
</objective>
