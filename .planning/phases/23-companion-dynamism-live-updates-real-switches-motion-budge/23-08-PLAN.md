   an enhancement over a page that is correct on load. Neither adds a control.

Binding constraints:
- `interpolate-size` / `calc-size()` are banned by plan 23-01's guard and by
  Baseline: Chromium-only. `grid-template-rows: 0fr -> 1fr` is the mechanism, and
  it is the one D3's own audit text names.
- A `<tr>` is not a grid container and `display` is discrete. The animation belongs
  to a wrapper INSIDE the `<td>`, not to the row box. Whatever keeps the collapsed
  row out of the tab order and the accessibility tree — `display` toggled with
  `transition-behavior: allow-discrete`, or simply not animating the collapse
  direction — must be chosen deliberately and stated, and it must be the property
  the harness asserts.
- The chevron transition gets NO per-rule reduced-motion block.
  `references/control-density.md:78` says so in advance: "the global
  prefers-reduced-motion block already covers a plain transform for free, and a
  per-rule block here would be dead code, not a safety net."
- The highlight is one-shot and never fires on first paint. A page that highlights
  every row on load has told the user nothing.
- Do not touch the Flights table's column count, its stacked When/Flight cells or
  its scoped 8px cell padding. `references/data-density.md` records the measured
  width budget those decisions were taken against.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| refetched page markup → the live list | swapped rows carry server-rendered flight data into a document being read |
| a row identity attribute → a client-side diff | markup-sourced values drive which rows are highlighted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-29 | Tampering | a new DOM sink while highlighting swapped rows | mitigate | the swap mechanism is unchanged (`DOMParser` + `importNode` + `replaceChild`); the highlight is a class toggle on an existing node and writes no markup |
| T-23-30 | Spoofing | a highlight implying a detection that did not happen | mitigate | the diff is over server-rendered row identity, applied only when a previous set exists, asserted in both directions in a browser |
| T-23-31 | Denial of Service | a fourth page polling | mitigate | the same cadence, visibility gate and retry ladder as the other three; a hidden tab still issues zero requests |
| T-23-32 | Information Disclosure | detail-row content present but visually collapsed | mitigate | the collapsed row is kept out of the tab order and the accessibility tree, asserted by a keyboard-reachability check rather than by a visual one |
| T-23-SC | Tampering | npm/pip/cargo installs | n/a | this plan installs zero packages in any ecosystem |
</threat_model>
