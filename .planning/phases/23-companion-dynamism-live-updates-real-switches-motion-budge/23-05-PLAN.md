<objective>
Plan 23-03 gave the app `<time data-relative>` elements whose text is correct at
render time and frozen afterwards. This plan makes them move, and it finishes D22
by making the one place that claims to be live actually look live — and, more
importantly, look NOT live the moment it stops being.

Purpose: a page that says "Updated 14:32" is telling the truth about a moment and
saying nothing about now. D22's whole point is honesty: a dot that breathes while
the loop is running, a dot that stops when it is paused, and an age that ticks so
a stale page announces its own staleness. T13 (22-15) already built the hard half
— the backoff ladder, the in-flight guard and the neutral Paused/Reconnecting
badge — so this plan adds the two things it deliberately left for Phase 23 and
re-implements none of it.
Output: a thirteenth script, a breathing dot, a ticking age, and three pinned
contracts that stop the ladder drifting from its Python definition.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a `datetime` attribute in the DOM → a script that formats it | markup-sourced input reaching client code |
| a one-second interval → the browser's main thread and the device's battery | a permanent timer on every authenticated page |
| the loop's internal state → a visual claim about liveness | the user believes the dot |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-13 | Tampering | a new DOM sink in the thirteenth script | mitigate | `textContent` only; `innerHTML`/`insertAdjacentHTML`/`document.write`/`eval` banned and pinned by name for this file in `test_companion_app.py`, asserted by an acceptance grep |
| T-23-14 | Denial of Service | a one-second interval running in every background tab forever | mitigate | the `visibilitychange` gate is copied from `freshness.js`'s own policy and proven by a browser check that a hidden tab's text does not change |
| T-23-15 | Spoofing | a dot that breathes while the page is not actually listening | mitigate | the class is toggled only where the loop's own state changes, never by a second timer; pinned by source scan and by the paused/reconnecting browser check 22-15 already ships |
| T-23-16 | Tampering | an unparseable or hostile `datetime` value | mitigate | the script parses defensively and leaves the server-rendered text in place on failure, the same parse-or-noop discipline `freshness.js:218-222` uses; every `datetime` is server-computed and escaped at render |
| T-23-17 | Elevation of Privilege | a new same-origin script | mitigate | `script-src 'self'` unchanged, no inline script, no nonce, no vendored library; served by its own route with no session data in it |
| T-23-SC | Tampering | npm/pip/cargo installs | n/a | this plan installs zero packages in any ecosystem |
</threat_model>
