Close D-03 — the mobile table-crop fix that `STATE.md` describes as covering "Airlines/History" but which only ever reached Airlines and Health — and add the one markup hook the Config page's desktop two-column layout needs.

Output: a two-string-literal change in `history_page.py`, a one-attribute change in `config_page.py`, and one new regression check in each page's existing test harness.
</objective>
