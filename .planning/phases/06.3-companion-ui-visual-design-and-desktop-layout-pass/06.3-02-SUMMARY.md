- Revised Dominant/Secondary/Accent hex values at all four theme-declaration sites (`:root`, `prefers-color-scheme: dark`, `data-ui-theme="light"`, `data-ui-theme="dark"`) and added a new `--color-border` token at the same four sites — the D-01 refresh propagates app-wide purely through token values, since every existing rule already reads these custom properties
