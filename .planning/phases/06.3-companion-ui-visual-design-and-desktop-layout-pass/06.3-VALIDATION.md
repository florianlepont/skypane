> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Hand-rolled stdlib `check()` harness (no pytest, no unittest) |
| **Config file** | none — each `test_*.py` is directly executable |

| **Estimated runtime** | ~30-45 seconds |

---

## Sampling Rate

- **After every task commit:** Run the specific `test_*.py` file(s) touched by that task
- **After every plan wave:** Run `scripts/run-all-tests.sh`
- **Before `/gsd-verify-work`:** Full suite green, **plus** a manual browser check at 960px/1440px/mobile widths — this phase's core value (does the dashboard actually look right) cannot be verified by the automated suite alone
- **Max feedback latency:** ~45 seconds (automated); manual browser check is a separate, explicit checkpoint
