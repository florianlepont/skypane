<interface_contract>
## Consumed from plan 06.3-01 (`companion/layout.py`)

```
stat_tile(caption, content_html, status=None) -> str
```
- `caption` is escaped by the builder — pass a plain string, never pre-escaped markup.
- `content_html` is interpolated verbatim and must never be pre-escaped by the caller. Pass the section builders' existing return values unchanged.
- `status` accepts `"ok"`, `"warn"`, `"error"`, or `None`/anything else (which resolves to the accent-neutral class).
- Returns a `<div class="stat-tile stat-tile--{state}">` whose first child is a `<p class="text-label stat-tile__caption">`.

## Consumed from plan 06.3-02 (`companion/static/style.css`)

- `.dashboard-grid` — `repeat(auto-fit, minmax(240px, 1fr))` with the `lg` gap. Emit tiles as direct children of one `<div class="dashboard-grid">`; do not nest an extra wrapper between the grid and a tile, which would collapse the grid to a single item.
- `.stat-tile` — carries `min-width: 0`, the fix that lets the Battery tile's nested table shrink instead of stretching its grid track.
- `.stat-tile__value` — the Display-size class available for a headline number, should a tile want one.
</interface_contract>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06.3-01 | Tampering (stored XSS) | The six new `layout.stat_tile()` call sites | high | mitigate | Captions are literal in-module strings or existing module constants — never a database value, never a request value — and `stat_tile()` escapes them regardless. | T-06.3-SC | Tampering (supply chain) | npm/pip/cargo installs | n/a | accept | No package-manager install occurs. `06.3-RESEARCH.md`'s Package Legitimacy Audit records this phase as installing zero external packages; both page modules import only in-repo modules and the stdlib. Categories not applicable: Spoofing, Information Disclosure, Elevation of Privilege — no identity, no newly exposed data (both pages already render every value shown), and no privilege boundary in this plan.
