Model (from 46-RESEARCH.md "Two-Run Model", units of the run-one charge Q1):
- Per run: Q = N x E + P x T, where N is observed polls in the window (first poll to cut poll inclusive) and T is seconds from first poll to cut poll.
- Generalised solve with wake-energy ratio k = E_run1 / E_run2 and usable-capacity ratio d = Q2/Q1 - 1: a = N1 x k, b = T1, e = N2, f = T2, det = a x f - b x e; E = (f - b x (1 + d)) / det; P = (a x (1 + d) - e) / det. With k = 1, d = 0: r = E/P = (T1 - T2)/(N2 - N1), ceiling Q/P in seconds = N1 x r + T1.
- Autonomy to the park at mean period g seconds: days = g / (E + P x g) / 86400.
- mAh per wake = E x capacity_mah; standing mA = P x capacity_mah x 3600.
