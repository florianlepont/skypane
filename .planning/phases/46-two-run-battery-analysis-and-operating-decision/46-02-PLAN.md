## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| companion Device form -> device_config.json | Authenticated operator input becomes the frame's sleep duration |
| device_config.json / poll_state.json -> GET /device/v1/display | Stored state becomes the sleep_s the battery-powered frame obeys |
| frame X-Battery-Mv header -> sleep chain | Device-reported reading can lift the park for the current reply |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-46-06 | Tampering / Denial of service | wake_interval_s value reaching the frame | mitigate | Tests prove values are bounded 60..3600 end to end (save rejects out-of-range; read_wake_interval_s falls back); the existing fail-open tests stay green |
| T-46-07 | Elevation of privilege (safety) | Saved interval bypassing the battery park or display-off pin | mitigate | HTTP precedence matrix asserts 3600 under the latch and 300 with the display off for every candidate interval |
| T-46-08 | Spoofing | A forged high X-Battery-Mv lifting the park | accept | Requires the device bearer token (existing auth, unchanged); the lift affects one reply and the poll cycle re-latches at the next low reading; behaviour unchanged by this plan |
| T-46-09 | Information disclosure | Test fixtures carrying real host, MAC or secret | mitigate | Synthetic MAC and secret only, local 127.0.0.1 subprocess, tmp_path state dir |
| T-46-SC | Tampering | Package installs | accept | No installs |
