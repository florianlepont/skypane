Functions:

`manual_resolutions_path(state_dir)` — `os.path.join(state_dir, MANUAL_RESOLUTIONS_FILENAME)`.

`normalise_prefix(raw)` — non-string or falsy returns `None`; otherwise `raw.strip().upper()` tested against `_PREFIX_RE`, returning the 3-letter prefix or `None`. Never raises.

`normalise_manual_airline_name(raw)` — non-string returns `None`; strip; empty returns `None`; longer than `MANUAL_AIRLINE_NAME_MAX_LEN` returns `None`. Never raises. (Length and emptiness are distinguished by `add_entry()` itself so it can return distinct rejection reasons; this helper is the shared strip/type gate.)

`illustration_key_for_name(airline_name)` — runs `illustrations.normalise_airline_key(airline_name)`, then returns the slug only when it matches `_SAFE_KEY_RE` and does not start with `RESERVED_KEY_PREFIX` and is not equal to `GENERIC_FALLBACK_FILENAME` with its `.png` suffix removed; otherwise `None`. This is the single function every other module in this phase calls to turn a stored name into an illustration key — plan 13-06 uses it to build the membership union, plan 13-04 uses it to decide whether artwork already exists.

`load_manual_resolutions(state_dir)` — never raises. Missing/unreadable file, invalid JSON, or a non-dict top level all yield `{}`. Then iterate the parsed dict in `sorted()` key order, dropping any entry where `normalise_prefix(key)` is `None`, the value is not a dict, `normalise_manual_airline_name(value.get("airline_name"))` is `None`, `illustration_key_for_name(...)` is `None`, or `value.get("created_at")` is not a string. Stop after `MANUAL_RESOLUTION_MAX_ENTRIES` surviving entries so a hand-edited oversized file cannot make a page render unbounded. Return `{prefix: {"airline_name": name, "created_at": created_at}}` — rebuilt values only, never the parsed dicts themselves.

`add_entry(state_dir, prefix, airline_name, now=None)` — returns one of the `ADD_*` constants and never raises. Order: normalise prefix (-> `ADD_REJECTED_PREFIX`); type/strip the name, empty -> `ADD_REJECTED_NAME_EMPTY`; over-length -> `ADD_REJECTED_NAME_TOO_LONG`; `illustrations.normalise_airline_key()` returning `None` or failing `_SAFE_KEY_RE` -> `ADD_REJECTED_NAME_EMPTY`; reserved slug -> `ADD_REJECTED_NAME_RESERVED`; load the current registry, and when the prefix is absent and `len(registry) >= MANUAL_RESOLUTION_MAX_ENTRIES` -> `ADD_REJECTED_FULL`. Only then touch the filesystem: `now` defaults to `datetime.now(timezone.utc).isoformat(timespec="seconds")`; set `registry[prefix] = {"airline_name": name, "created_at": now}` (an add on an existing prefix overwrites, with a fresh `created_at` — D-07 makes delete-and-re-add the correction path, so an overwrite is a new entry); `os.makedirs(state_dir, exist_ok=True)`; write to `path + ".tmp"` with `json.dump(..., indent=1)`; `os.replace(tmp, path)`; on any exception remove the stray tmp inside a nested try/except and return `ADD_FAILED` rather than re-raising (this differs from `save_device_config()`, which raises — the caller here is an HTTP route handler that needs a flash key, not a traceback; say so in the docstring).

`delete_entry(state_dir, prefix)` — returns `True` when an entry was removed, `False` otherwise (unknown prefix, malformed prefix, or a write failure). Idempotent, never raises. **It rewrites the JSON file and nothing else — it must not construct, stat, or unlink any path under the illustration override directory (D-08).** State the reason in the docstring: the override is keyed on the *airline name*, so two prefixes resolved to the same carrier share one file and the existing Airlines gallery flow can have written that same key by a different path; never delete a file from a path that does not own it. Note the accepted cost (orphaned PNGs, no garbage collection) explicitly.

`entry_rows(registry)` — takes an already-loaded registry dict and returns a list of `(prefix, airline_name, created_at)` tuples sorted by prefix ascending, skipping any malformed entry. Mirrors `health_page.unresolved_rows()`'s defensive shape so the management list in plan 13-04 renders deterministically.

Process-cache pair, mirroring `illustrations.set_override_state_dir()`:
- `_cached_registry = None` at module level.
- `set_manual_registry_state_dir(state_dir)` — sets the module-level cache to `load_manual_resolutions(state_dir)` when `state_dir` is truthy, else `{}`. Docstring: call once per poll cycle from `run_once()`, beside the existing `illustrations.set_override_state_dir(state_dir)` call, for exactly the reason `poll_loop.py`'s own comment gives for `device_cfg` — a companion-side save landing mid-cycle must not split one cycle across two registries.
- `airline_name_for_prefix(prefix)` — reads only the cache, never the disk; returns the stored name for a normalised prefix or `None`. Docstring must state that a process which never calls the setter sees an empty registry, i.e. exactly today's behaviour, which is what keeps every existing `enrich` test unchanged.
