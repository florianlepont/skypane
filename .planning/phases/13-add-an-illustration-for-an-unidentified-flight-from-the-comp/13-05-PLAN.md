<objective>
Wire the registry into the poll cycle and implement D-14's cleanup call site: one setter call beside the existing `illustrations.set_override_state_dir(state_dir)` call, and one unconditional cleanup call beside the existing `unresolved_prefixes` bookkeeping.

Purpose: this is what makes a manual resolution actually reach the glass, and what stops Health from listing a gap the operator has already closed. Both are two-line changes in `run_once()`, and both are easy to place wrongly — the setter in `main()` instead of `run_once()` (which would silently skip the companion's in-process poll trigger), and the cleanup gated on `route_source` (which would leave stale entries whenever adsbdb happened to answer). The plan is small; its value is in placing both correctly and proving it.

Output: two call sites, a comment sweep, and four harness checks.
</objective>
