<objective>
Build the foundation both extraction plans depend on, and capture the pre-split
measurements that nothing can reconstruct once the file has been cut.

Three things happen here and nothing else: (1) provision the local interpreter
and capture the pre-split baseline (per-harness timing at JOBS=4, and the full
96-check PASS/FAIL transcript); (2) create the shared helper module
`companion/test_browser_ux_helpers.py` by relocating `companion/test_browser_ux.py`'s
module-level preamble verbatim; (3) rewire `companion/test_browser_ux.py` to import
from it and prove it still runs 96/96.

**Zero checks move in this plan.** That is deliberate: it isolates the riskiest
mechanical change (relocating ~2,600 lines of shared helpers) from the check
relocation in plans 02/03, so a failure here is unambiguously an import problem
and not a hidden cross-check state dependency.

Purpose: plans 02 and 03 both need shared helpers importable from a third file
(D-04's incremental extraction is impossible otherwise — RESEARCH.md found
`_quiet_arc_minutes` is called from both a leaving block and a staying check, and
this plan's own verification found `_handle_sel` is a second instance of exactly
that shape). Plan 04's D-05 measurement needs a pre-split baseline that stops
existing the moment plan 02 lands.

Output: `companion/test_browser_ux_helpers.py`, a reduced-by-preamble
`companion/test_browser_ux.py` that still passes 96/96, `31-BASELINE-CHECKS.txt`,
and `31-TIMINGS.md` seeded with the pre-split numbers.
</objective>
