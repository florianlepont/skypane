## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-10-01 | Tampering | config values reaching detection and render | high | mitigate | `load_device_config()` normalises both ids through a membership test and is documented never to raise, so a corrupted or hand-edited file yields the defaults and the cycle completes. A dedicated check asserts a cycle survives invalid JSON on disk. |
| T-06-10-02 | Denial of Service | history row growth | medium | mitigate | Rows are written only on a hex, state or corroboration transition; the always-changing per-cycle timestamp lives in the fixed-size meta table. Pitfall 1's arithmetic is recorded in the gating function's docstring so the rule is not silently relaxed later. |
| T-06-10-03 | Denial of Service | gallery disk growth | medium | mitigate | A hard cap of 25 entries with oldest-first pruning, and the hook fires only when the panel bytes actually changed, so an unchanged cycle cannot accumulate duplicates. |
| T-06-10-04 | Denial of Service | e-ink refresh storm during an outage | medium | mitigate | The fault re-render is gated strictly on the flag's *transition*, never on its value. A full panel refresh takes roughly 31.5 seconds on this hardware per the Phase 1 measurement; re-rendering every 30-second cycle during an outage would leave the display permanently refreshing and drain the battery for no new information. |
| T-06-10-05 | Denial of Service | history or gallery failure breaking the poll cycle | high | mitigate | Both hooks are wrapped to catch the database and operating-system error classes, log one line and return. | T-06-10-08 | Repudiation | false alert on an ordinary quiet period | medium | mitigate | `_classify_source_fault()` returns true only on an all-providers-failed diagnostics report and explicitly not on an empty selection, with the seed document's reasoning recorded in its docstring and asserted by two opposing checks. |
| T-06-10-SC | Tampering | package installs | high | accept | No package manager runs; all imports are stdlib or already-present project modules. |
