`companion/auth.py` is stdlib-only: `hashlib`, `hmac`, `http.cookies`, `os`, `time`, `secrets`. It must not import Pillow, `sqlite3`, or anything under `server/`.

Constants and their rationale, stated in the module docstring:
- `PASSWORD_ENV_VAR` naming the environment variable that holds the shared password. Use the name `SKYPANE_COMPANION_PASSWORD` — plan 06-11 adds the matching entry to `deploy/skypane.env.example` and the matching `EnvironmentFile=` reference in the new systemd unit. - `SESSION_TTL_S = 12 * 3600`. Record the reasoning (06-RESEARCH.md Open Question 3): long enough that a single operator is not re-prompted during a working session, short enough that a leaked cookie does not stay valid indefinitely; it is a tunable, not an architectural commitment.
- `SESSION_COOKIE_NAME` and `UI_THEME_COOKIE_NAME`. Use `sp_session` and `sp_ui_theme`.

`AuthNotConfigured(RuntimeError)`: raised by `configured_password()` when the environment variable is absent or empty. `companion/app.py` (plan 06-05) turns this into a startup refusal — the service must not run with authentication silently disabled.

`configured_password()`: return the environment value as bytes, raising `AuthNotConfigured` when unset/empty. Never include the value in the exception message.

`password_ok(submitted)`: coerce a non-string submission to an empty string, encode, and compare with `hmac.compare_digest()` against `configured_password()`. Never use `==`. Pitfall 4 is the reason; cite it in the docstring.

`issue_session_token()`: build the payload as the integer expiry (now plus TTL) rendered as a decimal string, sign it with `hmac.new(configured_password(), payload, hashlib.sha256).hexdigest()`, and return payload and signature joined by a single dot. Stateless by design — there is no server-side session store to leak, to grow unbounded, or to lose on restart, which is appropriate for one shared secret with no per-user revocation requirement.

`verify_session_token(value)`: return `False` (never raise, never leak a reason to the caller) for a non-string, an absent separator, a signature mismatch under `hmac.compare_digest()`, a non-integer expiry, or an expiry at or before now. Verify the signature **before** parsing the expiry so a forged token cannot influence control flow through its payload.

`session_set_cookie_header(token)` / `logout_set_cookie_header()`: return the `Set-Cookie` header *value* (the handler supplies the header name). Both must carry `HttpOnly`, `Secure`, `SameSite=Strict` and `Path=/`. Pitfall 3 explains each: HttpOnly keeps the token out of reach of injected script, `SameSite=Strict` is the CSRF control for the state-changing endpoints (there is exactly one origin and no legitimate cross-site use), and `Secure` is unconditional because Caddy always terminates TLS in front of this service. The logout variant sets an empty value with `Max-Age=0`.

`parse_cookies(header_value)`: use `http.cookies.SimpleCookie`, wrapped so a malformed header yields an empty dict instead of raising, and return a plain name-to-value dict.

`LoginThrottle`: a tiny class holding an in-process failure count and a lockout deadline, with `record_failure()`, `record_success()`, `locked_out()` and `seconds_remaining()`. Deliberately global to the process, not per-session: D-01/D-02 mean there are no distinct users, so a per-session counter would be defeated by opening a second tab. Note in the docstring that this is a courtesy guard for a single-user personal tool, not a defence against a distributed attacker, and that the real strength is the length of the operator-generated shared secret.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet → the new nip.io subdomain → companion service | A new, publicly reachable HTTP surface whose only access control is one shared password. This is the primary new attack surface the whole phase introduces. |
| browser cookie jar → `verify_session_token()` | An attacker-controllable string is presented as proof of authentication on every request. |
| ADS-B / adsbdb feed values → `escape_html()` → rendered page | Airline names, callsigns and unresolved prefixes originate from external feeds and are displayed inside an authenticated admin page. |
| process environment → `configured_password()` | The shared secret enters the process from a gitignored env file loaded by systemd. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-04-01 | Spoofing | `verify_session_token()` | critical | mitigate | Signature verified with `hmac.compare_digest()` over an HMAC-SHA256 of the expiry payload, keyed by the shared password, *before* the payload is parsed. A forged or truncated token cannot influence control flow. Forged-secret and flipped-signature checks in Task 3 assert it. |
| T-06-04-02 | Information Disclosure | `password_ok()` | high | mitigate | `hmac.compare_digest()` only; the acceptance criteria grep for a direct equality comparison against the configured password and must find none (Pitfall 4). |
| T-06-04-03 | Elevation of Privilege | unconfigured password | critical | mitigate | `configured_password()` raises `AuthNotConfigured` when the environment variable is unset or empty; plan 06-05 turns that into a startup refusal, so the service can never come up with authentication silently disabled. Failing closed is the whole point. |
| T-06-04-04 | Information Disclosure | session cookie theft | high | mitigate | `HttpOnly` keeps the token out of injected script's reach, `Secure` is unconditional because Caddy always terminates TLS in front, and a 12-hour TTL bounds the value of a leaked token (Pitfall 3). |
| T-06-04-05 | Tampering | CSRF against the state-changing routes | high | mitigate | `SameSite=Strict` on the session cookie. There is exactly one origin and no legitimate cross-site use case, which is why a separate CSRF-token mechanism is not warranted for a single-user tool. The CFG-09 theme control is a form POST rather than a link precisely so no state change happens on a GET. |
| T-06-04-06 | Tampering | stored/reflected XSS via feed-sourced text | high | mitigate | One canonical `escape_html()` helper in `layout.py`; every page module imports it and no module calls `html.escape` directly, making the obligation auditable with a single grep. `data_table()` and `status_dot()` escape internally so a page author cannot forget. |
| T-06-04-07 | Elevation of Privilege | brute-forcing the shared password | medium | mitigate | Process-global `LoginThrottle` (not per-session — a per-session counter is defeated by a second tab, Pitfall 8's reasoning applied to login). Documented honestly as a courtesy guard for a single-user tool; the real strength is the operator-generated secret length that `deploy/skypane.env.example` prescribes. |
| T-06-04-08 | Information Disclosure | secret leaking into logs or errors | high | mitigate | The module is `print()`-free, the password value is never interpolated into any string other than the HMAC input, and `AuthNotConfigured`'s message names only the variable, never a value. A Task 3 check asserts the exception text does not contain the test password. |
| T-06-04-SC | Tampering | package installs | high | accept | Zero new packages. The stdlib-only recommendation was selected over the Flask alternative, so 06-RESEARCH.md's six `[SUS]` Package Legitimacy entries do not apply and no install checkpoint is required. Any future switch to Flask must re-run that audit with real network access first. |
