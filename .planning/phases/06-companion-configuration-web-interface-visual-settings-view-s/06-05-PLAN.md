**Startup refusal.** In `main()`, call `auth.configured_password()` once before binding the socket. On `AuthNotConfigured`, print a message naming the environment variable (never a value) to stderr and exit non-zero. The service must never come up with authentication disabled.

**Handler.** Subclass `BaseHTTPRequestHandler` with class attributes `args` and set before `serve_forever()`, exactly as `byos_server.py` does. Provide:
- `send_html(code, html_str)` — Content-Type `text/html; charset=utf-8`, explicit Content-Length.
- `send_bytes(code, content_type, payload, cache_seconds=0)` — used for the stylesheet and the PNG routes.
- `redirect(location, set_cookie=None)` — a 303 See Other, so a successful POST is followed by a GET and a browser reload cannot re-submit the form.
- `require_session()` — parse the cookie header with `auth.parse_cookies()`, verify with `auth.verify_session_token()`, and on failure redirect to the login route and return `False`. Every route branch except the login routes, the stylesheet, and the theme-toggle POST calls this first and returns immediately when it is false.
- `read_form()` — read Content-Length bytes, decode, `urllib.parse.parse_qs`, and return a plain single-value dict. Cap the body at a small explicit byte limit (a few kilobytes is far more than any form here needs) and treat an oversized or undecodable body as an empty form rather than raising.
- `page_context()` — build the `ctx` dict every page module receives: `state_dir`, `ui_theme` (from `layout.ui_theme_from_cookie()`), `device_config` (from `device_config.load_device_config()`), `flash` (a message name read from the query string and mapped through a fixed dictionary of allowed flash keys to their 06-UI-SPEC.md copy — never render a message supplied verbatim by the query string), and a `now` timestamp. Document this dict's keys as the page-module contract.
- `log_message()` — override to print method and path only, matching `byos_server.py`'s own override. Never log a header, a cookie, a form body, or a query string.

**Routes.** A flat `if self.path == ...` dispatch table, exactly `byos_server.py`'s shape (06-RESEARCH.md's Don't Hand-Roll table: six routes do not need a framework router). Split the path from the query string with `urllib.parse.urlsplit` before comparing, so a query string never causes a route miss.

`do_GET`:
- login route — render the login form; when already authenticated, redirect to the config route instead.
- the stylesheet route — serve `companion/static/style.css` from a path resolved at import time relative to this module's own directory, with a Content-Type of `text/css`. No auth (a stylesheet reveals nothing and the login page needs it).
- the five tab routes — `require_session()`, then call the matching page module's `render(ctx)` and wrap it with `layout.page_shell()`.
- the preview image route — `require_session()`, then `panel_preview.read_panel_file()` plus `panel_png_bytes()`; a missing file returns 404 with the empty-state copy, a `PanelDecodeError` returns 503 with 06-UI-SPEC.md's "temporarily unavailable" copy.
- the gallery image route — `require_session()`, then serve one file from the gallery directory. Resolve the requested name by **listing the gallery directory and selecting an exact match from that listing**; never join the client-supplied string onto a path (T-06-05-02). A name not in the listing is a 404.
- logout — clear the cookie and redirect to login.
- anything else — 404 carrying 06-UI-SPEC.md's "Page not found." copy and a link back to Config.

`do_POST`:
- login route — throttle check first via `auth.LoginThrottle`; when locked out, re-render the login form with the remaining seconds and do **not** evaluate the password at all. Otherwise `auth.password_ok()`; on success issue a token, set the cookie, record the throttle success and redirect to Config; on failure record the throttle failure and re-render with 06-UI-SPEC.md's "Incorrect password. Try again." copy.
- the config route — `require_session()`, `read_form()`, delegate to `config_page.handle_post(form, ctx)`, and redirect back to the config route with the returned flash key in the query string.
- the poll-trigger route — `require_session()`, then `poll_cooldown_remaining()`; when non-zero, redirect back with the cooldown flash key and do not run anything. Otherwise `import server.poll_loop as poll_loop` and call `poll_loop.run_once(state_dir=...)` in-process (Pattern 3 — the same code path production runs, without spawning a child process and without re-parsing console output), wrap it in a try that turns any exception into the save-failure flash rather than a traceback, then `mark_poll_triggered()` and redirect with the success flash key.
- the theme route — set the UI-theme cookie when the submitted value is a member of `layout.UI_THEME_CHOICES`, ignore it otherwise, and redirect back to the referring tab chosen from a fixed allowlist of the five known routes (never redirect to a client-supplied URL).
- anything else — 404.

**Cooldown.** `POLL_COOLDOWN_S = 45` (D-17: tens of seconds, a guard against an accidental double-click, not an abuse rate-limit). `poll_cooldown_remaining(state_dir)` and `mark_poll_triggered(state_dir)` read and write the last-trigger timestamp through `history_db`'s meta table, so the window is **server-global and survives a service restart** — a per-session cooldown would be defeated by a second browser tab, which is Pitfall 8's exact point.

**Gallery helpers.** `gallery_entries(state_dir, limit)` returns the newest N filenames from `<state_dir>/gallery/`, sorted by name descending (plan 06-10 names them by timestamp so lexical order is chronological), filtered to entries whose name ends in the PNG extension. `gallery_bytes(state_dir, name)` returns the file's bytes only when `name` appears in that listing, else `None`.

**CLI.** `build_parser()` with `--port` (default `DEFAULT_PORT = 8643`), `--state-dir` (default matching `poll_loop.DEFAULT_STATE_DIR`), and `--geofence`. `main()` performs the startup refusal, sets the Handler class attributes, binds `ThreadingHTTPServer`, prints a startup line naming the port and state directory only, and calls `serve_forever()`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet → Caddy → companion service | Every request arrives from an untrusted network; the only access control is the shared-password session. |
| client request path/query/body → router | Path segments, query strings and form bodies are attacker-controlled and reach file lookups, redirects and a code path that runs the production poll cycle. |
| companion service → free ADS-B aggregators | `POST /poll-now` causes outbound requests to third-party free APIs whose goodwill this project depends on. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-05-01 | Elevation of Privilege | a route missing its session gate | critical | mitigate | `require_session()` is called as the first statement of every non-public branch, and the harness asserts the refusal on nine routes individually rather than once. A single missed call is a whole-site bypass, so route-by-route assertion is the control, not a spot check. |
| T-06-05-02 | Information Disclosure | gallery file route path traversal | critical | mitigate | The requested name is matched against an `os.listdir()` of the gallery directory and served only on an exact match; no client string is ever joined onto a path. The harness asserts traversal-shaped, absolute and null-byte names all 404 and that a canary file one level up is never returned. |
| T-06-05-03 | Denial of Service | `POST /poll-now` hammering the free aggregators | high | mitigate | A server-global cooldown persisted in `history_db`'s meta table, checked before any outbound call, surviving both a second browser tab and a service restart (Pitfall 8). D-17's stated purpose is protecting adsb.fi and adsb.lol from accidental repeat triggering. |
| T-06-05-04 | Tampering | open redirect via the theme-toggle return path | medium | mitigate | The post-toggle redirect target is chosen from a fixed allowlist of the five known tab routes; a client-supplied URL is never used as a redirect location. |
| T-06-05-05 | Tampering | reflected content via the flash query parameter | high | mitigate | The query string carries only a key; the key is mapped through a fixed dictionary to 06-UI-SPEC.md's own copy. No query-string value is ever rendered into the page, escaped or otherwise. |
| T-06-05-06 | Elevation of Privilege | service running with no password configured | critical | mitigate | `main()` calls `auth.configured_password()` before binding the socket and exits non-zero on `AuthNotConfigured`; the harness asserts the non-zero exit and that the message contains no value. |
| T-06-05-07 | Denial of Service | oversized request body | medium | mitigate | `read_form()` caps the body at a small explicit limit and treats an oversized or undecodable body as an empty form, so a large POST cannot exhaust memory in a thread of `ThreadingHTTPServer`. |
| T-06-05-08 | Information Disclosure | request logging | medium | mitigate | `log_message()` is overridden to print method and path only, matching the vendored server's own override; no header, cookie, form body or query string is ever logged. |
| T-06-05-09 | Tampering | writing `poll_state.json` from two processes | medium | mitigate | The companion service never writes `poll_state.json`; user settings live in the separate `device_config.json` (Pitfall 5), and the poll trigger mutates state only by calling `run_once()`, which is that file's single legitimate writer. |
| T-06-05-SC | Tampering | package installs | high | accept | Zero new packages; stdlib `http.server` plus the already-pinned Pillow reached through `server.panel_preview`. The Flask alternative and its six `[SUS]` legitimacy entries were not selected, so no install checkpoint applies. |
