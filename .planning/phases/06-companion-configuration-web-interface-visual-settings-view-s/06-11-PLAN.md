## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-11-01 | Information Disclosure | companion port reachable directly | critical | mitigate | An explicit ufw deny for the companion port beside the existing app-port deny, plus the unit comment recording that loopback restriction is enforced at the firewall and proxy layer. Without it the service answers plaintext on a public port, bypassing TLS entirely. Plan 06-12 verifies the deny from outside the host. |
| T-06-11-02 | Information Disclosure | the shared password entering git | critical | mitigate | Only the template file is committed, carrying a placeholder and the same never-committed warning the existing secret carries. The unit references the env file, never a value. The password is written by hand on the VPS only, per the documented one-time step. |
| T-06-11-03 | Information Disclosure | credentials in the durable access log | high | mitigate | The battery tailer extracts only an explicit four-name telemetry-header allowlist rather than copying the header map, so even a future Caddy configuration that stopped redacting the authorisation header could not move a device bearer token into the history database. The Caddyfile comment records this. |
| T-06-11-04 | Denial of Service | unbounded access-log growth | medium | mitigate | The durable log directive sets a size-based roll and a bounded retained-file count, and the tailer resets its stored offset when the file is shorter than the offset, so a rotation neither loses nor double-counts readings. |
| T-06-11-05 | Elevation of Privilege | companion process privileges | high | mitigate | The unit runs as the unprivileged service user with the same five hardening directives as the existing unit and `ReadWritePaths` scoped to the state directory only, so a compromise of the web-facing process cannot write application code or system paths. |
| T-06-11-06 | Denial of Service | a companion crash taking down detection | medium | mitigate | D-03's separate-process design: three independent units. A restart loop in the configuration interface leaves the poll timer and the device-protocol server untouched, and the device keeps fetching the last good panel. |
| T-06-11-07 | Repudiation | untested code shipping silently | high | mitigate | All six new harnesses join the canonical array CI already calls, and the companion package joins the coverage scope with a freshly-derived threshold, so new code cannot be both shipped and unmeasured. |
| T-06-11-SC | Tampering | package installs | high | accept | No package manager runs in this plan and no new pinned requirement is added — the companion service reuses the deployed venv's existing Pillow and requests. The provisioning script's own apt installs are unchanged. |
