  <action>
Create `server/panel_preview.py` importing only stdlib (`io`, `os`, `datetime`, `sys`) plus `PIL.Image` and `server.panel_format`. Use the repo-root `sys.path` bootstrap block `server/poll_loop.py` uses (lines 31-38) so the module resolves under both import styles.

Module docstring must state, in its own words: this module is the inverse of `panel_format.pack_panel()`; it exists because the render CLI's preview flag renders a synthetic sample flight and therefore cannot answer what the panel is showing right now (06-RESEARCH.md Pattern 4 and its Anti-Patterns list); and the RGB values it produces come from `panel_format.PALETTE_RGB`, which D-P2-03 defines as nominal render-internal swatches, so the preview faithfully reproduces the *indices* on the wire but is explicitly not colour-accurate against real Spectra 6 glass. Plan 06-09's Preview page surfaces that same caveat as caption copy.

Define `NIBBLE_TO_INDEX` by inverting `panel_format.INDEX_TO_NIBBLE` with a dict comprehension — never by retyping the six pairs. That single derivation is what makes silent drift between pack and unpack impossible; say so in a comment.

Define `PanelDecodeError(ValueError)`.

`unpack_panel(raw_bytes)`: validate the length against `panel_format.IMAGE_BYTES` and raise `PanelDecodeError` naming both expected and actual lengths when it differs. Build a `bytearray` of `WIDTH * HEIGHT` index values by walking rows and column pairs exactly as `pack_panel()` does in reverse — high nibble is the left pixel, low nibble the right. Look each nibble up with an explicit membership test against `NIBBLE_TO_INDEX`, raising `PanelDecodeError` naming the illegal code and its byte offset when absent. Construct `Image.new("P", (WIDTH, HEIGHT))`, apply `panel_format.padded_palette()`, `putdata()` the index bytes, and return the "P"-mode image. Return "P" mode, not RGB, so the round-trip check can compare index data directly; callers needing colour call `.convert("RGB")`.

`panel_png_bytes(raw_bytes, max_width=None)`: unpack, convert to RGB, optionally resize to `max_width` preserving aspect ratio using nearest-neighbour resampling, save into an `io.BytesIO` as PNG with `optimize=True`, return `getvalue()`. Nearest-neighbour is required, not a preference: any smoothing filter blends the six flat panel colours into intermediate values that do not exist on the device.

`read_panel_file(state_dir)`: read `panel.bin` from the state directory in binary; return `None` on `OSError`. Do not validate the length here — that is `unpack_panel()`'s job, so the caller can distinguish "no panel yet" from "panel present but unreadable".

`panel_file_mtime_iso(state_dir)`: return the panel file's modification time as a timezone-aware UTC ISO-8601 second-precision string, or `None` when the file is missing. This is the Preview page's caption timestamp.

The module must emit nothing to standard output and must never write to the filesystem — it is imported inside an HTTP request handler, where a stray console write would pollute the service journal and a stray file write would race the poll pipeline.
