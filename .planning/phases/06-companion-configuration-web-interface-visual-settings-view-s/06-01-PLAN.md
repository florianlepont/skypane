## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| companion HTTP form → `save_device_config()` | A user-submitted theme/runway id crosses into code that would otherwise use it as a dict key and as a render/detection parameter. |
| ADS-B aggregator / adsbdb → `record_runway_event()` | Callsigns, airline names and aircraft types originate from untrusted external feeds and are persisted verbatim for later HTML display. |
| Caddy access log file → `ingest_caddy_battery_log()` | A log file on disk, written by another process, parsed as JSON and turned into database rows. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01-01 | Tampering | `device_config.normalise_theme_id` / `normalise_runway_id` | high | mitigate | Membership test against the fixed `THEMES`/`RUNWAYS` key sets before the value is ever used as a dict key or written; `save_device_config()` raises `ValueError` on a non-member and leaves the file untouched. No path substitution, no dynamic import, no `eval`. |
| T-06-01-02 | Tampering | `history_db` query layer | high | mitigate | Every statement uses `?` placeholders; the acceptance criteria grep for f-string and `%`-formatted SQL and must find none. |
