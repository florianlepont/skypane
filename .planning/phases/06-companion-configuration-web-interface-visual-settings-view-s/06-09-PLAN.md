<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| feed-sourced flight fields in `history.db` → rendered HTML table | Callsigns, airline names and aircraft types originate from untrusted external feeds. |
| gallery filenames on disk → rendered URLs and captions | Filenames are written by the poll pipeline but are read back from a directory and interpolated into markup. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-09-01 | Tampering | stored XSS via flight-log cells | high | mitigate | Every cell reaches HTML through `layout.data_table()`, which escapes internally; the module imports no escaping of its own and a dedicated check asserts a markup-shaped callsign renders escaped. |
| T-06-09-02 | Information Disclosure | gallery URL construction | high | mitigate | The page builds gallery URLs only from names the router's own listing helper returned, and the router itself serves a file only on an exact match against a fresh directory listing (plan 06-05's T-06-05-02). The page never constructs a path. |
| T-06-09-03 | Denial of Service | unbounded gallery or history rendering | medium | mitigate | Both sections are capped by explicit module constants — a display limit for tiles and a row limit for events — so a large database or a retention-hook bug cannot produce a multi-megabyte page. |
| T-06-09-04 | Repudiation | preview presented as colour-accurate | medium | mitigate | A mandatory caveat sentence states the preview uses nominal render-internal swatches, two of which are still explicitly interim pending Phase 7. Without it a user could mistake a preview mismatch for a hardware fault. |
| T-06-09-05 | Tampering | scope creep into a deferred idea | low | mitigate | The simulate-a-flight control was explicitly not selected during discussion; the page contains no input element and the module docstring records why, so the omission is a documented decision rather than an oversight a later contributor "fixes". |
| T-06-09-SC | Tampering | package installs | high | accept | No package manager runs; the thumbnails are produced by the already-pinned Pillow through `server.panel_preview`. |
</threat_model>
