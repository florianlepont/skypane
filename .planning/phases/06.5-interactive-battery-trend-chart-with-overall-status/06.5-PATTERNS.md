### `companion/pages/health_page.py` — `battery_sparkline_svg()` hit-target extension (utility, transform)

**Analog:** itself — extend the existing per-point coordinate loop rather than rewriting it.

**Current core pattern** (verbatim, ~232-271):
```python
def battery_sparkline_svg(rows):
    chronological = list(reversed(rows))
    values = [
        row.get("battery_mv") for row in chronological
        if isinstance(row.get("battery_mv"), int) and not isinstance(row.get("battery_mv"), bool)
    ]
    if len(values) < 2:
        return ""

    width, height, padding = 300, 60, 4
    usable_w = width - 2 * padding
    usable_h = height - 2 * padding
    lo, hi = min(values), max(values)
    span = (hi - lo) or 1
    step = usable_w / (len(values) - 1)

    points = []
    for index, value in enumerate(values):
        x = padding + index * step
        y = padding + usable_h - ((value - lo) / span) * usable_h
        points.append("%.1f,%.1f" % (x, y))

    return (
        '<svg viewBox="0 0 %d %d" width="%d" height="%d" '
        'xmlns="http://www.w3.org/2000/svg" role="img" aria-label="Battery trend">'
        '<polyline points="%s" fill="none" stroke="currentColor" stroke-width="2"/>'
        "</svg>"
    ) % (width, height, width, height, " ".join(points))
```

**Extension pattern** (from RESEARCH.md Pattern 1/2 — per-point `<circle>` markers with escaped attributes, matching this file's single-escaping-choke-point discipline via `escape_html()`):
```python
'<circle class="sparkline-point" tabindex="0" cx="%.1f" cy="%.1f" r="3" '
'data-mv="%d" data-ts="%s"><title>%s mV at %s</title></circle>' % (
    x, y, value, escape_html(ts), value, escape_html(ts))
```
Note: `ts` needs to be threaded through the existing `chronological`/`values` loop (currently only `battery_mv` is extracted per row — the extension must also carry each row's `ts` alongside its `value` to emit `data-ts`). Use `escape_html()` for the `ts` string exactly as `_device_section()`/`_pipeline_section()` already do for their own timestamp interpolation (`escape_html(ts)` appears at line ~356 and ~369 in the same file).

Enlarge the tap target per RESEARCH.md Pattern 2 (transparent `r="8"` hit-circle at the same coordinates, visible `r="3"` circle kept cosmetic) — this is additive to the pattern above, not a replacement.

```python
def send_bytes(self, code, content_type, payload, cache_seconds=0):
    self.send_response(code)
    self.send_header("Content-Type", content_type)
    self.send_header("Content-Length", str(len(payload)))
    if cache_seconds > 0:
        self.send_header("Cache-Control", "public, max-age=%d" % cache_seconds)
    else:
        self.send_header("Cache-Control", "no-store")
    self.end_headers()
    self.wfile.write(payload)
```

### `companion/static/battery-trend.js` (NEW — no in-repo analog)

This is the first JS file in the project; there is no existing analog to copy structurally. RESEARCH.md's Code Examples section provides the reference implementation (already vetted against this codebase's conventions — `textContent` not `innerHTML`, matching the single-escaping-choke-point discipline in spirit):
```javascript
(function () {
  "use strict";
  var readout = document.getElementById("battery-readout");
  if (!readout) return;
  function reveal(circle) {
    readout.textContent = circle.dataset.mv + " mV — " + circle.dataset.ts;
  }
  document.querySelectorAll(".sparkline-point").forEach(function (circle) {
    circle.addEventListener("click", function () { reveal(circle); });
    circle.addEventListener("keydown", function (evt) {
      if (evt.key === "Enter" || evt.key === " ") { evt.preventDefault(); reveal(circle); }
    });
  });
})();
```
Constraints carried forward from RESEARCH.md: no inline `on*=` handlers anywhere in rendered HTML, `click` handles both mouse and touch (no separate `touchstart`), exactly one `<script src=...>` tag emitted only on the branch where a sparkline actually renders (never on the empty-state path).
