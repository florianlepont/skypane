<objective>
`sketch-findings-skypane` is this project's design authority, and D-08's standing
framing is that it moves in step with whatever a phase changes. This phase changed
a lot that is not in it: the app now has a shared drawing module, two distinct SVG
coordinate schemes with a rule for choosing between them, status-coloured data
marks, a ring gauge used at two sizes, a chart with an area and a threshold, a
time-domain band, and — for the first time in the project's history — browser
assertions that run in dark mode.

That last one is worth stating plainly in the authority, because until this phase
every visual claim this project made about dark mode was made by reading CSS.

Purpose: close the phase. Record what changed where the next phase will look for
it; write the coverage ledger clause by clause; collect the provisional decisions
so the developer settles them rather than inheriting them; and run the gate,
including the human sweep that `workflow.human_verify_mode: end-of-phase` defers to
here.

Output: an updated authority, a ledger, a decision list, and a green suite that did
not skip.
</objective>

</decisions_covered>
