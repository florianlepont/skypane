Verified via a fresh screenshot (visibly smaller, proportionate) and the full `companion/test_companion_app.py` (88/88) and `companion/test_view_pages.py` (42/42) suites, which pass unmodified since no test pins the specific pixel values.

## Deviations from Plan

### Auto-fixed Issues

**1. [Verify-script correction, no code impact] Task 1's non-goal gate initially reported a false D-11 violation**
- **Found during:** Task 1 (non-goal regression gate)
- **Issue:** The plan's own inline Python assertion located the headings-serif selector via `d.index('.text-heading {')`, which finds the *first* of three distinct rules in `style.css` ending in that exact selector text — a bare size/weight rule (no `legend`), the actual serif-family rule (which does carry `legend`), and a margin-rhythm rule. The script matched the wrong one and asserted `legend` was missing.
- **Fix:** Verified the real intent by hand — `legend` is present in the correct serif-family rule (`h1, h2, h3, legend, .text-heading { font-family: var(--font-serif); ... }`, `companion/static/style.css` line ~285-293) — then re-ran the gate with a corrected regex anchored on that full selector sequence. Passed clean.
- **Files modified:** None (the fix was to the verification approach, not to `style.css` — `legend` was never actually removed).
- **Verification:** Corrected script printed `OK D-10/D-11 non-goals held (corrected selector check)`.
- **Committed in:** `371c194` (documented inline in `06.6.4-VALIDATION.md`'s new note on Task 1's gate).

**2. [Real checkpoint finding, fixed post-verdict] Copy button still read as too large**
- **Found during:** Task 2 (developer's real-browser checkpoint)
- **Issue:** D-02's implemented treatment (28px visual box, standard global 20px `.icon`) left only 4px of padding per side — the icon nearly filled the box, reading as "the whole button is too big" per the developer's direct feedback.
- **Fix:** See "Decisions Made" above — box to 22px, icon scoped to 14px, hit area re-centred at -11px inset (44×44 effective, unchanged).
- **Files modified:** `companion/static/style.css`.
- **Verification:** Visual re-check in the browser (light theme, History page) plus `companion/test_companion_app.py` (88/88) and `companion/test_view_pages.py` (42/42).
- **Committed in:** `ee7235a`.
