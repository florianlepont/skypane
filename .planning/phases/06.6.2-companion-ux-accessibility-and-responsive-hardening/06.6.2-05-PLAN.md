<objective>
Give the sidebar the calm control-rail treatment D-17 asks for (tinted active-state pill, a small icon per nav label, a sticky position on long pages) and its missing footer region — the first place in this app a Sign out control exists at all — while moving `/logout` from GET to POST (D-11) so a stray prefetch or crawler request can no longer end a session. This plan closes all of it in the one shared shell file everything else in this phase composes with.
Output: an extended `layout.py` (nav icons, active-pill markup, sidebar/mobile-nav footer region with theme+logout), matching `style.css` rules, and `app.py`'s `/logout` moved to POST.
</objective>
