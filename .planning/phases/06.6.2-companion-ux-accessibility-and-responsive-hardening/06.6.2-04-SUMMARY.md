# Phase 06.6.2 Plan 04: Shared page_header() Component + Page-Title Typography Role Summary

**One `layout.page_header()` component (a new ~30px serif `.page-title` role plus optional purpose/freshness/action slots) now backs every one of the five authenticated pages' top-level heading, replacing five independent bare-`<h1>` patterns — applied title-only in this plan, with the signature locked as the literal contract Phase 06.6.3's per-page redesign plans will consume.**

## Accomplishments

- `companion/layout.py` gained `page_header(title, purpose=None, freshness_html=None, action_html=None)`, placed after `empty_state()`. It escapes `title` into `<h1 class="page-title">`, optionally escapes `purpose` into a `<p class="page-header__purpose text-body">`, and interpolates `freshness_html`/`action_html` verbatim when truthy — mirroring `stat_tile()`'s existing "escape the caption, pass already-built content through unmodified" contract, with the docstring explicitly stating the signature is a literal contract Phase 06.6.3 depends on by name.
- `companion/static/style.css` gained `--font-page-title-size: 30px` (placed between `--font-heading-size: 20px` and `--font-display-size: 24px` in file order, per the plan's explicit instruction), a new `.page-title` rule (30px serif, distinct from the 20px `.text-heading` section-heading role — D-15), plus `.page-header__purpose` and `.page-header` spacing rules.
- All five authenticated pages' `render()` now open with `layout.page_header("...")` instead of an independent bare `<h1 class="text-heading">...</h1>` literal: Config (`Config`), Health (`Health`), History (`History`), Airlines (`Airlines`), Preview (`Preview`) — closing D-16. `config_page.py` and `preview_page.py` each gained `import companion.layout as layout` alongside their existing `from companion.layout import escape_html` line, matching `history_page.py`'s pre-existing dual-import convention; `health_page.py` and `airlines_page.py` already had the dual import.
- `companion/test_config_page.py` (38→39), `companion/test_status_pages.py` (47→49), and `companion/test_view_pages.py` (28→30) each gained regression checks pinning every page's new `<h1 class="page-title">...</h1>` markup and the absence of the old `<h1 class="text-heading">` pattern.
