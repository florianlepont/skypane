# Phase 06.6.2 Plan 01: Visual Foundation (Contrast Utility, Colour Tokens, Motion) Summary

**Pure-stdlib WCAG contrast checker plus a reworked 3-surface-level colour-token system that fixes the light-theme accent's failing text contrast (UXA-04), adds D-06's native-control accent-color rule, and D-19's global motion/reduced-motion polish.**

## Performance

- **Duration:** 10 min (three task commits, 09:31-09:38 local)
- **Started:** 2026-08-31T09:31:34+02:00 (first task commit)
- **Completed:** 2026-08-31T09:38:03+02:00 (last task commit)
- **Tasks:** 3/3
- **Files modified:** 4 (2 new, 2 modified)

## Accomplishments

- `companion/contrast_check.py` ships as a new zero-import, pure-arithmetic WCAG 2.1 SC 1.4.3 module — `relative_luminance()`/`contrast_ratio()` reproduce every one of `06.6.1-UX-AUDIT.md`'s own published contrast numbers exactly.
- `companion/static/style.css`'s four token blocks (`:root`, `prefers-color-scheme: dark`, `data-ui-theme="light"`, `data-ui-theme="dark"`) each gained `--color-canvas` and now express three genuinely distinct surface levels — page canvas, primary card/control surface, secondary/elevated/nav surface — in both light and dark.
- Light-mode `--color-accent` darkened `#E8622C` -> `#B13F16` (hover `#D2521F` -> `#963610`), closing UXA-04's failing WCAG AA contrast while staying hue-separated from `--color-status-warn`'s amber.
- Dark-mode `.stat-tile`/`.page-section`/`.battery-trend-section` gained a restrained visible `border-color` (D-14's explicit dark-mode instruction); light mode's shadow-only card treatment is untouched.
- `accent-color: var(--color-accent)` added to the shared `input, select` rule, so every native radio/checkbox site-wide renders in the terracotta accent (D-06).
- 120-180ms colour/border/shadow transitions added to `a`, `button`, `.sidebar-link`, `.mobile-nav__link`, `.site-nav-toggle`, `.theme-form .theme-option`, `input`, `select`, plus one global `@media (prefers-reduced-motion: reduce)` override every later plan's new transitions inherit for free (D-19).
- `companion/test_contrast_check.py` ships as a new permanent, dependency-free regression harness (16 checks: 8 formula-fidelity fixtures + 8 live light/dark token-pair contrast checks with hard-coded hex literals), registered in `scripts/run-all-tests.sh`'s `HARNESSES` array (15 -> 16 files).
