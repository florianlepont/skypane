<objective>
Capture the pre-migration baseline of the 9 companion harnesses before any of them is
rewritten, and build `33-ledger-check.py`. Every migration plan uses that tool to prove its
slice is fully accounted for (TST-15).

harness's own stdout. It must be captured BEFORE any rewrite. The large harnesses migrate in
stages across 4-7 plans each, so the tool must also check a half-migrated state. The rule is
that the pending rows equal the checks the shrunk legacy harness still runs, so every check is
always either still running as legacy or ported (33-MIGRATION-RULES.md section 1).
